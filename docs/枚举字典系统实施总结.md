## 🔄 缓存机制

### 配置
```javascript
const CACHE_KEY = 'app_dictionaries_cache'
const CACHE_TIMESTAMP_KEY = 'app_dictionaries_timestamp'
const CACHE_VALIDITY_HOURS = 24 // 24小时
```

### 缓存流程
```
1. 首次加载 → 从服务器获取 → 存入localStorage
2. 再次加载 → 检查缓存 → 未过期使用缓存
3. 缓存过期 → 从服务器获取 → 更新缓存
4. 加载失败 → 使用过期缓存（降级方案）
```

### 手动操作
```javascript
// 强制刷新
this.$store.dispatch('dictionary/loadProductionPlanDictionaries', true)

// 清除缓存
this.$store.dispatch('dictionary/clearDictionaryCache')
```

## 🎓 最佳实践

### ✅ 推荐做法

1. **使用Mixin**：组件中优先使用mixin
2. **使用工具函数**：工具函数或非组件中使用
3. **避免硬编码**：所有枚举都从字典获取
4. **信任缓存**：不要频繁清除缓存

### ❌ 避免的做法

1. **不要硬编码枚举**：
   ```javascript
   // ❌ 错误
   const STATUS_MAP = { RELEASED: '已发布' }

   // ✅ 正确
   this.getPlanStatusLabel('RELEASED')
   ```

2. **不要重复定义选项**：
   ```javascript
   // ❌ 错误
   data() {
     return {
       statusOptions: [{ value: 'RELEASED', label: '已发布' }]
     }
   }

   // ✅ 正确
   computed: {
     statusOptions() {
       return this.planStatusOptions
     }
   }
   ```

3. **不要频繁强制刷新**：
   ```javascript
   // ❌ 错误：每次打开对话框都刷新
   mounted() {
     this.$store.dispatch('dictionary/loadProductionPlanDictionaries', true)
   }

   // ✅ 正确：信任缓存机制
   mounted() {
     // 不需要手动加载，系统会自动处理
   }
   ```
