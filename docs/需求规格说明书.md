## 1. 文档概述

### 1.1 文档目的

本文档旨在详细描述铝箔退火炉MES系统的功能性需求，明确各功能模块的核心目标、功能边界和交互关系，为系统设计和开发提供准确的需求依据。

### 1.2 适用范围

本文档适用于铝箔退火炉车间的制造执行系统，涵盖从原料入库到成品出库的完整生产流程管理。

### 1.3 术语定义

- **料框 (Bin)**: 承载铝箔卷材的标准化容器
- **料垛 (Stack)**: 多个料框的组合单元
- **退火炉**: 对铝箔进行热处理的核心设备
- **行车**: 车间内物料搬运的起重设备
- **AGV/RGV**: 自动导引车/轨道导引车
- **MES**: 制造执行系统

---

## 2. 系统架构概览

### 2.1 系统定位

铝箔退火炉MES系统作为车间级制造执行系统，承接上层ERP的生产计划，协调下层设备控制系统，实现生产过程的精细化管理和实时监控。

### 2.2 核心业务实体

- **料框 (Bin)**: 物料承载的基本单位
- **料垛 (Stack)**: 物料管理的逻辑单位
- **退火炉**: 生产执行的核心设备
- **库位**: 物料存储的空间单位
- **退火任务**: 生产执行的基本单位
- **物流任务**: 物料转运的执行单位

## 3. 功能模块详细说明

### 3.1 主数据管理模块 (MDM)

#### 3.1.1 核心功能目标

建立和维护系统运行所需的基础数据，确保数据的标准化、一致性和准确性，为其他业务模块提供可靠的数据支撑。

#### 3.1.2 功能边界定义

- **包含功能**: 料框规格、产品信息、物料编码、库位定义、设备参数、工艺模板、质量标准的创建、修改、查询、状态管理
- **不包含功能**: 实时数据采集、业务流程执行、报表生成、权限控制

#### 3.1.3 范围限制说明

- 仅负责主数据的静态管理，不涉及动态业务数据
- 数据变更需要版本控制和审批流程
- 与外部系统的数据同步通过接口实现，不直接操作外部数据

#### 3.1.4 子功能模块

**料框规格管理**

- 功能描述：维护料框的物理规格和技术参数
- 核心数据：料框类型、尺寸规格、承重能力、材质信息
- 业务规则：料框规格一旦被使用不可删除，只能停用

**产品信息管理**

- 功能描述：维护铝箔产品的基本信息和技术规格
- 核心数据：产品编码、产品名称、规格参数、工艺要求
- 业务规则：产品信息与工艺模板强关联，变更需同步更新

**工艺模板管理**

- 功能描述：定义和维护退火工艺的标准参数和执行流程
- 核心数据：工艺编码、温度曲线、时间参数、气氛要求
- 业务规则：工艺模板支持版本管理，生效版本唯一

**质量标准管理**

- 功能描述：定义产品质量检验的标准和判定规则
- 核心数据：检验项目、标准值范围、检测方法、判定规则
- 业务规则：质量标准与产品类型关联，支持多版本并存

### 3.2 库存管理模块 (INV)

#### 3.2.1 核心功能目标

实现车间内物料的精确定位、状态跟踪和库存优化，确保物料流转的可视化和可追溯性。

#### 3.2.2 功能边界定义

- **包含功能**: 料框/料垛的注册、状态管理、位置跟踪、库存查询、库位分配
- **不包含功能**: 物料的物理搬运、设备控制、生产计划制定

#### 3.2.3 范围限制说明

- 仅管理车间内部库存，不涉及原料库和成品库
- 库存数据以料框/料垛为最小管理单位
- 库位分配基于预设规则，不支持完全自由分配

#### 3.2.4 子功能模块

**料框/料垛管理**

- 功能描述：管理料框和料垛的基本信息、状态变化和组合关系
- 核心数据：料框ID、料垛ID、物料信息、重量、状态、组合关系
- 业务规则：料框状态变化遵循预定义流程，料垛拆分需记录历史

**库存状态管理**

- 功能描述：实时维护和查询车间内所有物料的状态信息
- 核心数据：物料ID、当前状态、位置信息、状态变更历史
- 业务规则：状态变更需要触发事件，支持状态回滚机制

**物料位置跟踪**

- 功能描述：实时跟踪物料在车间内的精确位置
- 核心数据：物料ID、当前库位、移动轨迹、时间戳
- 业务规则：位置变更必须通过物流任务触发，支持历史轨迹查询

**库位分配优化**

- 功能描述：基于预设规则智能推荐或自动分配最优库位
- 核心数据：库位信息、占用状态、分配规则、优化参数
- 业务规则：分配优先级可配置，支持手动干预和强制分配

### 3.3 生产任务管理模块 (PROD)

#### 3.3.1 核心功能目标

承接生产计划，分解为可执行的退火任务和物流任务，实现生产资源的合理调度和任务的有序执行。

#### 3.3.2 功能边界定义

- **包含功能**: 生产计划接收、退火任务生成、炉次调度、物流任务生成
- **不包含功能**: 生产计划制定、设备维护计划、质量检验执行

#### 3.3.3 范围限制说明

- 仅处理退火工序的生产任务，不涉及其他工序
- 任务调度基于有限产能和资源约束
- 任务执行状态由执行模块反馈，本模块不直接控制设备

#### 3.3.4 子功能模块

**生产计划管理**

- 功能描述：接收、解析和管理来自上层系统的生产计划
- 核心数据：计划编号、产品信息、数量要求、交期要求
- 业务规则：计划变更需要重新评估影响，支持计划优先级调整

**退火任务管理**

- 功能描述：将生产计划分解为具体的退火任务，关联物料和工艺
- 核心数据：任务ID、关联计划、物料清单、工艺模板、计划时间
- 业务规则：任务生成遵循工艺约束，支持任务合并和拆分

**退火炉调度**

- 功能描述：基于资源可用性和优化规则调度退火任务到具体炉次
- 核心数据：炉次计划、资源占用、调度规则、优化目标
- 业务规则：调度算法可配置，支持手动调整和紧急插单

**物流任务生成**

- 功能描述：根据生产需求自动生成物料转运任务
- 核心数据：任务类型、起止位置、物料信息、优先级、时间窗口
- 业务规则：任务生成遵循物流路径约束，支持任务优先级动态调整

### 3.4 执行与监控模块 (EXEC)

#### 3.4.1 核心功能目标

实时监控和控制生产过程执行，确保按计划和工艺要求进行生产，记录完整的执行数据。

#### 3.4.2 功能边界定义

- **包含功能**: 退火过程监控、设备作业跟踪、炉次过程管理、设备状态监控、质量检验执行
- **不包含功能**: 设备底层控制、工艺参数设定、设备维护执行

#### 3.4.3 范围限制说明

- 监控数据来源于设备接口，不直接采集传感器数据
- 过程控制通过指令下发，不直接操作设备
- 异常处理以报警和流程中断为主，不自动修复

#### 3.4.4 子功能模块

**退火过程监控**

- 功能描述：实时监控退火炉工艺参数执行情况，记录过程数据
- 核心数据：实时温度、压力、流量、设定值、偏差、报警信息
- 业务规则：监控频率可配置，偏差超限自动报警，数据完整记录

**设备作业跟踪**

- 功能描述：跟踪行车和AGV/RGV的任务执行状态和位置信息
- 核心数据：设备状态、任务进度、实时位置、载荷状态、异常信息
- 业务规则：任务分配基于设备能力，状态同步实时更新，异常自动处理

**炉次过程管理**

- 功能描述：指导和确认装炉、退火、出炉的完整炉次生命周期
- 核心数据：装炉清单、扫描记录、操作员、时间节点、确认状态
- 业务规则：操作步骤强制顺序，扫描校验必须通过，关键节点必须确认

**设备状态监控**

- 功能描述：实时监控关键设备的运行状态和关键参数
- 核心数据：设备状态、运行参数、故障信息、OEE指标、维护提醒
- 业务规则：状态变化实时记录，故障自动报警，OEE自动计算

**质量检验执行**

- 功能描述：支持质量检验操作的执行和结果记录
- 核心数据：检验任务、检验标准、检验结果、判定结果、检验员
- 业务规则：检验依据最新标准，结果自动判定，不合格品自动处理

### 3.5 报表与看板模块 (REPORT)

#### 3.5.1 核心功能目标

提供全面的数据可视化和统计分析功能，支持生产监控、管理决策和持续改进。

#### 3.5.2 功能边界定义

- **包含功能**: 生产分析、质量分析、设备分析、实时看板、自定义报表
- **不包含功能**: 数据录入、业务流程执行、系统配置、权限管理

#### 3.5.3 范围限制说明

- 报表数据来源于业务模块，不直接操作原始数据
- 分析结果仅供参考，不自动触发业务流程
- 自定义功能面向高级用户，需要一定的业务理解

#### 3.5.4 子功能模块

**生产分析报表**

- 功能描述：提供产量、效率、计划达成等生产相关的统计分析
- 核心数据：产量统计、炉次效率、计划达成率、趋势分析
- 业务规则：数据按时间维度统计，支持多维度钻取，结果可导出

**质量分析报表**

- 功能描述：提供质量检验、不合格品、工艺质量关联等分析
- 核心数据：合格率统计、不合格品分析、质量追溯、工艺关联
- 业务规则：质量数据完整关联，追溯链条清晰，分析结果准确

**设备分析报表**

- 功能描述：提供设备效率、能耗、故障等设备相关分析
- 核心数据：OEE分析、能耗统计、故障分析、维护记录
- 业务规则：设备数据实时更新，指标计算标准化，分析维度灵活

**实时监控看板**

- 功能描述：以可视化方式实时展示车间关键运行状态和KPI
- 核心数据：车间总览、设备状态、任务进度、库存状态、关键指标
- 业务规则：数据自动刷新，异常信息突出显示，界面适配大屏

**数据分析工具**

- 功能描述：提供灵活的数据查询、自定义报表和数据导出能力
- 核心数据：自定义查询、报表设计、数据导出、钻取分析
- 业务规则：查询权限受控，报表可保存共享，导出格式多样

### 3.6 用户权限管理模块 (USER)

#### 3.6.1 核心功能目标

管理系统用户、角色和权限，确保系统访问的安全性和操作的合规性。

#### 3.6.2 功能边界定义

- **包含功能**: 用户管理、组织结构、角色定义、权限配置、安全策略
- **不包含功能**: 业务数据管理、系统功能开发、外部认证集成

#### 3.6.3 范围限制说明

- 仅管理系统内部用户和权限，不涉及外部系统集成
- 权限控制基于角色模型，不支持复杂的权限继承
- 安全策略配置影响全系统，需要谨慎操作

#### 3.6.4 子功能模块

**用户管理**

- 功能描述：管理系统用户的账号信息、基本资料和状态
- 核心数据：用户信息、登录凭证、状态管理、角色关联
- 业务规则：用户名全局唯一，密码加密存储，状态变更记录

**组织结构管理**

- 功能描述：维护企业的部门层级结构和岗位信息
- 核心数据：部门层级、岗位定义、人员归属
- 业务规则：部门支持层级结构，岗位与权限关联，变更需审批

**角色定义**

- 功能描述：定义不同的用户角色，作为权限分配的载体
- 核心数据：角色信息、权限集合、用户关联
- 业务规则：角色权限可组合，用户可多角色，权限取并集

**权限配置**

- 功能描述：精细化配置角色的功能权限、数据权限和操作权限
- 核心数据：功能权限树、数据权限规则、操作权限列表
- 业务规则：权限最小化原则，变更需记录，配置需测试验证

**安全策略**

- 功能描述：配置系统级的安全参数和规则
- 核心数据：密码策略、会话管理、登录控制、操作日志
- 业务规则：策略全局生效，变更需授权，日志完整保留

## 4. 模块间交互关系

### 4.1 主数据管理模块交互

**对外提供服务：**

- 向库存管理模块提供料框规格、产品信息查询服务
- 向生产任务管理模块提供工艺模板、产品信息查询服务
- 向执行与监控模块提供工艺参数、质量标准查询服务
- 向报表与看板模块提供基础数据字典服务

**对外依赖服务：**

- 依赖用户权限管理模块进行数据变更权限验证
- 依赖外部ERP系统同步产品和物料基础信息

**关键交互流程：**

1. 工艺模板变更 → 通知生产任务管理模块更新相关任务
2. 质量标准更新 → 通知执行与监控模块更新检验规则
3. 设备参数修改 → 通知执行与监控模块更新监控配置

### 4.2 库存管理模块交互

**对外提供服务：**

- 向生产任务管理模块提供物料可用性查询和预留服务
- 向执行与监控模块提供物料位置和状态查询服务
- 向报表与看板模块提供库存统计数据服务

**对外依赖服务：**

- 依赖主数据管理模块获取料框规格和产品信息
- 依赖执行与监控模块接收物料状态变更通知
- 依赖生产任务管理模块接收物料需求信息

**关键交互流程：**

1. 物料入库 → 更新库存状态 → 通知生产任务管理模块可用性变化
2. 任务分配 → 预留物料 → 通知执行与监控模块执行转运
3. 状态变更 → 更新位置信息 → 触发库位重新分配

### 4.3 生产任务管理模块交互

**对外提供服务：**

- 向执行与监控模块提供退火任务和物流任务信息
- 向报表与看板模块提供计划执行数据服务
- 向库存管理模块提供物料需求预测服务

**对外依赖服务：**

- 依赖主数据管理模块获取工艺模板和产品信息
- 依赖库存管理模块获取物料可用性信息
- 依赖执行与监控模块接收任务执行状态反馈
- 依赖外部ERP系统接收生产计划

**关键交互流程：**

1. 接收生产计划 → 查询物料可用性 → 生成退火任务 → 下发执行模块
2. 任务调度 → 检查设备可用性 → 分配炉次 → 生成物流任务
3. 接收执行反馈 → 更新任务状态 → 触发后续任务或报警

### 4.4 执行与监控模块交互

**对外提供服务：**

- 向生产任务管理模块提供任务执行状态反馈服务
- 向库存管理模块提供物料状态变更通知服务
- 向报表与看板模块提供实时执行数据服务

**对外依赖服务：**

- 依赖主数据管理模块获取工艺参数和质量标准
- 依赖生产任务管理模块接收任务指令
- 依赖库存管理模块获取物料位置信息
- 依赖设备控制系统进行数据采集和指令下发

**关键交互流程：**

1. 接收任务指令 → 下发设备控制指令 → 监控执行过程 → 反馈执行状态
2. 采集过程数据 → 判断工艺偏差 → 触发报警 → 记录异常事件
3. 完成质量检验 → 更新物料状态 → 触发后续物流任务

### 4.5 报表与看板模块交互

**对外提供服务：**

- 向管理层提供决策支持数据服务
- 向各业务模块提供数据分析结果服务

**对外依赖服务：**

- 依赖所有业务模块获取原始数据
- 依赖用户权限管理模块进行数据访问权限控制

**关键交互流程：**

1. 定时采集各模块数据 → 数据清洗和计算 → 生成报表和看板
2. 接收用户查询请求 → 权限验证 → 数据查询和展示
3. 异常数据发现 → 通知相关业务模块 → 触发数据核查

### 4.6 用户权限管理模块交互

**对外提供服务：**

- 向所有模块提供用户身份验证和权限验证服务
- 向系统提供安全策略配置服务

**对外依赖服务：**

- 可选依赖外部认证系统进行单点登录集成

**关键交互流程：**

1. 用户登录 → 身份验证 → 获取权限信息 → 返回访问令牌
2. 业务操作 → 权限验证 → 允许或拒绝操作 → 记录操作日志
3. 权限变更 → 通知相关模块 → 更新权限缓存 → 生效新权限

## 5. 数据流转说明

### 5.1 核心业务数据流

**生产计划流转：**
ERP系统 → 生产任务管理模块 → 退火任务生成 → 执行与监控模块 → 任务执行反馈 → 生产任务管理模块 → ERP系统

**物料状态流转：**
库存管理模块 → 物料注册 → 生产任务管理模块 → 任务分配 → 执行与监控模块 → 状态变更 → 库存管理模块 → 位置更新

**工艺数据流转：**
主数据管理模块 → 工艺模板 → 生产任务管理模块 → 任务关联 → 执行与监控模块 → 过程监控 → 报表与看板模块 → 工艺分析

**质量数据流转：**
主数据管理模块 → 质量标准 → 执行与监控模块 → 质量检验 → 结果记录 → 报表与看板模块 → 质量分析

### 5.2 关键控制点

**数据一致性控制：**

- 物料状态变更必须通过库存管理模块统一处理
- 任务状态变更必须通过生产任务管理模块统一管理
- 设备状态变更必须通过执行与监控模块统一监控

**业务流程控制：**

- 生产任务必须基于有效的生产计划和可用物料
- 物流任务必须基于有效的生产任务和库位分配
- 质量检验必须基于有效的质量标准和检验流程

**权限访问控制：**

- 所有数据访问必须通过用户权限管理模块验证
- 关键操作必须记录操作日志和审计轨迹
- 敏感数据必须按照数据权限规则进行过滤

### 5.3 异常处理机制

**数据异常处理：**

- 数据不一致时触发数据校验和修复流程
- 关键数据丢失时触发数据恢复和补录流程
- 数据访问异常时触发权限重新验证流程

**业务异常处理：**

- 任务执行异常时触发任务暂停和人工干预流程
- 设备故障时触发任务重新调度和资源重新分配流程
- 质量异常时触发不合格品处理和原因分析流程

**系统异常处理：**

- 模块通信异常时触发重试和降级处理机制
- 外部接口异常时触发离线模式和数据缓存机制
- 性能异常时触发负载均衡和资源优化机制
