# Token自动刷新功能 - 快速测试操作手册

## ⚡ 5分钟快速测试

**目标**：快速验证Token自动刷新功能是否正常工作

**前置条件**：
- ✅ 前端开发服务器运行中 (http://localhost:9529)
- ✅ 后端服务已重启（Token配置已生效）

---

## 🎯 测试场景1：正常Token刷新（必测）

### 步骤1：登录系统

1. 打开浏览器访问：http://localhost:9529/login
2. 输入用户名密码登录
3. 登录成功后停留在首页

### 步骤2：准备测试环境

**打开浏览器开发者工具**（按F12）：
- ✅ 切换到 **Network（网络）** 标签
- ✅ 勾选 **Preserve log**（保留日志）
- ✅ 切换到 **Console（控制台）** 标签

### 步骤3：让Token快速过期

⚠️ **重要说明**：Token过期是由**后端JWT验证**决定的，不是前端存储的`expiresAt`字段。

#### 方法A：修改后端配置（推荐）⭐

**操作步骤**：
1. 让后端修改配置文件：
   ```env
   # .env.development
   JWT_ACCESS_EXPIRATION_MINUTES=1  # 改为1分钟
   ```

2. **后端重启服务**

3. **前端重新登录**（获取新的1分钟过期Token）

4. **等待1-2分钟**

5. **跳到步骤4**：点击菜单触发请求

#### 方法B：模拟后端401响应（开发调试用）

如果后端无法修改配置，可以在Console模拟：

```javascript
// ⚠️ 仅用于理解流程，实际测试需要真实的Token过期
console.log('模拟Token过期场景...');
console.log('实际测试需要：');
console.log('1. 后端配置JWT_ACCESS_EXPIRATION_MINUTES=1');
console.log('2. 重新登录');
console.log('3. 等待1分钟');
console.log('4. 点击菜单触发请求');
```

#### 为什么修改expiresAt不起作用？

```
❌ 错误理解：
  修改前端的expiresAt → Token过期 ✗

✅ 正确流程：
  后端验证JWT内部的exp → Token过期 ✓
  后端返回401 + AUTH_002 → 前端检测到 ✓
  前端自动刷新Token ✓
```

### 步骤4：触发API请求

**前提**：确保已按照步骤3方法A操作（后端Token配置为1分钟）

**等待时间**：登录后等待 **1-2分钟**

**触发请求**：点击任意菜单，例如：
- "主数据管理" → "铝箔产品管理"
- 或 "主数据管理" → "料框规格管理"

### 步骤5：观察结果 🔍

#### ✅ 成功的标志

**Network面板应该看到**：
```
1️⃣ GET /v1/... (或其他API)
   Status: 401
   Response: { error: { code: "AUTH_004" } }

2️⃣ POST /v1/auth/refresh-tokens
   Status: 200
   Response: { success: true, data: { access: {...}, refresh: {...} } }

3️⃣ GET /v1/... (重试)
   Status: 200
   Response: 正常数据
```

**Console面板应该看到**：
```
🔄 Token过期，尝试自动刷新...
✅ Token刷新成功
```

**页面表现**：
- ✅ 没有跳转到登录页
- ✅ 页面正常加载数据
- ✅ **用户完全无感知**

#### ❌ 失败的标志

如果看到以下情况，说明有问题：
- ❌ 直接跳转到登录页
- ❌ 显示"登录已过期"
- ❌ Network只看到一次401，没有刷新请求
- ❌ Console报错

### 步骤6：验证Token已更新

在 **Console** 中执行：

```javascript
// 获取Token（兼容两种存储位置）
const storageKey = 'moses_auth_data';
const authData = sessionStorage.getItem(storageKey)
  ? JSON.parse(sessionStorage.getItem(storageKey))
  : JSON.parse(localStorage.getItem(storageKey));

console.log('新accessToken:', authData.token.access.substring(0, 50) + '...');
console.log('新过期时间:', new Date(authData.token.expiresAt));
console.log('距离过期还有:', Math.round((authData.token.expiresAt - Date.now()) / 60000), '分钟');
console.log('存储位置:', authData.token.storage);
```

**预期结果**：
```
新accessToken: eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
新过期时间: [约30分钟后的时间]
距离过期还有: 29 或 30 分钟
```

## 🎯 测试场景2：refreshToken过期（可选）

### 快速操作

1. 在 **Console** 执行：

```javascript
// 同时让accessToken和refreshToken都无效
const storageKey = 'moses_auth_data';
let authData, storage;

if (sessionStorage.getItem(storageKey)) {
  authData = JSON.parse(sessionStorage.getItem(storageKey));
  storage = sessionStorage;
  console.log('📍 从 sessionStorage 获取Token');
} else {
  authData = JSON.parse(localStorage.getItem(storageKey));
  storage = localStorage;
  console.log('📍 从 localStorage 获取Token');
}

console.log('修改前:', {
  access: authData.token.access?.substring(0, 30) + '...',
  refresh: authData.token.refresh?.substring(0, 30) + '...'
});

// 设置为无效的Token（字段名是 access 和 refresh，不是 accessToken）
authData.token.access = 'invalid_access_token_xxxxxxxxx';
authData.token.refresh = 'invalid_refresh_token_xxxxxxxx';
authData.token.expiresAt = Date.now() - 1000;

storage.setItem(storageKey, JSON.stringify(authData));

console.log('修改后:', {
  access: authData.token.access,
  refresh: authData.token.refresh
});
console.log('✅ Token已设置为无效状态');
```

2. **点击任意菜单**触发请求

3. **预期结果**：
   - ✅ 显示提示："刷新令牌已过期，请重新登录"
   - ✅ 自动跳转到 `/login` 页面
   - ✅ sessionStorage/localStorage中的Token被清空

## 🐛 常见问题排查

### 问题1：Token刷新后还是跳转登录页

**可能原因**：
- refreshToken也过期了
- 后端刷新接口返回错误

**排查方法**：
1. 检查Network面板，查看 `POST /v1/auth/refresh-tokens` 的响应
2. 如果返回401，说明refreshToken过期，重新登录即可
3. 如果返回500，说明后端有问题，联系后端

### 问题2：没有触发自动刷新

**可能原因**：
- Token未真正过期
- 前端代码未正确检测过期

**排查方法**：
```javascript
// Console检查Token状态（兼容两种存储）
const storageKey = 'moses_auth_data';
const authData = sessionStorage.getItem(storageKey)
  ? JSON.parse(sessionStorage.getItem(storageKey))
  : JSON.parse(localStorage.getItem(storageKey));
console.log('Token过期时间:', new Date(authData.token.expiresAt));
console.log('当前时间:', new Date());
console.log('是否过期:', Date.now() > authData.token.expiresAt);
console.log('存储位置:', authData.token.storage);
```

### 问题3：Network看不到refresh请求

**可能原因**：
- 请求被浏览器缓存
- 拦截器配置有问题

**排查方法**：
1. 清空浏览器缓存
2. 勾选 Network 面板的 "Disable cache"
3. 刷新页面重新测试

### 问题4：并发场景下多次刷新

**可能原因**：
- 前端队列机制失效

**排查方法**：
1. 检查 Console 是否有 JavaScript 错误
2. 查看 `src/utils/request.js` 的 `isRefreshingToken` 标志
3. 联系前端开发排查
