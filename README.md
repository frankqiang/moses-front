# 铝箔退火炉车间MES系统

## 项目概述
这是一个基于Vue.js 2.x的铝箔退火炉车间MES系统，集成了Element UI、axios、权限控制等功能，提供车间生产管理、过程控制、物料追踪、质量管理和设备监控的完整解决方案。

## 系统功能模块

### 1. 主数据管理模块
管理系统运行所需的基础静态数据，确保数据的一致性和准确性，为其他模块提供数据支持。

#### 1.1 料框规格管理
维护车间使用的各种料框的物理规格、承载能力、适用范围等基础信息。
- 支持创建、编辑、查询和禁用料框规格
- 记录规格代码、名称、尺寸、最大载重、材质、适用产品类型、最大堆叠层数、供应商信息等
- 校验输入参数的合法性和规格代码的唯一性
- 启用/禁用状态管理
- 批量操作功能（批量删除、批量启用/禁用）
- 数据导入/导出功能（支持Excel导入导出和模板下载）

#### 1.2 铝箔产品管理
管理车间生产或处理的铝箔产品的基础信息，为生产计划和工艺控制提供数据支持。
- 支持创建、编辑、查询和状态变更产品信息
- 记录产品编码、名称、原材料类型、合金牌号、状态/硬度、规格（厚度、宽度）、单位重量等
- 支持关联退火工艺模板和质量标准
- 产品生命周期状态管理（试产/量产/停产）
- 批量操作功能（批量删除、批量状态变更）
- 数据导入/导出功能（支持Excel导入导出和模板下载）

#### 1.3 物料编码管理
定义和管理料框ID的生成规则及二维码内容，确保系统能够自动生成全局唯一的料框标识。
- 支持创建、编辑和查询编码规则
- 提供多种编码规则类型：纯数字流水号、前缀+流水号、自定义规则
- 支持配置流水号位数、起始值、步长等参数
- 支持配置二维码内容（仅包含料框ID/包含规格信息/完整物料信息）
- 支持配置二维码参数（尺寸、纠错级别）
- 支持设置默认规则，用于新增料框时自动生成编码
- 提供编码预览功能，直观展示生成的编码格式

#### 1.4 库位主数据管理
管理车间内所有库位的基础信息，为库存管理和物料流转提供位置数据支持。
- 支持创建、编辑、查询和状态管理（启用/禁用）库位信息
- 记录库位编码、名称、所属仓库、库位类型、位置描述、尺寸、容量等信息
- 支持库位容量可视化展示（使用进度条显示占用情况）
- 支持库位混放配置（是否允许不同物料混放）
- 提供多种库位类型：存储区、收货区、发货区、暂存区、质检区等
- 批量操作功能（批量删除、批量启用/禁用）
- 数据导入/导出功能（支持Excel导入导出和模板下载）

### 2. 库存管理模块
实时管理和追踪车间内所有物料（料框/料垛）的状态、位置和属性信息，确保物料流转可视化和可追溯。

#### 2.1 仓库管理
维护车间内各类仓库的基本信息和管理规则，为库位管理和库存控制提供基础。
- 支持创建、编辑、查询和状态管理（启用/禁用）仓库信息
- 记录仓库编码、名称、类型、位置、面积、负责人等基础信息
- 支持配置仓库管理规则（先进先出/先进后出/指定批次）
- 支持仓库容量监控和预警设置
- 支持仓库权限管理，控制用户对仓库的操作权限
- 提供仓库使用率统计和可视化展示
- 批量操作功能（批量删除、批量启用/禁用）
- 数据导入/导出功能（支持Excel导入导出和模板下载）

#### 2.2 库存查询（开发中）
提供多维度的库存信息查询功能，支持按物料、位置、状态等条件灵活查询。

#### 2.3 库存操作（开发中）
提供入库、出库、移库、盘点等库存操作功能，支持物料的全生命周期管理。

#### 2.4 库存报表（开发中）
提供库存统计、分析和预警功能，支持库存决策和优化。

### 3. 生产任务管理模块（开发中）
管理生产计划的下达、分解、排程和调度，确保生产任务有序、高效执行。

### 4. 执行与监控模块（开发中）
实时监控和控制生产过程的执行，确保按计划和工艺要求进行，并记录生产实绩数据。

### 5. 报表与看板模块（开发中）
提供数据可视化展示和分析功能，支持生产监控和管理决策。

## 全局组件

本项目提供了一系列全局可复用的组件，这些组件被设计为独立、高度可配置且易于使用。全局组件位于`src/components`目录下，可以在项目的任何页面中使用。最近，我们添加了Pagination分页组件，用于优化数据列表的分页展示和控制。

### Pagination 分页组件
系统提供了一个全局可复用的分页组件，用于数据列表的分页显示和控制。该组件封装了Element UI的el-pagination组件，并提供了更便捷的使用方式。

#### 组件特性
- 自动处理页码和每页条数的双向绑定
- 支持自定义分页布局和页码选项
- 提供页面自动滚动功能，切换页码后自动滚动到页面顶部
- 支持隐藏分页控件的功能

#### 使用方法
```vue
<template>
  <div class="app-container">
    <div class="data-list">
      <!-- 数据列表内容 -->
    </div>
    
    <pagination
      v-show="total>0"
      :total="total"
      :page.sync="listQuery.page"
      :limit.sync="listQuery.limit"
      @pagination="getList"
    />
  </div>
</template>

<script>
import Pagination from '@/components/Pagination'

export default {
  components: { Pagination },
  data() {
    return {
      total: 0,
      listQuery: {
        page: 1,
        limit: 20
      },
      list: []
    }
  },
  methods: {
    getList() {
      // 根据页码和每页条数获取数据
      // ...
    }
  }
}
</script>
```

#### 组件参数
| 参数 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| total | 总记录数 | Number | - |
| page | 当前页码 | Number | 1 |
| limit | 每页记录数 | Number | 20 |
| pageSizes | 每页显示个数选择器的选项 | Array | [10, 20, 30, 50] |
| layout | 组件布局 | String | 'total, sizes, prev, pager, next, jumper' |
| background | 是否为分页按钮添加背景色 | Boolean | true |
| autoScroll | 切换分页后是否自动滚动到顶部 | Boolean | true |
| hidden | 是否隐藏分页组件 | Boolean | false |

#### 事件
| 事件名称 | 说明 | 回调参数 |
| --- | --- | --- |
| pagination | 页码或每页条数改变时触发 | { page, limit } |

## 工具函数

本项目提供了多种实用工具函数，用于简化常见操作和提高开发效率。这些工具函数位于`src/utils`目录下，涵盖了请求处理、数据转换、权限验证等多个方面。最近，我们添加了scroll-to.js工具函数，用于实现页面平滑滚动效果，提升用户体验。

### scroll-to.js
提供平滑滚动页面的功能，使用缓动效果让滚动更自然，比浏览器默认的跳转更友好。

#### 功能特性
- 支持平滑滚动到指定位置
- 可自定义滚动动画持续时间
- 支持滚动完成后的回调函数
- 使用easeInOutQuad缓动函数实现自然的滚动效果

#### 使用方法
```js
import { scrollTo } from '@/utils/scroll-to'

// 滚动到页面顶部，动画持续800毫秒
scrollTo(0, 800)

// 滚动到指定位置，并在完成后执行回调
scrollTo(500, 600, () => {
  console.log('滚动完成')
})
```

#### 函数参数
| 参数 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| to | 目标滚动位置（像素） | Number | - |
| duration | 动画持续时间（毫秒） | Number | 500 |
| callback | 滚动完成后的回调函数 | Function | - |

### API和Mock目录结构规范

为确保代码组织一致性和可维护性，本项目采用基于业务模块的目录结构组织方式：

1. **API目录结构规范**
   - 所有API请求文件必须放置在对应的业务模块目录下
   - 例如：主数据管理模块的API应放在 `src/api/master-data/` 目录下
   - 禁止在API根目录直接创建业务相关的API文件

2. **Mock目录结构规范**
   - Mock目录结构必须与API目录结构保持一致
   - 例如：主数据管理模块的Mock数据应放在 `mock/master-data/` 目录下
   - 文件命名应与对应的API文件保持一致
   - **重要**: Mock文件必须使用CommonJS模块系统（require/module.exports），不可使用ES模块语法（import/export）
   - 正确示例：
     ```js
     const Mock = require('mockjs')
     // 导出为数组
     module.exports = [
       // API定义...
     ]
     ```

3. **开发流程**
   - 创建新模块时，先在mock和api目录下创建对应的模块目录
   - 在相应目录下开发模块功能
   - 确保导入路径正确引用了模块化的结构
   - 开发Mock数据文件时严格遵循CommonJS模块规范

4. **API URL路径规范**
   - 所有API路径必须以`/mes`作为前缀
   - 路径应按照业务模块组织，例如：`/mes/master-data/xxx`、`/mes/production/xxx`
   - 不要使用`/vue-admin-template`前缀
   - 正确示例：`/mes/master-data/storage-location/list`
   - 错误示例：`/master-data/storage-location/list`（缺少`/mes`前缀）

## 组件化架构

为保证代码质量和可维护性，本项目采用组件化架构模式，将复杂的功能页面拆分为多个小型、可复用的组件，并结合mixins管理业务逻辑。

### 组件拆分模式
每个功能模块按照以下结构组织：
```
module-name/
├── index.vue                 # 主页面（容器组件）
├── components/               # 子组件目录
│   ├── SearchForm.vue        # 搜索表单组件
│   ├── ActionBar.vue         # 操作按钮组件
│   ├── DataTable.vue         # 数据表格组件
│   ├── DetailForm.vue        # 详情/编辑表单组件
│   └── ImportDialog.vue      # 导入对话框组件（如需要）
└── mixins/                   # 混入目录
    ├── tableMixin.js         # 表格操作相关混入
    ├── formMixin.js          # 表单处理相关混入
    └── importExportMixin.js  # 导入导出相关混入（如需要）
```

### 架构优势
- **模块化设计**：每个组件负责单一功能，降低代码复杂度
- **可复用性**：拆分的组件可在其他模块中复用
- **易于维护**：小组件更易于理解和调试
- **协作开发**：团队可并行开发不同组件
- **性能优化**：更精细的组件渲染控制

详细的组件化开发规范请参考项目根目录的`07-component-architecture.md`文件。

## 使用说明

### 料框规格管理
1. 进入系统后，从左侧菜单选择"主数据管理" -> "料框规格管理"
2. 页面上方可以按规格代码、名称和状态搜索已有料框规格
3. 点击"新增料框规格"按钮可以创建新的料框规格
4. 在列表中可以对每条记录进行编辑或状态切换操作
5. 使用批量操作功能可对多条记录同时操作：
   - 选中记录后可进行批量删除、批量启用/禁用操作
6. 使用导入/导出功能可进行数据交换：
   - 下载导入模板：获取标准Excel导入模板
   - 导入数据：上传填写好的Excel文件批量导入数据
   - 导出数据：将当前筛选条件下的数据导出为Excel文件

### 铝箔产品管理
1. 从左侧菜单选择"主数据管理" -> "铝箔产品管理"
2. 页面上方可以按产品编码、名称、合金牌号和产品状态搜索产品
3. 点击"新增产品"按钮可以创建新的铝箔产品记录
4. 在产品列表中可以对每条记录进行以下操作：
   - 编辑：修改产品基本信息和关联的工艺模板、质量标准
   - 状态变更：可将产品设置为"试产"、"量产"或"停产"状态
5. 关联工艺模板和质量标准列显示格式为"名称(+数量)"，点击可查看完整列表
6. 使用批量操作功能可对多条记录同时操作：
   - 选中记录后可进行批量删除、批量状态变更操作
7. 使用导入/导出功能可进行数据交换：
   - 下载导入模板：获取标准Excel导入模板
   - 导入数据：上传填写好的Excel文件批量导入数据
   - 导出数据：将当前筛选条件下的数据导出为Excel文件

### 物料编码管理
1. 从左侧菜单选择"主数据管理" -> "物料编码管理"
2. 页面上方可以按规则名称和规则类型搜索编码规则
3. 点击"新增编码规则"按钮可以创建新的编码规则
4. 在规则列表中可以对每条记录进行以下操作：
   - 编辑：修改规则名称、类型、参数等信息
   - 设为默认：将规则设置为系统默认规则，用于新增料框时自动生成编码
5. 创建或编辑规则时可以：
   - 选择规则类型（纯数字流水号/前缀+流水号/自定义规则）
   - 配置流水号参数（位数、起始值、步长）
   - 配置二维码内容和参数（尺寸、纠错级别）
   - 查看编码预览，直观了解生成的编码格式

### 库位主数据管理
1. 从左侧菜单选择"主数据管理" -> "库位主数据管理"
2. 页面上方可以按库位编码、库位名称、所属仓库、库位类型和状态搜索库位
3. 点击"新增库位"按钮可以创建新的库位记录
4. 在库位列表中可以对每条记录进行以下操作：

   - 绿色：占用率<70%

6. 使用批量操作功能可对多条记录同时操作：
   - 选中记录后可进行批量删除、批量启用/禁用操作
7. 使用导入/导出功能可进行数据交换：
   - 下载导入模板：获取标准Excel导入模板
   - 导入数据：上传填写好的Excel文件批量导入数据
   - 导出数据：将当前筛选条件下的数据导出为Excel文件

### 仓库管理
1. 从左侧菜单选择"库存管理" -> "仓库管理"
2. 页面上方可以按仓库编码、名称、类型和状态搜索仓库
3. 点击"新增仓库"按钮可以创建新的仓库记录
4. 在仓库列表中可以对每条记录进行以下操作：
   - 编辑：修改仓库基本信息、管理规则等
   - 状态切换：可将仓库设置为"启用"或"禁用"状态
   - 查看详情：显示仓库详细信息，包括使用率、库位分布等
   - 权限设置：配置用户对仓库的操作权限
5. 仓库容量使用率以进度条形式直观显示，不同使用率显示不同颜色：
   - 绿色：使用率<70%
   - 黄色：使用率70%-90%
   - 红色：使用率>90%
6. 使用批量操作功能可对多条记录同时操作：
   - 选中记录后可进行批量删除、批量启用/禁用操作
7. 使用导入/导出功能可进行数据交换：
   - 下载导入模板：获取标准Excel导入模板
   - 导入数据：上传填写好的Excel文件批量导入数据
   - 导出数据：将当前筛选条件下的数据导出为Excel文件
8. 仓库统计面板提供以下信息：
   - 仓库总数和启用/禁用数量
   - 各类型仓库分布比例
   - 整体使用率和空间利用率
   - 近期库存变动趋势
