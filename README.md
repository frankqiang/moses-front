# 铝箔退火炉车间MES系统

## 项目概述
这是一个基于Vue.js 2.x的铝箔退火炉车间MES系统，集成了Element UI、axios、权限控制等功能，提供车间生产管理、过程控制、物料追踪、质量管理和设备监控的完整解决方案。

## 系统功能模块

### 1. 主数据管理模块
管理系统运行所需的基础静态数据，确保数据的一致性和准确性，为其他模块提供数据支持。

#### 1.1 料框规格管理
维护车间使用的各种料框的物理规格、承载能力、适用范围等基础信息。
- 支持创建、编辑、查询和禁用料框规格
- 记录规格代码、名称、尺寸、最大载重、材质、适用产品类型、最大堆叠层数、供应商信息等
- 校验输入参数的合法性和规格代码的唯一性
- 启用/禁用状态管理
- 批量操作功能（批量删除、批量启用/禁用）
- 数据导入/导出功能（支持Excel导入导出和模板下载）

#### 1.2 铝箔产品管理
管理车间生产或处理的铝箔产品的基础信息，为生产计划和工艺控制提供数据支持。
- 支持创建、编辑、查询和状态变更产品信息
- 记录产品编码、名称、原材料类型、合金牌号、状态/硬度、规格（厚度、宽度）、单位重量等
- 支持关联退火工艺模板和质量标准
- 产品生命周期状态管理（试产/量产/停产）
- 批量操作功能（批量删除、批量状态变更）
- 数据导入/导出功能（支持Excel导入导出和模板下载）

### 2. 库存管理模块（开发中）
实时管理和追踪车间内所有物料（料框/料垛）的状态、位置和属性信息。

### 3. 生产任务管理模块（开发中）
管理生产计划的下达、分解、排程和调度，确保生产任务有序、高效执行。

### 4. 执行与监控模块（开发中）
实时监控和控制生产过程的执行，确保按计划和工艺要求进行，并记录生产实绩数据。

### 5. 报表与看板模块（开发中）
提供数据可视化展示和分析功能，支持生产监控和管理决策。

## 技术栈
- 前端框架：Vue.js 2.x
- UI组件库：Element UI
- 状态管理：Vuex
- 路由管理：Vue Router
- HTTP请求：Axios
- 模拟数据：Mock.js

### API和Mock目录结构规范

为确保代码组织一致性和可维护性，本项目采用基于业务模块的目录结构组织方式：

1. **API目录结构规范**
   - 所有API请求文件必须放置在对应的业务模块目录下
   - 例如：主数据管理模块的API应放在 `src/api/master-data/` 目录下
   - 禁止在API根目录直接创建业务相关的API文件

2. **Mock目录结构规范**
   - Mock目录结构必须与API目录结构保持一致
   - 例如：主数据管理模块的Mock数据应放在 `mock/master-data/` 目录下
   - 文件命名应与对应的API文件保持一致

3. **开发流程**
   - 创建新模块时，先在mock和api目录下创建对应的模块目录
   - 在相应目录下开发模块功能
   - 确保导入路径正确引用了模块化的结构

## 组件化架构

为保证代码质量和可维护性，本项目采用组件化架构模式，将复杂的功能页面拆分为多个小型、可复用的组件，并结合mixins管理业务逻辑。

### 组件拆分模式
每个功能模块按照以下结构组织：
```
module-name/
├── index.vue                 # 主页面（容器组件）
├── components/               # 子组件目录
│   ├── SearchForm.vue        # 搜索表单组件
│   ├── ActionBar.vue         # 操作按钮组件
│   ├── DataTable.vue         # 数据表格组件
│   ├── DetailForm.vue        # 详情/编辑表单组件
│   └── ImportDialog.vue      # 导入对话框组件（如需要）
└── mixins/                   # 混入目录
    ├── tableMixin.js         # 表格操作相关混入
    ├── formMixin.js          # 表单处理相关混入
    └── importExportMixin.js  # 导入导出相关混入（如需要）
```

### 架构优势
- **模块化设计**：每个组件负责单一功能，降低代码复杂度
- **可复用性**：拆分的组件可在其他模块中复用
- **易于维护**：小组件更易于理解和调试
- **协作开发**：团队可并行开发不同组件
- **性能优化**：更精细的组件渲染控制

详细的组件化开发规范请参考项目根目录的`07-component-architecture.md`文件。

## 使用说明

### 料框规格管理
1. 进入系统后，从左侧菜单选择"主数据管理" -> "料框规格管理"
2. 页面上方可以按规格代码、名称和状态搜索已有料框规格
3. 点击"新增料框规格"按钮可以创建新的料框规格
4. 在列表中可以对每条记录进行编辑或状态切换操作
5. 使用批量操作功能可对多条记录同时操作：
   - 选中记录后可进行批量删除、批量启用/禁用操作
6. 使用导入/导出功能可进行数据交换：
   - 下载导入模板：获取标准Excel导入模板
   - 导入数据：上传填写好的Excel文件批量导入数据
   - 导出数据：将当前筛选条件下的数据导出为Excel文件

### 铝箔产品管理
1. 从左侧菜单选择"主数据管理" -> "铝箔产品管理"
2. 页面上方可以按产品编码、名称、合金牌号和产品状态搜索产品
3. 点击"新增产品"按钮可以创建新的铝箔产品记录
4. 在产品列表中可以对每条记录进行以下操作：
   - 编辑：修改产品基本信息和关联的工艺模板、质量标准
   - 状态变更：可将产品设置为"试产"、"量产"或"停产"状态
5. 关联工艺模板和质量标准列显示格式为"名称(+数量)"，点击可查看完整列表
6. 使用批量操作功能可对多条记录同时操作：
   - 选中记录后可进行批量删除、批量状态变更操作
7. 使用导入/导出功能可进行数据交换：
   - 下载导入模板：获取标准Excel导入模板
   - 导入数据：上传填写好的Excel文件批量导入数据
   - 导出数据：将当前筛选条件下的数据导出为Excel文件
