# 铝箔退火炉车间MES系统

## 项目概述
这是一个基于Vue.js 2.x的铝箔退火炉车间MES系统，集成了Element UI、axios、权限控制等功能，提供车间生产管理、过程控制、物料追踪、质量管理和设备监控的完整解决方案。

## 系统功能模块

### 1. 主数据管理模块
管理系统运行所需的基础静态数据，确保数据的一致性和准确性，为其他模块提供数据支持。

#### 1.1 料框规格管理
维护车间使用的各种料框的物理规格、承载能力、适用范围等基础信息。
- 支持创建、编辑、查询和禁用料框规格
- 记录规格代码、名称、尺寸、最大载重、材质、适用产品类型、最大堆叠层数、供应商信息等
- 校验输入参数的合法性和规格代码的唯一性
- 启用/禁用状态管理
- 批量操作功能（批量删除、批量启用/禁用）
- 数据导入/导出功能（支持Excel导入导出和模板下载）

#### 1.2 铝箔产品管理
管理车间生产或处理的铝箔产品的基础信息，为生产计划和工艺控制提供数据支持。
- 支持创建、编辑、查询和状态变更产品信息
- 记录产品编码、名称、原材料类型、合金牌号、状态/硬度、规格（厚度、宽度）、单位重量等
- 支持关联退火工艺模板和质量标准
- 产品生命周期状态管理（试产/量产/停产）
- 批量操作功能（批量删除、批量状态变更）
- 数据导入/导出功能（支持Excel导入导出和模板下载）

#### 1.3 物料编码管理
定义和管理料框ID的生成规则及二维码内容，确保系统能够自动生成全局唯一的料框标识。
- 支持创建、编辑和查询编码规则
- 提供多种编码规则类型：纯数字流水号、前缀+流水号、自定义规则
- 支持配置流水号位数、起始值、步长等参数
- 支持配置二维码内容（仅包含料框ID/包含规格信息/完整物料信息）
- 支持配置二维码参数（尺寸、纠错级别）
- 支持设置默认规则，用于新增料框时自动生成编码
- 提供编码预览功能，直观展示生成的编码格式

#### 1.4 设备主数据管理
管理车间内所有生产和辅助设备的基础信息，为设备监控和维护提供数据支持。
- 支持创建、编辑、查询和状态管理（启用/禁用）设备信息
- 记录设备编码、名称、类型、型号、规格、制造商、购置日期、位置等信息
- 支持设备状态管理（正常/维修中/停用）
- 支持设备使用状态追踪和变更历史记录
- 提供设备详情查看功能，包括技术参数、维护记录和使用状况
- 支持批量操作功能（批量删除、批量启用/禁用）
- 数据导入/导出功能（支持Excel导入导出和模板下载）
- 采用全局组件实现统一的操作界面和状态显示

#### 1.5 库位主数据管理
管理车间内所有库位的基础信息，为库存管理和物料流转提供位置数据支持。
- 支持创建、编辑、查询和状态管理（启用/禁用）库位信息
- 记录库位编码、名称、所属仓库、库位类型、位置描述、尺寸、容量等信息
- 支持库位容量可视化展示（使用进度条显示占用情况）
- 支持库位混放配置（是否允许不同物料混放）
- 提供多种库位类型：存储区、收货区、发货区、暂存区、质检区等
- 批量操作功能（批量删除、批量启用/禁用）
- 数据导入/导出功能（支持Excel导入导出和模板下载）

### 2. 库存管理模块
实时管理和追踪车间内所有物料（料框/料垛）的状态、位置和属性信息，确保物料流转可视化和可追溯。

#### 2.1 仓库管理
维护车间内各类仓库的基本信息和管理规则，为库位管理和库存控制提供基础。
- 支持创建、编辑、查询和状态管理（启用/禁用）仓库信息
- 记录仓库编码、名称、类型、位置、面积、负责人等基础信息
- 支持配置仓库管理规则（先进先出/先进后出/指定批次）
- 支持仓库容量监控和预警设置
- 支持仓库权限管理，控制用户对仓库的操作权限
- 提供仓库使用率统计和可视化展示
- 批量操作功能（批量删除、批量启用/禁用）
- 数据导入/导出功能（支持Excel导入导出和模板下载）

#### 2.2 库存查询（开发中）
提供多维度的库存信息查询功能，支持按物料、位置、状态等条件灵活查询。

#### 2.3 库存操作（开发中）
提供入库、出库、移库、盘点等库存操作功能，支持物料的全生命周期管理。

#### 2.4 库存报表（开发中）
提供库存统计、分析和预警功能，支持库存决策和优化。

### 3. 生产任务管理模块（开发中）
管理生产计划的下达、分解、排程和调度，确保生产任务有序、高效执行。

### 4. 执行与监控模块（开发中）
实时监控和控制生产过程的执行，确保按计划和工艺要求进行，并记录生产实绩数据。

### 5. 报表与看板模块（开发中）
提供数据可视化展示和分析功能，支持生产监控和管理决策。

## 技术栈
- 前端框架：Vue.js 2.x
- UI组件库：Element UI
- 状态管理：Vuex
- 路由管理：Vue Router
- HTTP请求：Axios
- 模拟数据：Mock.js

## 使用说明

### 料框规格管理
1. 进入系统后，从左侧菜单选择"主数据管理" -> "料框规格管理"
2. 页面上方可以按规格代码、名称和状态搜索已有料框规格
3. 点击"新增料框规格"按钮可以创建新的料框规格
4. 在列表中可以对每条记录进行编辑或状态切换操作
5. 使用批量操作功能可对多条记录同时操作：
   - 选中记录后可进行批量删除、批量启用/禁用操作
6. 使用导入/导出功能可进行数据交换：
   - 下载导入模板：获取标准Excel导入模板
   - 导入数据：上传填写好的Excel文件批量导入数据
   - 导出数据：将当前筛选条件下的数据导出为Excel文件

### 铝箔产品管理
1. 从左侧菜单选择"主数据管理" -> "铝箔产品管理"
2. 页面上方可以按产品编码、名称、合金牌号和产品状态搜索产品
3. 点击"新增产品"按钮可以创建新的铝箔产品记录
4. 在产品列表中可以对每条记录进行以下操作：
   - 编辑：修改产品基本信息和关联的工艺模板、质量标准
   - 状态变更：可将产品设置为"试产"、"量产"或"停产"状态
5. 关联工艺模板和质量标准列显示格式为"名称(+数量)"，点击可查看完整列表
6. 使用批量操作功能可对多条记录同时操作：
   - 选中记录后可进行批量删除、批量状态变更操作
7. 使用导入/导出功能可进行数据交换：
   - 下载导入模板：获取标准Excel导入模板
   - 导入数据：上传填写好的Excel文件批量导入数据
   - 导出数据：将当前筛选条件下的数据导出为Excel文件

### 物料编码管理
1. 从左侧菜单选择"主数据管理" -> "物料编码管理"
2. 页面上方可以按规则名称和规则类型搜索编码规则
3. 点击"新增编码规则"按钮可以创建新的编码规则
4. 在规则列表中可以对每条记录进行以下操作：
   - 编辑：修改规则名称、类型、参数等信息
   - 设为默认：将规则设置为系统默认规则，用于新增料框时自动生成编码
5. 创建或编辑规则时可以：
   - 选择规则类型（纯数字流水号/前缀+流水号/自定义规则）
   - 配置流水号参数（位数、起始值、步长）
   - 配置二维码内容和参数（尺寸、纠错级别）
   - 查看编码预览，直观了解生成的编码格式

### 设备主数据管理
1. 从左侧菜单选择"主数据管理" -> "设备管理"
2. 页面上方可以按设备编码、设备名称、设备类型和状态搜索设备
3. 点击"新增设备"按钮可以创建新的设备记录
4. 在设备列表中可以对每条记录进行以下操作：

   - 状态切换：可将设备设置为"启用"或"禁用"状态
5. 设备状态以标签形式显示，不同状态显示不同颜色：
   - 绿色：正常状态
   - 黄色：维修中状态

6. 使用批量操作功能可对多条记录同时操作：

7. 使用导入/导出功能可进行数据交换：
