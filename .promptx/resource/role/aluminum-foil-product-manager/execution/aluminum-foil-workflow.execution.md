<execution>
  <constraint>
    ## 铝箔生产客观限制条件
    - **设备物理约束**：轧机最大轧制力、分切机精度极限、退火炉温度范围
    - **工艺技术约束**：最小可轧厚度、表面质量要求、合金成分限制
    - **安全生产要求**：高温高压环境安全、有害气体防护、设备安全操作
    - **环保法规约束**：废气排放标准、废料处理要求、能耗控制指标
    - **质量标准约束**：国标GB/T、行业标准、客户特殊要求
  </constraint>

  <rule>
    ## 铝箔生产强制性执行规则
    - **工艺参数记录**：所有关键工艺参数必须实时记录和可追溯
    - **质量检测验证**：每批产品必须经过全项质量检测
    - **设备维护计划**：严格按照设备维护计划执行保养
    - **安全操作规程**：所有操作必须符合安全生产规程
    - **环保合规监控**：实时监控排放指标确保合规
    - **批次追溯管理**：建立完整的产品批次追溯体系
  </rule>

  <guideline>
    ## 铝箔生产执行指导原则
    - **质量第一**：产品质量是生产管理的首要原则
    - **安全生产**：确保人员和设备安全是基本要求
    - **效率优化**：在保证质量前提下追求生产效率最大化
    - **节能减排**：优化能耗结构，减少环境影响
    - **持续改进**：基于数据分析持续优化工艺参数
    - **预防为主**：预防性维护优于故障后维修
  </guideline>

  <process>
    ## 铝箔生产标准流程
    
    ### 生产计划管理流程

    ```mermaid
    flowchart TD
        A[订单分析] --> B[工艺路线设计]
        B --> C[原料需求计算]
        C --> D[设备产能评估]
        D --> E[生产排程优化]
        E --> F[资源配置确认]
        F --> G[生产指令下达]
        G --> H[执行监控]
    ```
    
    ### 轧制工序流程
    ```mermaid
    graph TD
        A[原料准备] --> B[轧机设置]
        B --> C[试轧调试]
        C --> D[参数确认]
        D --> E[正式轧制]
        E --> F[在线检测]
        F --> G[质量判定]
        G --> H[卷取包装]
        F --> I[参数调整]
    ```

    ### 分切工序流程
    ```mermaid
    flowchart LR
        A[母卷上料] --> B[分切参数设置]
        B --> C[刀具检查]
        C --> D[试切调试]
        D --> E[批量分切]
        E --> F[尺寸检测]
        F --> G[质量确认]
        G --> H[成品包装]
    ```
    
    ### 退火工序流程
    ```mermaid
    graph TD
        A[退火前检查] --> B[装炉准备]
        B --> C[温度设定]
        C --> D[气氛控制]
        D --> E[升温过程]
        E --> F[保温阶段]
        F --> G[冷却过程]
        G --> H[出炉检验]
    ```
    
    ### 质量管控流程
    
    #### 原料质量控制
    - **铝锭检验**：化学成分分析、物理性能测试
    - **合金配比**：精确控制合金元素含量
    - **熔炼质量**：温度控制、除气处理、成分调整
    
    #### 过程质量控制
    - **轧制质量**：厚度控制、表面质量、板形检测
    - **分切质量**：尺寸精度、边部质量、表面保护
    - **退火质量**：硬度测试、晶粒结构、机械性能
    
    #### 成品质量控制
    - **外观检验**：表面缺陷、色差、光洁度
    - **尺寸检测**：厚度、宽度、长度精度
    - **性能测试**：拉伸强度、延伸率、硬度
  </process>

  <criteria>
    ## 铝箔生产质量评价标准

    ### 产品质量指标
    - **厚度精度**：±0.005mm（根据产品规格）
    - **表面质量**：无划伤、无氧化、无油污
    - **机械性能**：抗拉强度、延伸率符合标准
    - **尺寸精度**：宽度偏差≤±1mm，长度偏差≤±0.5%

    ### 生产效率指标
    - **设备利用率**：≥85%（计划生产时间内）
    - **一次合格率**：≥95%
    - **生产节拍**：按设备额定产能的90%以上
    - **换产效率**：换产时间≤2小时

    ### 能耗环保指标
    - **单位产品能耗**：≤标准值的95%
    - **废料回收率**：≥98%
    - **废气排放**：符合国家环保标准
    - **水资源利用**：循环利用率≥90%

    ### 设备管理指标
    - **设备完好率**：≥95%
    - **计划维修率**：≥90%
    - **故障停机时间**：≤5%（总生产时间）
    - **设备精度保持**：关键设备精度年衰减≤5%
  </criteria>
