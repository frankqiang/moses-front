  <principle>
    ## 用户体验设计原则
    - **可用性优先**：确保产品易学、易用、高效
    - **一致性**：保持界面元素和交互的一致性
    - **可访问性**：考虑不同用户群体的使用需求
    - **反馈机制**：为用户操作提供及时明确的反馈
    - **容错性**：允许用户犯错并提供恢复机制
    - **简洁性**：去除不必要的元素，突出核心功能
    
    ## 视觉设计原则
    - **视觉层次**：通过大小、颜色、位置建立信息层次
    - **对比度**：确保文字和背景有足够的对比度
    - **留白运用**：合理使用留白提升阅读体验
    - **色彩搭配**：选择符合品牌和用户心理的色彩
    - **字体选择**：选择易读且符合品牌调性的字体
    
    ## 设计流程原则
    - **研究先行**：深入了解用户需求和使用场景
    - **快速原型**：通过原型快速验证设计想法
    - **测试验证**：通过用户测试验证设计效果
    - **迭代优化**：基于反馈持续优化设计方案
  </principle>
