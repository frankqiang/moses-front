  ## Vue Admin Template项目设计约束
  - **Element UI组件库**：基于Element UI的组件设计语言和视觉规范
  - **管理后台特性**：面向B端用户的管理系统界面设计
  - **数据密集型界面**：大量表格、表单、图表的信息展示
  - **权限系统集成**：不同权限级别的界面状态设计
  - **响应式要求**：适配桌面端和平板设备的响应式设计
  - **主题定制**：支持主题色彩和样式的定制化
  
  ## Element UI设计系统约束
  - **组件规范**：遵循Element UI的组件使用规范和最佳实践
  - **色彩系统**：基于Element UI的色彩体系进行扩展
  - **字体系统**：使用Element UI推荐的字体层级和规范
  - **间距系统**：遵循Element UI的间距和布局规范
  - **图标系统**：使用Element UI图标库或保持风格一致的自定义图标
  - **交互模式**：遵循Element UI的交互模式和用户习惯
  
  ## 管理后台UI设计特点
  - **信息密度高**：需要在有限空间内展示大量信息
  - **操作效率优先**：界面设计以提高操作效率为主要目标
  - **功能导向**：界面布局以功能逻辑为主导
  - **专业用户**：面向有一定专业背景的用户群体
  - **长时间使用**：考虑用户长时间使用的视觉疲劳问题
  - **多任务处理**：支持用户同时处理多个任务的界面设计
  
  ## 前端技术对设计的影响
  - **CSS Grid/Flexbox**：利用现代CSS布局技术优化界面布局
  - **CSS变量**：使用CSS变量实现主题切换和样式定制
  - **动画性能**：考虑CSS动画和过渡效果的性能影响
  - **SVG图标**：使用SVG格式图标保证清晰度和可缩放性
  - **字体加载**：考虑Web字体加载对页面性能的影响
  - **图片优化**：使用WebP等现代图片格式优化加载速度
  
  ## 用户体验设计原则
  - **认知负荷最小化**：减少用户的认知负担，简化操作流程
  - **一致性原则**：保持界面元素、交互模式、视觉风格的一致性
  - **反馈原则**：为用户的每个操作提供明确的反馈
  - **容错原则**：允许用户犯错并提供简单的恢复机制
  - **效率原则**：优化常用功能的操作路径，提高使用效率
  - **可访问性**：确保界面对不同能力的用户都是可访问的
  
  ## 设计系统建设
  - **组件库建设**：建立可复用的UI组件库
  - **设计令牌**：定义颜色、字体、间距等设计令牌
  - **模式库**：建立常用的设计模式和最佳实践
  - **文档规范**：维护详细的设计规范文档
  - **版本管理**：建立设计系统的版本管理机制
  - **协作流程**：建立设计师与开发者的协作流程
  
  ## 移动端适配考虑
  - **触摸友好**：按钮和可点击区域满足最小触摸尺寸
  - **手势支持**：支持常见的移动端手势操作
  - **性能优化**：考虑移动设备的性能限制
  - **网络环境**：考虑移动网络环境下的加载体验
  - **屏幕适配**：适配不同尺寸和分辨率的移动设备
  - **输入方式**：优化移动端的输入体验
  
  ## 数据可视化设计
  - **图表选择**：根据数据类型选择合适的图表类型
  - **色彩编码**：使用色彩有效传达数据信息
  - **交互设计**：设计直观的数据探索交互方式
  - **响应式图表**：确保图表在不同设备上的可读性
  - **性能考虑**：大数据量图表的渲染性能优化
  - **无障碍**：确保数据可视化对视觉障碍用户的可访问性
