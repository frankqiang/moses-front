## ⚠️ 注意事项

### 1. 常量使用原则

- ✅ **推荐**: 始终使用常量（如 `STACK_STATUS.ACTIVE`）
- ❌ **禁止**: 硬编码字符串（如 `'ACTIVE'` 或 `'活动中'`）

### 2. 向后兼容性

- ⚠️ **不兼容**: 英文枚举值（如 `'ACTIVE'`）不再有效
- ✅ **兼容**: 中文值（如 `'活动中'`）从接口文档发布之日起生效

### 3. URL 参数编码

- ✅ **自动处理**: axios 会自动对中文参数进行 URL 编码
- ✅ **无需手动**: 不需要手动调用 `encodeURIComponent()`

### 4. 状态判断

```javascript
// ✅ 正确：使用常量
if (stack.status === STACK_STATUS.ACTIVE) { }

// ✅ 也可以：直接比较中文（但不推荐，不利于维护）
if (stack.status === '活动中') { }

// ❌ 错误：使用英文值
if (stack.status === 'ACTIVE') { }
```
