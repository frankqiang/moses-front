# Moses API 料框管理模块接口文档

## 概述

本文档详细说明了 Moses API 料框管理模块的所有接口，包括请求方法、路径、参数、请求和响应数据结构、功能描述、错误码和返回示例。**本文档严格基于实际代码实现编写**，确保前端开发人员能够准确对接。

## 🚨 **重要提醒**

**本文档基于代码分析编写，在前端集成前必须通过实际调用接口验证所有响应结构和字段！**

### API 基础信息

- **基础 URL**: `http://localhost:3000/v1` (开发环境)
- **API 版本**: v1
- **认证方式**: JWT Bearer Token
- **数据格式**: JSON
- **字符编码**: UTF-8
- **Content-Type**: application/json

### Swagger 文档

项目已集成 Swagger 文档，可通过以下地址访问：

- **开发环境**: http://localhost:3000/v1/docs
- **在线文档**: 提供完整的 API 接口说明、参数定义和示例

### 权限约定

- **inv.bin.manage**: 料框管理权限，可执行料框注册、批量注册等写操作
- **inv.bin.view**: 料框查看权限，可执行料框列表查询、详情查询、状态历史查询等读操作
- **inv.bin.status-update**: 料框状态更新权限，可执行料框状态变更操作

## 统一响应格式

### 成功响应格式

所有成功的 API 调用都会返回以下统一格式：

```json
{
  "success": true,
  "data": {
    // 具体的业务数据，根据接口而不同
  },
  "message": "操作成功的描述信息",
  "meta": {
    "timestamp": "2024-01-20T10:30:00.000Z",
    "requestId": "req-1234567890-abcdef",
    "version": "v1"
  }
}
```

### 错误响应格式

所有错误的 API 调用都会返回以下统一格式：

```json
{
  "success": false,
  "error": {
    "code": "ERROR_CODE",
    "message": "用户友好的错误描述",
    "details": {
      "field": "发生错误的字段名（可选）",
      "value": "错误的字段值（可选）",
      "retryAfter": 300,
      "traceId": "req-1234567890-abcdef"
    }
  },
  "meta": {
    "timestamp": "2024-01-20T10:30:00.000Z",
    "requestId": "req-1234567890-abcdef",
    "version": "v1"
  }
}
```

**响应字段说明**：

- `success`: 布尔值，表示请求是否成功
- `data`: 成功时包含业务数据，失败时为 null
- `error`: 失败时包含错误信息，成功时为 null
- `message`: 成功时的操作描述
- `error.code`: 标准化的错误码，用于程序化处理
- `error.message`: 用户友好的错误描述，可直接展示给用户
- `error.details`: 可选的错误详细信息
- `meta`: 元数据信息，包含时间戳、请求 ID 和版本号

## 料框业务流程说明

### 料框生命周期概述

```
步骤1：料框注册 → 状态：待入库退火
   ↓
步骤2：入库登记 → 状态：待退火
   ↓
步骤3：退火计划生成 → 状态：待备料
   ↓
步骤4：物流移动 → 状态：待装炉
   ↓
步骤5：装炉操作 → 状态：装炉中 → 退火中
   ↓
步骤6：退火完成 → 状态：待出炉 → 已退火
   ↓
步骤7：检验环节 → 状态：待检验 → 已检验合格/已检验不合格
   ↓
步骤8：出库操作 → 状态：待出库 → 已出库 → 空闲（循环使用）
```

### 料框状态列表

⚠️ **重要说明**：接口传参时必须使用**中文状态值**，而非英文枚举常量名！

| 状态值（接口传参） | 常量名（仅供参考）        | 说明                               |
| ------------------ | ------------------------- | ---------------------------------- |
| 空闲               | IDLE                      | 料框可重新使用                     |
| 待入库退火         | PENDING_ANNEALING_STORAGE | 料框注册后的初始状态               |
| 待退火             | WAITING_ANNEALING         | 已入库，等待退火计划               |
| 待备料             | WAITING_PREPARATION       | 已有退火计划，等待备料             |
| 待装炉             | WAITING_LOADING           | 备料完成，等待装炉                 |
| 装炉中             | LOADING                   | 正在装炉操作                       |
| 退火中             | ANNEALING                 | 正在进行退火处理                   |
| 待出炉             | WAITING_UNLOAD            | 退火完成，等待出炉                 |
| 已退火             | ANNEALED                  | 出炉完成                           |
| 待检验             | WAITING_INSPECTION        | 等待质检                           |
| 已检验合格         | INSPECTED_QUALIFIED       | 质检合格                           |
| 已检验不合格       | INSPECTED_UNQUALIFIED     | 质检不合格，可能需要重新退火或报废 |
| 待出库             | WAITING_OUTBOUND          | 等待出库操作                       |
| 已出库             | OUTBOUND                  | 已完成出库                         |

### 状态触发类型列表

⚠️ **重要说明**：接口传参时必须使用**中文触发类型值**，而非英文枚举常量名！

| 触发类型值（接口传参） | 常量名（仅供参考） | 说明                 | 适用场景          |

## 料框接口详细说明

### 1. 料框注册

**接口路径**: `POST /v1/inv/bins`

**功能描述**: 注册新料框，记录料框基本信息并设置初始状态为"待入库退火"（PENDING_ANNEALING_STORAGE）。支持自动生成料框编号或使用扫码录入的编号。料框编号格式为：LK-YYYYMMDD-XXXX（如：LK-20250110-0001）。

**认证要求**: 需要 Bearer Token

**权限要求**: `inv.bin.manage`

**请求头**:

```
Authorization: Bearer <access_token>
Content-Type: application/json
```

**请求参数**:

| 参数名             | 类型   | 必填 | 限制                             | 描述                       | 示例                                 |
| ------------------ | ------ | ---- | -------------------------------- | -------------------------- | ------------------------------------ |
| binCode            | string | 否   | 格式：LK-YYYYMMDD-XXXX，长度1-50 | 料框编号，不提供则自动生成 | LK-20250110-0001                     |
| binSpecificationId | string | 是   | UUID格式                         | 料框规格ID                 | 123e4567-e89b-12d3-a456-426614174000 |
| productId          | string | 是   | UUID格式                         | 铝箔产品ID                 | 223e4567-e89b-12d3-a456-426614174000 |
| productCode        | string | 是   | 长度1-100字符                    | 产品代码                   | AF-1060-O-0.05x500                   |
| batchNumber        | string | 否   | 长度最大100字符                  | 批次号                     | BATCH-2025-001                       |
| weight             | number | 是   | 正数，最多3位小数                | 重量(kg)                   | 250.5                                |
| currentLocationId  | string | 否   | UUID格式                         | 初始位置ID                 | 323e4567-e89b-12d3-a456-426614174000 |
| remarks            | string | 否   | 长度最大500字符                  | 备注                       | 入库登记                             |

### 2. 批量注册料框

**接口路径**: `POST /v1/inv/bins/batch`

**功能描述**: 批量注册多个料框，使用事务确保原子性。如果部分料框注册失败，会返回详细的成功和失败记录。此接口适用于批量导入料框数据的场景。

**认证要求**: 需要 Bearer Token

**权限要求**: `inv.bin.manage`

**请求头**:

```
Authorization: Bearer <access_token>
Content-Type: application/json
```

**请求参数**:

| 参数名 | 类型  | 必填 | 限制                            | 描述         | 示例       |
| ------ | ----- | ---- | ------------------------------- | ------------ | ---------- |
| bins   | array | 是   | 至少1个元素，每个元素为料框对象 | 料框数据数组 | 见下方示例 |

**料框对象字段**（与单个注册接口相同）:

### 3. 料框列表查询

**接口路径**: `GET /v1/inv/bins`

**功能描述**: 分页查询料框列表，支持多条件筛选和排序。可按状态、产品代码、批次号、规格ID、位置ID、料垛ID、注册时间范围等条件进行筛选，也支持关键词搜索（搜索料框编号、产品代码、批次号）。

**认证要求**: 需要 Bearer Token

**权限要求**: `inv.bin.view`

**请求头**:

```
Authorization: Bearer <access_token>
```

**查询参数**:

| 参数名             | 类型   | 必填 | 限制                       | 描述                                     | 示例                                 |
| ------------------ | ------ | ---- | -------------------------- | ---------------------------------------- | ------------------------------------ |
| status             | string | 否   | 中文枚举值，见料框状态列表 | 状态筛选（使用中文）                     | 待退火                               |
| productCode        | string | 否   | 长度最大100字符            | 产品代码筛选                             | AF-1060-O-0.05x500                   |

### 错误处理最佳实践

1. **统一错误处理**: 前端应根据错误码进行统一处理，而不是依赖 HTTP 状态码

2. **错误码模式识别**: 建议根据错误码前缀进行模式识别处理
   - `BIN_`: 料框相关错误，根据具体错误码处理
   - `INV_`: 库存管理通用错误，可能影响多个模块
   - `UNAUTHORIZED/FORBIDDEN`: 认证授权错误，需要处理登录和权限问题

3. **错误消息展示**: 直接使用 `error.message` 字段的内容，无需前端硬编码错误消息

4. **重试机制**: 对于包含 `retryAfter` 字段的错误，应按照指定时间后重试

5. **日志记录**: 使用 `traceId` 进行错误追踪和问题排查

## 数据模型

### 料框模型

料框是退火车间物料管理的基本单元，记录料框的全生命周期信息。

```json
{
  "id": "string (UUID)",
  "binCode": "string",
  "binSpecificationId": "string (UUID)",
  "productId": "string (UUID)",
  "productCode": "string",
  "batchNumber": "string | null",
  "weight": "number",
  "status": "string (枚举)",
  "currentLocationId": "string (UUID) | null",
  "stackId": "string (UUID) | null",
  "registeredAt": "string (ISO日期)",
  "registeredBy": "string (UUID) | null",
  "remarks": "string | null",
  "isDeleted": "boolean",
  "createdBy": "string (UUID) | null",
  "updatedBy": "string (UUID) | null",
  "createdAt": "string (ISO日期)",
  "updatedAt": "string (ISO日期)"
}
```

### 字段说明

**主要字段**:
- `id`: 料框唯一标识
- `binCode`: 料框编号，格式：LK-YYYYMMDD-XXXX，自动转换为大写
- `binSpecificationId`: 料框规格ID，关联料框规格表
- `productId`: 产品ID，关联铝箔产品表
- `productCode`: 产品代码，冗余存储便于查询，自动转换为大写
- `batchNumber`: 批次号，用于组垛时的批次一致性校验
- `weight`: 重量(kg)，DECIMAL类型，响应时自动转换为number
- `status`: 当前状态，枚举值，见料框状态列表

**位置和关联**:
- `currentLocationId`: 当前位置ID，可为null
- `stackId`: 所属料垛ID，未组垛时为null

**时间和操作员**:
- `registeredAt`: 料框首次入系统的时间
- `registeredBy`: 注册操作员ID
- `createdAt`: 数据库记录创建时间
- `updatedAt`: 数据库记录更新时间
- `createdBy`: 创建人ID
- `updatedBy`: 最后更新人ID

**其他**:
- `remarks`: 备注信息
- `isDeleted`: 软删除标志，false表示正常，true表示已删除

**日期时间格式**:
- 所有日期时间字段均使用 ISO 8601 格式：`YYYY-MM-DDTHH:mm:ss.sssZ`
- 示例：`"2025-01-10T10:30:00.000Z"`
