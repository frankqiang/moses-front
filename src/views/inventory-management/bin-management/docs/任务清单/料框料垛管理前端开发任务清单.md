# 料框/料垛管理前端开发任务清单

## 项目概述

料框/料垛管理模块是退火车间库存管理的核心功能，实现料框从入车间登记、组垛/拆垛到状态变更的全生命周期管理。本模块基于Vue 2.x + Element UI架构，遵循项目既定的组件化开发规范，严格按照后端接口文档实现前后端数据对接。

**核心业务价值：**
- 料框注册：实现料框入库登记，关联规格、产品、批次等信息
- 料框状态追踪：管理料框从"待入库退火"到"已出库"的14种状态流转
- 料垛管理：支持料框组垛和拆垛操作，批量管理料框
- 状态历史追溯：记录并查询料框的完整状态变更历史

**与前端架构集成方式：**
- 采用与铝箔产品管理模块相同的架构模式
- 使用全局组件（BaseTable、TableToolbar、SearchForm、Drawer等）
- 遵循constants配置驱动的开发方式
- 严格按照后端接口文档的统一响应格式处理数据
