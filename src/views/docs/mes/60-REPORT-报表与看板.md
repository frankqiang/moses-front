### 3.5. 报表与看板模块 (REPORT)

**核心功能:** 提供数据可视化展示和统计分析功能，支持实时监控、管理决策和持续改进。

#### 3.5.1. 生产分析报表 (Production Analysis Reports)

* **功能描述:** 提供各类与生产执行相关的统计分析报表。
* **实现逻辑:** 基于记录的生产实绩数据 (`3.3`, `3.4`) 生成报表。
  * **产量报表:** 班/日/周/月维度的总产量、合格产量、不合格产量、合格率；可按退火炉维度统计。
  * **炉次效率报表:** 炉次数、平均装载率、平均炉次时间、单位能耗（如有能耗数据）、工艺符合度分析。
  * **计划执行报表:** 生产计划达成率、按时完成率、延误分析（含原因分类）。
  * **趋势分析:** 关键指标（日产量、合格率、OEE）趋势图。
  * **报表特性:** 多维筛选与分组；导出 Excel/CSV。

#### 3.5.2. 质量分析报表 (Quality Analysis Reports)

* **功能描述:** 提供与产品质量相关的统计分析和追溯功能。
* **实现逻辑:** 基于`3.4.6`检验数据与`3.4.1`过程数据。
  * **检验汇总:** 按时间、产品、批次、检验员统计送检/合格/不合格与一次合格率；分检验项目统计合格率。
  * **不合格分析:** 产品/批次/炉次分布；柏拉图分析主要不合格原因（若记录）。
  * **工艺-质量关联:** 选定参数与质量指标的散点图与（可选）相关系数。
  * **质量追溯:** 以料框/料垛ID或批次号生成完整追溯报告（过程、工艺、质量数据），支持PDF导出。

#### 3.5.3. 设备分析报表 (Equipment Analysis Reports)

* **功能描述:** 提供设备运行效率、能耗、故障等统计分析。
* **实现逻辑:** 基于`3.4.5`设备状态与运行数据。
  * **OEE分析:** 展示OEE与可用率/性能率/质量率，提供OEE损失分析（停机、速度、小停顿、废品等）。
  * **能耗分析:** 总能耗、单位产量/炉次能耗，按设备/时间段统计。
  * **故障分析:** 故障次数/时间、MTBF/MTTR趋势、故障原因柏拉图。
  * **维护分析(可选):** 维护按时完成率、维护成本与备件消耗。

#### 3.5.4. 实时监控看板 (Real-time Monitoring Dashboards)

* **功能描述:** 在大屏或PC实时展示车间关键运行状态与KPI。
* **实现逻辑:**
  * **总览看板:** 车间布局+设备状态、当日产量、合格率、进行中炉次、报警数、各区容量占用率、滚动报警。
  * **退火炉看板:** 各炉卡片显示状态、当前任务/产品、主控温度、工艺阶段、剩余时间、进度、报警。
  * **物流任务看板:** 待分配/执行中任务列表与地图位置、队列长度与等待时间。
  * **库存看板:** 各库区占用图、产品/状态分布、超期库存高亮。
  * **KPI看板:** 关键KPI当前值与目标、红绿灯指示、短期趋势。

#### 3.5.5. 数据分析工具 (Data Analysis Tools)

* **功能描述:** 自定义报表、即席查询、数据导出与钻取。
* **实现逻辑:**
  * **自定义报表:** 拖拽选择数据源/字段/筛选/分组/排序，选择图表类型，保存与共享模板（含权限）。
  * **高级查询:** 核心实体多条件组合查询，结果支持筛选、排序、分页。
  * **导出:** 标准报表、自定义报表、查询结果导出 Excel/CSV；支持全量/当前页。
  * **数据钻取:** 汇总图表下钻到明细或更细维度。
* **关键业务规则:** 所有数据访问遵循数据权限；性能优化避免影响系统运行。
