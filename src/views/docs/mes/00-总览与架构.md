## 1. 引言

### 1.1. 文档目的

本文档旨在详细描述铝箔退火炉车间制造执行系统（MES）的功能需求、设计细节、接口规范及非功能性要求。其主要目的是作为系统开发、测试、实施和验收的核心依据，确保开发团队、项目管理人员、业务方及其他相关方对系统功能有统一、清晰且具体的理解，最大限度地减少需求误解，保障项目顺利交付。

### 1.2. 系统范围

本MES系统专注于铝箔退火炉车间的生产执行层面，管理和追踪物料（以料框/料垛形式存在的铝箔卷）从进入车间到离开车间的全过程。系统覆盖的核心流程与实体包括：

* **物料管理:** 料框/料垛的注册、状态跟踪（待退火、退火中、已退火、待检等）、位置追踪（库位、备料台、料车、炉内）、组垛与拆垛操作。
* **生产计划与调度:** 接收生产指令，生成退火任务，对退火炉（考虑容量约40T）进行智能排程，生成配套的物流任务（行车、自动料车）。
* **生产执行与监控:** 指导和确认装/出炉操作，实时监控退火炉工艺参数（温度曲线等），跟踪行车及自动料车（含备料台交互）的作业。
* **质量管理:** 执行在线或离线的质量检验录入，结果判定与关联追溯。
* **设备管理:** 监控退火炉、行车、自动料车的实时状态与基础OEE计算。
* **数据可视化:** 提供实时看板和生产、质量、设备分析报表。
* **集成:** 与上层ERP系统（同步订单、反馈实绩）、QMS系统（同步标准、反馈结果）、WMS系统（库存协同）以及底层西门子S7-1500 PLC（工艺控制与数据采集）、行车/自动料车控制系统、扫码设备等进行数据交互。

**不在此范围内的内容（需明确）：**

* 详细的财务成本核算（MES提供基础数据给ERP）。
* 人力资源管理。
* 完整的设备维护管理系统（CMMS/EAM），MES仅做基础状态监控和维护提醒。
* 胚料铝卷入库、轧制、分切、包装、成品出库等退火前后工序的详细管理（仅做接口数据交互）。

| ERP           | Enterprise Resource Planning         | 企业资源计划                                                                                 |

| OPC UA        | OPC Unified Architecture             | OPC统一架构（工业通讯协议，用于与PLC等设备安全可靠通讯）                                     |
| **料框**      | Bin / Basket                         | 承载铝箔卷进行退火的标准金属框架，具有唯一二维码标识。                                       |
| **料垛**      | Stack                                | 由多个规格、产品、状态相同的料框垂直堆叠组成的单元，具有唯一标识（可选），作为整体进行物流。 |
| **退火炉**    | Annealing Furnace                    | 对铝箔卷进行热处理的设备，本系统涉及的炉型容量约40T。                                        |
| **行车**      | Overhead Crane                       | 车间顶部用于垂直升降和水平移动重物的起重设备，用于吊运料框/料垛。                            |
| **自动料车**  | AGV / RGV                            | 自动导引或有轨导引的物料搬运车，用于地面水平运输，特别是与备料台和退火炉的自动交互。         |
| **备料台**    | Staging Table / Preparation Platform | 退火炉附近用于临时存放待装炉或刚出炉物料的平台，可与自动料车交互。                           |
| **库位**      | Storage Location                     | 车间内（如待退火区、已退火区）用于存放料框/料垛的具体物理位置，具有唯一编号。                |
| **铝箔产品**  | Aluminum Foil Product                | 指不同牌号、规格（厚度、宽度）的铝箔卷。                                                     |
| **批次号**    | Batch Number / Lot Number            | 用于标识一批生产物料的编号，用于追溯。                                                       |
| **温度曲线**  | Temperature Profile                  | 退火过程中炉温随时间变化的预设曲线（包含升温段、保温段、降温段）。                           |
| **工艺参数**  | Process Parameter                    | 控制退火过程的技术设定值（如温度、时间、升降温速率、保护气氛类型及流量等）。                 |
| **退火任务**  | Annealing Task                       | MES下达给特定退火炉执行一次退火操作的指令，包含物料清单和工艺要求。                          |
| **物流任务**  | Logistics Task                       | MES生成的物料搬运指令，由行车或自动料车执行。                                                |
| OEE           | Overall Equipment Effectiveness      | 设备综合效率，衡量设备利用情况的关键指标。                                                   |
| MTBF          | Mean Time Between Failures           | 平均故障间隔时间。                                                                           |
| MTTR          | Mean Time To Repair                  | 平均修复时间。                                                                               |
| **单/双零箔** | Single/Double Zero Foil              | 铝箔按厚度分类，是本系统处理的主要产品类型。                                                 |

### 1.5. 假设与约束

* **假设:**
  * 车间内提供稳定可靠的有线以太网和（或）工业级无线网络覆盖，满足设备（PLC、AGV、PDA等）的通讯需求。
  * 西门子S7-1500 PLC已编程实现对退火炉的基本控制逻辑，并能通过OPC UA提供约定的数据接口。
  * 行车和自动料车具备其独立的控制系统，并能提供与其他系统交互的接口（协议待确认）。
  * 所有料框均粘贴有规范、清晰、耐用的二维码标签，内容包含唯一料框ID。
  * 操作人员（调度员、行车工、炉前工、质检员）经过培训，能够按照MES系统的指导和要求进行操作（包括扫码、确认等）。
  * 客户已有ERP、QMS、WMS系统，并能提供相应的集成接口（API或数据库视图）。
* **约束:**
  * MES系统需优先适配西门子S7-1500 PLC，通讯协议首选OPC UA。详细的PLC数据点表（DB地址、数据类型、读写权限、频率等）是本MES成功实施的关键依赖，需由自动化工程师提供并确认。
  * MES需能与客户现有的行车控制系统和双向自动料车控制系统集成。接口协议和数据格式需与设备供应商确认并遵循。
  * 系统开发需在特定的预算和时间范围内完成（具体待定）。
  * 系统初期将在客户本地服务器环境部署（硬件配置要求待定）。
  * 系统主要用户界面语言为简体中文，需要提供英文界面切换选项。
  * 系统主要处理单零箔和双零箔的退火业务。

## 2. 系统概述

### 2.1. 系统描述

铝箔退火炉车间MES系统是一个集成了车间物料追踪、生产调度、过程监控、质量记录和设备状态管理的信息化系统。它旨在打通企业计划层（ERP）与车间自动化控制层（PLC、行车、自动料车等）之间的信息壁垒，实现退火生产过程的精细化、透明化和智能化管理。通过实时采集生产数据，结合优化算法和规则引擎，系统能够优化资源（退火炉、物流设备）利用，确保工艺稳定执行，提高生产效率和产品质量，并为管理决策提供准确的数据支持。

### 2.2. 系统目标

* **全程可视化追溯:** 实现铝箔料框/料垛从进入退火车间到离开的全生命周期（状态、位置、工艺、质量）信息透明化与可追溯。
* **计划精准执行:** 将ERP生产订单转化为可执行的退火任务和物流任务，通过智能排程优化退火炉和物流设备的利用，减少等待和空闲时间。
* **工艺合规保证:** 实时监控退火过程关键参数（特别是温度曲线），与设定的标准工艺进行比对，及时发现偏差并报警，确保退火质量。
* **物流高效协同:** 实现行车和自动料车（含与备料台交互）的自动化任务调度与路径优化（若控制系统支持），提升车间内部物流效率。
* **设备状态可视:** 实时监控退火炉、行车、自动料车的运行状态，记录故障信息，为计算OEE和支持维护提供数据。
* **数据驱动决策:** 提供实时的车间看板和多维度分析报表（生产、质量、设备），为生产管理和持续改进提供数据支撑。

### 2.3. 主要特点

* **基于二维码的物料追踪:** 以料框二维码为载体，实现物料单元的精准识别与追踪。
* **料框与料垛管理:** 支持料框的独立管理以及基于规则的组垛/拆垛操作，适应车间实际作业模式。
* **退火炉智能排程:** 基于规则和优化算法，综合考虑设备、工艺、物料、时间等约束，生成优化的炉次计划。
* **实时工艺监控与报警:** 图形化展示实际温度曲线与设定曲线的对比，关键参数超限自动报警。
* **自动化物流调度:** 集成行车和自动料车控制系统，实现物流任务的自动下发与状态跟踪。
* **与自动化设备深度集成:** 通过OPC UA等标准协议与PLC、扫码器、AGV系统等无缝连接。
* **模块化与可扩展性:** 系统采用模块化设计，便于未来功能扩展或与其他系统集成。
* **友好的用户界面:** 针对车间操作环境优化设计，提供PC端和移动端（PDA）界面。

### 2.5. 核心业务实体

* **料框 (Bin):** 系统中物料追踪的基本物理单元。
  * 关键属性: 料框ID (唯一, 来自二维码), 料框规格代码 (关联规格), 当前状态 (如待退火, 退火中), 当前位置 (库位ID/设备ID), 关联产品代码, 关联批次号, 重量, 关联料垛ID (若在垛中), 注册时间, 最后更新时间。
* **料垛 (Stack):** 由多个料框组成的逻辑和物理单元。
  * 关键属性: 料垛ID (唯一, 可选), 包含料框ID列表, 料垛规格代码, 料垛状态 (同步成员料框状态), 当前位置, 总重量, 组垛时间, 拆垛时间 (若已拆)。
* **退火炉 (Annealing Furnace):** 核心生产设备。
  * 关键属性: 设备ID (唯一), 设备名称, 型号, 容量 (如40T), 当前状态 (空闲, 运行中, 故障, 维护), 当前炉次号, 关联退火任务ID, 实时工艺参数 (温度数组, 压力, 气氛流量等), 通讯接口地址 (PLC地址)。
* **行车 (Overhead Crane):** 物流设备。
  * 关键属性: 设备ID (唯一), 名称, 型号, 额定起重量, 当前状态 (空闲, 作业中, 故障), 当前位置 (坐标或区域), 载荷状态 (空载/负载), 当前执行任务ID, 通讯接口地址。
* **自动料车 (AGV/RGV):** 物流设备。
  * 关键属性: 设备ID (唯一), 名称, 型号, 载重能力, 当前状态 (空闲, 作业中, 充电中, 故障), 当前位置, 电池电量, 当前执行任务ID, 通讯接口地址。
* **库位 (Storage Location):** 存储位置。
  * 关键属性: 库位ID (唯一), 所属库区 (待退火区/已退火区/缓存区/质检区), 库位类型 (地面/货架), 尺寸限制, 承重限制, 适用料框规格, 占用状态 (空闲/占用/预留/禁用), 占用物料ID (料框/料垛)。
* **退火任务 (Annealing Task):** 生产执行指令。
  * 关键属性: 任务ID (唯一), 关联生产订单号, 计划执行炉号, 待退火料框/料垛ID列表, 关联产品代码, 关联工艺参数模板ID, 计划开始/结束时间, 实际开始/结束时间, 任务状态 (待排程, 已排程, 执行中, 完成, 异常), 优先级。
* **物流任务 (Logistics Task):** 物料搬运指令。
  * 关键属性: 任务ID (唯一), 任务类型 (入库/出库/转运/装炉/出炉), 物料ID (料框/料垛), 起始位置ID, 目标位置ID, 计划执行设备类型 (行车/料车), 指派设备ID (若已分配), 优先级, 任务状态 (待分配, 已分配, 执行中, 完成, 失败)。
