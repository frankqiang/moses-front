# 待审批申请列表页面重构说明

## 重构概述

根据后端数据库结构和接口更新，对待审批申请列表页面进行了重构，增加了对新字段的支持。

## 新增字段

### 1. 工作相关信息
- **positionId**: 岗位ID (UUID格式)
- **hireDate**: 入职日期 (日期格式)
- **managerId**: 直属上级ID (UUID格式)

### 2. 个人信息
- **birthDate**: 出生日期 (日期格式)
- **gender**: 性别 (枚举: male/female/other)
- **address**: 家庭住址 (最大500字符)

### 3. 紧急联系信息
- **emergencyContact**: 紧急联系人 (最大100字符)
- **emergencyPhone**: 紧急联系电话 (电话格式验证)

### 4. 扩展信息
- **customFields**: 自定义字段 (JSON对象)

## 表格列配置

### 分组显示
新增字段按照业务逻辑进行了分组：

1. **基本信息** (basic): 姓名、用户名、邮箱、电话
2. **工作信息** (work): 部门、职位、岗位、入职日期、直属上级
3. **个人信息** (personal): 性别、出生日期、家庭住址
4. **紧急联系** (emergency): 紧急联系人及联系方式
5. **状态信息** (status): 申请状态、申请时间
6. **其他信息** (other): 申请原因等
7. **操作** (actions): 审批操作按钮

### 显示优先级
- **优先级1（高）**: 默认显示的核心字段
- **优先级2（中）**: 可选显示的重要字段
- **优先级3（低）**: 按需显示的补充字段
- **优先级4（最低）**: 详细信息字段

### 默认可见列
为了保持界面整洁，默认只显示最重要的字段：
- 申请人姓名、用户名、邮箱
- 部门、职位、电话
- 状态、申请时间、操作

用户可以通过列设置功能自定义显示的字段。

## 搜索功能

### 新增搜索条件
- **岗位筛选**: 支持按岗位筛选申请
- **性别筛选**: 支持按性别筛选申请
- **入职日期范围**: 支持按预期入职日期范围筛选
- **出生日期范围**: 支持按出生日期范围筛选
- **直属上级筛选**: 支持按直属上级筛选申请

### 搜索参数处理
- 自动处理日期范围参数转换
- 清理空值参数
- 支持多条件组合搜索

## 数据格式化

### 新增格式化规则
- **性别显示**: male→男, female→女, other→其他
- **日期格式**: 统一使用 YYYY-MM-DD 格式
- **关联数据**: 支持显示部门名称、岗位名称、上级姓名等

## 使用说明

### 列设置
1. 点击表格工具栏的"列设置"按钮
2. 可以按分组查看和选择要显示的列
3. 设置会自动保存到本地存储

### 搜索筛选
1. 使用搜索表单可以按多个条件筛选申请
2. 日期范围筛选支持快捷选择
3. 支持关键词搜索（姓名、邮箱、用户名）

### 审批操作
审批操作逻辑保持不变：
- 单个审批：查看、批准、拒绝
- 批量审批：批量批准、批量拒绝

## 技术实现

### 文件结构
```
src/views/register/pending/
├── index.vue                 # 主页面组件
├── components/
│   ├── SearchForm.vue       # 搜索表单组件
│   └── ApplicationTable.vue # 申请列表表格组件
├── constants/
│   ├── index.js            # 常量导出入口
│   ├── application.js      # 申请相关常量
│   ├── table-config.js     # 表格配置
│   └── form-config.js      # 表单配置
└── README.md               # 本说明文档
```

### 配置文件
- **table-config.js**: 表格列定义、分组配置、优先级设置
- **form-config.js**: 搜索表单字段配置
- **application.js**: 业务常量、选项数据

### 组件复用
- 使用全局 `BaseTable` 组件提供虚拟滚动、列设置等高级功能
- 使用全局 `SearchForm` 组件提供配置化的搜索表单
- 使用全局 `TableToolbar` 组件提供工具栏功能

## 兼容性

### 向后兼容
- 保持原有API接口调用方式不变
- 新增字段为可选显示，不影响现有功能
- 搜索功能向下兼容，原有搜索参数继续有效

### 数据容错
- 新增字段支持空值显示（显示为"-"）
- 关联数据异常时显示友好提示
- 数据格式错误时自动降级处理

## 后续优化建议

1. **API优化**: 考虑按需返回字段，减少不必要的数据传输
2. **缓存策略**: 对部门、岗位、上级等选项数据进行缓存
3. **导出功能**: 支持按当前筛选条件导出申请数据
4. **移动端适配**: 优化小屏幕设备的显示效果
5. **性能优化**: 大数据量时启用虚拟滚动和分页优化
