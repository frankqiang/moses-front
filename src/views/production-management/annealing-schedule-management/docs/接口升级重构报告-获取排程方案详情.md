## 📋 接口更新概述

### 后端接口变更
根据 `获取排程方案详情接口详细说明.md` (2025-10-24更新)：

#### 新增字段
- ✅ `plan.statusLabel`: 方案状态中文名称（如"已生成"、"已发布"）
- ✅ `plan.algorithmTypeLabel`: 算法类型中文名称（如"规则算法"）

#### 结构调整
- ✅ `items[].task`: 任务详情对象字段简化，只保留核心字段：
  - `task.id`: 任务ID
  - `task.taskCode`: 任务编号
  - `task.productCode`: 产品编码
  - `task.plannedWeight`: 计划重量（吨）
  - `task.alloyGrade`: 合金牌号

#### 移除字段
- ❌ `task.customerName`: 客户名称
- ❌ `task.urgencyLevel`: 紧急程度
- ❌ `task.plannedQuantity`: 计划数量
- ❌ `task.actualWeight`: 实际重量

### 3. gantt.vue
**文件路径**: `src/views/production-management/annealing-schedule-management/gantt.vue`

#### 修改内容

**1. 数据结构修正** (第153-164行)
```javascript
// 修改前
async loadPlanInfo() {
  try {
    const response = await fetchSchedulePlanDetail(this.planId)
    this.planInfo = response.data
  }
  // ...
}

// 修改后
async loadPlanInfo() {
  try {
    const response = await fetchSchedulePlanDetail(this.planId)
    // 接口返回的data对象包含plan、items、conflicts、logs
    // 这里只需要plan对象
    this.planInfo = response.data?.plan || response.data
  } catch (error) {
    console.error('加载排程方案信息失败:', error)
    const message = error.response?.data?.error?.message || '加载排程方案信息失败'
    this.$message.error(message)
  }
}
```
