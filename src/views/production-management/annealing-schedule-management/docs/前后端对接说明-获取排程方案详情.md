# 获取排程方案详情接口 - 前后端对接说明

**接口**: `GET /v1/prod/schedule-plans/:id`

**更新日期**: 2025-10-27

---

## 📋 本次修改摘要

### 主要变更

1. **`constraintRules` 简化**：只返回 `enableMixing` 字段，移除 `maxCapacity`/`minCapacity`
2. **`scheduleContext` 增强**：每个排程项新增 `furnaceMaxCapacity` 和 `furnaceMinCapacity` 字段

### 修改原因

- 多个炉子容量可能不一致（如42吨、35吨、50吨），单一容量值无法准确表达
- 容量限制改为每个炉子独立计算，基于设备主数据动态获取

## ✅ P0阶段有效字段

### 方案基本信息（建议显示）

| 字段                 | 说明             | 示例值                   |
| -------------------- | ---------------- | ------------------------ |
| `id`                 | 排程方案ID       | uuid                     |
| `planCode`           | 排程方案编号     | "SP-20241022-143052-123" |
| `planName`           | 排程方案名称     | "排程方案-2024/10/22"    |
| `status`             | 方案状态码       | "generated"              |
| `statusLabel`        | 方案状态中文名称 | "已生成"                 |
| `algorithmType`      | 算法类型码       | "rule-based"             |
| `algorithmTypeLabel` | 算法类型中文名称 | "规则算法"               |
| `taskCount`          | 任务数量         | 27                       |
| `conflictCount`      | 冲突数量         | 0                        |
| `scheduleStartTime`  | 排程开始时间     | ISO 8601 格式            |
| `scheduleEndTime`    | 排程结束时间     | ISO 8601 格式            |
| `createdAt`          | 创建时间         | ISO 8601 格式            |
| `creator.name`       | 创建人姓名       | "张三"                   |

### 约束规则（建议显示）

| 字段                           | 说明         | 示例值 |
| ------------------------------ | ------------ | ------ |
| `constraintRules.enableMixing` | 是否启用混炉 | true   |

### 排程结果项（建议显示）

| 字段                                          | 说明                         | 示例值            |
| --------------------------------------------- | ---------------------------- | ----------------- |
| `items[].taskCode`                            | 任务编号                     | "AT-20251021-074" |
| `items[].furnaceCode`                         | 炉号                         | "TH-001"          |
| `items[].plannedLoadingAt`                    | 计划装炉时间                 | ISO 8601 格式     |

| `items[].isMixed`                             | 是否混炉                     | false             |

✨ 标记为新增字段

## ❌ P0阶段无意义字段（可不显示）

### 无意义字段清单

| 字段                      | 当前值 | 原因                 | 建议处理             |
| ------------------------- | ------ | -------------------- | -------------------- |
| `optimizationGoals`       | `{}`   | 空对象，算法未使用   | 不显示               |
| `utilizationRate`         | `null` | 未计算（P1阶段实现） | 不显示或显示"未计算" |
| `loadRate`                | `null` | 未计算（P1阶段实现） | 不显示或显示"未计算" |
| `deliveryAchievementRate` | `null` | 未计算（P1阶段实现） | 不显示或显示"未计算" |
| `overallScore`            | `null` | 未计算（P1阶段实现） | 不显示或显示"未计算" |

**重要**：这些字段虽然存在于响应中，但在P0阶段没有实际业务价值，前端可以：
- 方案1：完全不渲染这些字段
- 方案2：显示为"暂未支持"或灰色占位，等待P1阶段启用
