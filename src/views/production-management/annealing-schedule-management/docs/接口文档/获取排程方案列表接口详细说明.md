## 功能概述

### 所有功能

获取排程方案列表（Get Schedule Plans List）是退火排程管理模块中的核心查询接口，用于获取系统中所有排程方案的分页列表信息，以支持排程方案管理、状态监控和数据展示的业务场景。

### 关键特性

- ✅ **分页查询**：支持大数据量的分页加载，提供高效的数据访问体验
- ✅ **灵活筛选**：支持多维度筛选条件，包括状态、创建时间、退火炉、创建人等
- ✅ **多重排序**：支持按创建时间、更新时间、状态等字段进行升序或降序排列
- ✅ **状态统计**：提供各状态方案数量的统计信息，便于整体数据掌控
- ✅ **关联信息**：返回排程方案的关联信息，如创建人、退火炉、任务数量等
- ✅ **权限控制**：根据用户权限返回相应的数据和操作权限信息

---

### 使用前提

- ✅ 用户已通过身份认证并获得有效的访问令牌
- ✅ 用户具有排程方案查看权限（`prod.scheduling.view`）
- ✅ 系统中存在排程方案数据或允许查看空列表
- ✅ 数据库连接正常，排程方案相关表可正常访问

### 不适用场景

- ❌ 获取单个排程方案的详细信息（应使用获取单个排程方案接口）
- ❌ 创建或修改排程方案（应使用相应的创建/更新接口）

- 接收 HTTP GET 请求

- 根据筛选条件构建 WHERE 子句

- 执行计数查询获取总记录数

- 计算是否有下一页/上一页
- 生成分页元数据信息

#### 步骤7: 格式化返回数据

#### 步骤8: 返回查询结果
- 返回格式化的 JSON 响应
- 包含数据列表和分页元信息
- 记录访问日志

## 接口文档

### 基本信息

**接口路径**: `GET /v1/prod/schedule-plans`

**功能描述**: 获取退火排程方案的分页列表，支持多条件筛选和排序，用于排程方案管理界面的数据展示

**认证要求**: Bearer Token认证，需要 `prod.scheduling.view` 权限

### 查询参数

| 参数名                | 类型   | 必填 | 限制               | 描述                          | 默认值           | 示例                       |
| --------------------- | ------ | ---- | ------------------ | ----------------------------- | ---------------- | -------------------------- |
| page                  | number | 否   | >= 1               | 页码                          | 1                | 1                          |
| limit                 | number | 否   | 1-200              | 每页记录数                    | 20               | 20                         |
| status                | string | 否   | 见附录状态枚举     | 排程方案状态筛选              | null             | "generated"                |
| planNumber            | string | 否   | 最大60字符         | 方案编号模糊搜索              | null             | "SP-20251024"              |

**参数说明**:
- `sortBy` 格式为 `字段名:排序方向`，如 `createdAt:desc` 或 `overallScore:desc`
- 支持多字段排序，使用逗号分隔，如 `overallScore:desc,createdAt:desc`
- 时间范围参数需使用完整的 ISO 8601 格式（包含时区）

## 使用示例

```bash
curl -X GET "http://localhost:3000/v1/prod/schedule-plans?createdAtStart=2025-10-01T00:00:00.000Z&createdAtEnd=2025-10-31T23:59:59.999Z&limit=50" \
```

## 附录

### 排程方案状态枚举

| 状态码    | 中文名称 | 说明                       |
| --------- | -------- | -------------------------- |
| draft     | 草稿     | 方案草稿，尚未开始排程计算 |
| computing | 计算中   | 排程算法正在计算中         |
| generated | 已生成   | 排程方案已生成，待发布     |
| published | 已发布   | 方案已发布，任务已下发     |
| cancelled | 已取消   | 方案已取消，不再执行       |

### 排程算法类型枚举

| 算法类型               | 中文名称 | 说明                   |
| ---------------------- | -------- | ---------------------- |
| rule-based             | 规则算法 | 基于规则的排程算法     |
| constraint-programming | 约束规划 | 基于约束规划的排程算法 |
| simulated-annealing    | 模拟退火 | 基于模拟退火的排程算法 |
| genetic-algorithm      | 遗传算法 | 基于遗传算法的排程算法 |

### 排序字段枚举

| 字段名            | 中文名称     | 说明                   |
| ----------------- | ------------ | ---------------------- |
| createdAt         | 创建时间     | 按方案创建时间排序     |
| updatedAt         | 更新时间     | 按方案最后更新时间排序 |
| scheduleStartTime | 排程开始时间 | 按排程开始时间排序     |
| scheduleEndTime   | 排程结束时间 | 按排程结束时间排序     |
| statusUpdatedAt   | 状态更新时间 | 按状态最近更新时间排序 |
| publishedAt       | 发布时间     | 按方案发布时间排序     |
| overallScore      | 综合评分     | 按方案综合评分排序     |
| planCode          | 方案编号     | 按方案编号排序         |

**排序格式**: `sortBy=字段名:排序方向`
- 排序方向: `asc` (升序) 或 `desc` (降序)
- 示例: `sortBy=createdAt:desc` 或 `sortBy=overallScore:desc,createdAt:desc` (多字段排序)


**状态转换说明**:
- `draft` → `computing`: 开始排程计算
- `computing` → `generated`: 排程计算完成
- `generated` → `published`: 发布排程方案
- 任何状态 → `cancelled`: 取消排程方案
