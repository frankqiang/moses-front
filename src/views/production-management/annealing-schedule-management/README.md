# 退火炉排程管理模块

## 模块概述

退火炉排程管理模块是生产执行系统的核心调度引擎，负责将待执行的退火任务合理分配到各个退火炉，制定详细的炉次排程计划。

## 核心特性

### 1. 智能状态管理
- 方案状态自动识别：草稿、运算中、已生成、已发布、已取消
- 状态流转控制：已生成可发布，草稿和已生成可取消
- 运算中状态自动轮询刷新

### 2. 关键指标可视化
- 利用率、装载率、交期达成率使用进度条展示
- 根据指标数值自动着色：
  - ≥90%：绿色（优秀）
  - 70-90%：黄色（良好）
  - <70%：红色（需改进）

### 3. 冲突预警
- 冲突数量红色高亮显示
- 冲突数量>0时显示警告图标

### 4. 方案编号快速复制
- 点击方案编号一键复制到剪贴板

### 5. 灵活筛选排序
- 支持按状态、算法类型、时间范围多维度筛选
- 支持按创建时间、排程时间、利用率等多字段排序

## 使用指南

### 查看排程方案列表
1. 进入"生产管理" -> "退火炉排程"菜单
2. 列表展示所有排程方案，包含方案编号、名称、状态、关键指标等信息
3. 使用搜索框输入方案编号或名称进行搜索
4. 使用筛选条件按状态、算法类型、时间范围筛选方案

### 发布排程方案
1. 找到状态为"已生成"的排程方案
2. 点击"发布"按钮
3. 确认发布操作
4. 系统将同步更新退火任务状态

### 取消排程方案
1. 找到状态为"草稿"或"已生成"的排程方案
2. 点击"取消"按钮
3. 输入取消原因（选填）
4. 确认取消操作

### 查看方案详情
1. 点击"查看详情"按钮
2. 进入方案详情页面（待开发）

### 查看甘特图
1. 点击"查看甘特图"按钮
2. 进入甘特图可视化页面（待开发）

### 导出方案列表
1. 点击工具栏的"导出"按钮
2. 系统将根据当前筛选条件导出Excel文件

### 列设置
1. 点击工具栏的"列设置"按钮
2. 勾选/取消勾选要显示/隐藏的列
3. 设置会自动保存到浏览器本地存储

## 注意事项

1. **方案状态转换规则**:
   - 草稿 -> 已生成（运行排程算法）
   - 已生成 -> 已发布（发布方案）
   - 草稿/已生成 -> 已取消（取消方案）

2. **自动刷新机制**:
   - 当列表中存在"运算中"状态的方案时，自动每3秒刷新列表
   - 当列表中没有"运算中"状态的方案时，停止自动刷新

3. **指标数值处理**:
   - 利用率、装载率、交期达成率字段为0-1的小数
   - 前端需乘以100显示为百分比

4. **方案编号格式**:
   - 格式为`SP-YYYYMMDD-XXXX`
   - 由系统自动生成

5. **冲突数量显示**:
   - 冲突数量>0时使用红色字体和警告图标
   - 提醒用户需要处理冲突
