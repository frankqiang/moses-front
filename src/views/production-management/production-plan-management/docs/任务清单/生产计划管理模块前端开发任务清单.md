# 生产计划管理模块前端开发任务清单

## 项目概述

生产计划管理模块是生产任务管理系统的核心子模块，负责管理从ERP接收或手工创建的生产订单，进行计划的确认、拆分、合并、调整和下达。本模块为后续的退火任务管理和排程提供计划数据支持，是整个生产执行流程的起点。模块基于统一的权限控制体系和审批流程，实现生产计划的全生命周期管理。

**任务描述:**

- **需求文档参考:** `3.3.1. 生产计划管理 (Production Planning Management)`
- **接口文档参考:**

- 实现分页功能，支持页码和每页数量的配置，默认每页10条，显示总页数和总记录数
- 实现关键词搜索功能，支持按计划编号、产品编码、客户名称进行模糊搜索
- 实现多条件筛选功能，支持按计划来源（ERP/MANUAL）、状态（RECEIVED/CONFIRMED/PENDING_APPROVAL/PARTIALLY_RELEASED/RELEASED/IN_PROGRESS/COMPLETED/CANCELLED）、优先级（LOW/NORMAL/HIGH/URGENT）、产品编码、计划编号、外部订单号筛选
- 实现时间范围筛选，支持按计划交期范围和创建时间范围筛选
- 实现排序功能，支持按计划交期、创建时间等字段升序或降序排序，默认按创建时间降序

- 计划优先级显示中文名称和颜色标记：低-灰色、普通-蓝色、高-橙色、紧急-红色
- 完成进度使用进度条组件展示，显示百分比数值
- 实现状态快速变更功能，在列表中提供"确认"、"提交审批"、"取消"等快捷操作按钮
- 状态变更时根据当前状态显示对应的操作选项：已接收状态可确认，已确认状态可提交下达审批或取消，待审批状态可取消审批
- 状态变更成功后自动刷新列表并显示成功提示
- 实现权限控制：查看列表需要`prod.production-plan.view`权限，状态变更需要`prod.production-plan.cancel`权限
- 处理接口错误响应，针对不同错误码显示对应的用户友好提示
- 实现操作按钮的权限显示，无相应权限时隐藏对应操作按钮
- 列表支持表格格式和甘特图格式切换，通过format参数控制
- 甘特图格式按时间轴展示计划，横轴为时间，纵轴为计划，显示计划时间段和状态

- 实现生产计划创建对话框，分多个表单区域组织字段：基本信息、产品信息、客户信息、工艺与设备配置
- 基本信息区：计划编号（选填，为空时自动生成）、计划来源（下拉选择，ERP/MANUAL，默认MANUAL）、计划优先级（下拉选择，LOW/NORMAL/HIGH/URGENT，默认NORMAL）、计划交期（日期时间选择器，必填）
- 产品信息区：产品选择（下拉搜索或弹窗选择，必填）、产品编码（选填，选择产品后自动填充）、需求数量（必填，正数，最多3位小数）、需求单位（必填，如"吨"、"卷"）
- 客户信息区：客户名称（选填）、客户编码（选填）、特殊要求（文本域，选填，最大1000字符）
- 工艺与设备配置区：默认工艺模板（下拉选择，选填）、工艺模板关联类型（下拉选择，PRIMARY/BACKUP/MANUAL_OVERRIDE，选填）、工艺能力快照（JSON编辑器，选填，用于参考）
- 支持同时创建子批次：子批次列表（动态表格，选填），包含子计划编号、拆分序号、预计重量、预计数量、工艺模板ID等字段

- 产品选择支持下拉搜索，显示产品编码和名称，输入关键词实时搜索
- 计划交期选择器限制不能选择过去的日期
- 工艺模板下拉选择只显示状态为"生效"的模板
- 创建成功后自动关闭对话框、刷新列表并显示成功提示
- 实现批量导入对话框，支持从Excel文件导入ERP计划
- 导入对话框包含：文件选择器、ERP同步批次令牌输入框、导入时间选择器、导入结果展示区
- 支持Excel文件格式（.xlsx/.xls），提供标准模板下载
- Excel模板包含列：外部订单号、产品编码、需求数量、需求单位、计划交期、客户名称、客户编码、计划优先级、特殊要求、默认工艺模板ID
- 文件选择后自动解析并预览数据，显示导入记录数和数据预览表格
- 预览表格支持数据校验，标记错误行和错误原因
- 提供数据校验功能：检查必填字段、数据格式、产品编码有效性、交期合理性
- 导入过程显示进度条，展示当前导入进度和状态
- 导入完成后显示导入结果摘要：成功数量、失败数量、跳过数量、总数量
- 导入结果详情展示：成功记录列表、失败记录列表（含失败原因）、跳过记录列表（含跳过原因）
- 支持导出导入失败记录为Excel文件，便于修正后重新导入
- 实现权限控制：创建和导入都需要`prod.production-plan.manage`权限
- 处理接口错误响应，针对不同错误码（产品不存在、工艺模板无效、交期无效等）显示对应提示

### TASK003: 生产计划详情与编辑功能开发 🔴 **P0**
