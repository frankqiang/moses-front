## 15. 批准审批请求

**接口路径**: `POST /v1/approval-center/requests/:approvalId/approve`

**功能描述**: 审批人批准待审批的生产计划状态变更请求，审批通过后计划状态自动更新为目标状态（如RELEASED）。

**认证要求**: 需要 Bearer Token，需要审批请求中定义的审批权限（如 `prod.production-plan.approval`）

**请求头**:

```
Authorization: Bearer <access_token>
Content-Type: application/json
```

**路径参数**:

| 参数名     | 类型   | 必填 | 描述       | 示例                                   |
| ---------- | ------ | ---- | ---------- | -------------------------------------- |
| approvalId | string | 是   | 审批请求ID | "1h7g0i2f-3e6d-8j5g-2i9h-0e3f5g6h7i8d" |

**请求参数**:

| 参数名              | 类型   | 必填 | 限制         | 描述         | 示例                              |
| ------------------- | ------ | ---- | ------------ | ------------ | --------------------------------- |
| decisionRemarks     | string | 否   | 最大500字符  | 审批意见     | "审批通过，同意下达生产"          |
| requiredPermissions | array  | 是   | 权限代码数组 | 审批所需权限 | ["prod.production-plan.approval"] |

**请求示例**:

```bash
curl -X POST http://localhost:3000/v1/approval-center/requests/1h7g0i2f-3e6d-8j5g-2i9h-0e3f5g6h7i8d/approve \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..." \
  -d '{
    "decisionRemarks": "审批通过，同意下达生产",
    "requiredPermissions": ["prod.production-plan.approval"]
  }'
```

```json
{
  "decisionRemarks": "审批通过，同意下达生产",
  "requiredPermissions": ["prod.production-plan.approval"]
}
```

## 16. 驳回审批请求

**接口路径**: `POST /v1/approval-center/requests/:approvalId/reject`

**功能描述**: 审批人驳回待审批的生产计划状态变更请求，驳回后计划状态回退到原状态（如CONFIRMED）。

**认证要求**: 需要 Bearer Token，需要审批请求中定义的审批权限（如 `prod.production-plan.approval`）

**请求头**:

```
Authorization: Bearer <access_token>
Content-Type: application/json
```

**路径参数**:

| 参数名     | 类型   | 必填 | 描述       | 示例                                   |
| ---------- | ------ | ---- | ---------- | -------------------------------------- |
| approvalId | string | 是   | 审批请求ID | "1h7g0i2f-3e6d-8j5g-2i9h-0e3f5g6h7i8d" |

**请求参数**:

| 参数名              | 类型   | 必填 | 限制         | 描述             | 示例                              |
| ------------------- | ------ | ---- | ------------ | ---------------- | --------------------------------- |
| decisionRemarks     | string | 是   | 最大500字符  | 驳回原因（必填） | "库存不足，暂不下达"              |
| requiredPermissions | array  | 是   | 权限代码数组 | 审批所需权限     | ["prod.production-plan.approval"] |

**请求示例**:

```bash
curl -X POST http://localhost:3000/v1/approval-center/requests/1h7g0i2f-3e6d-8j5g-2i9h-0e3f5g6h7i8d/reject \
```

## 17. 取消审批请求

**接口路径**: `POST /v1/approval-center/requests/:approvalId/cancel`

**功能描述**: 申请人取消自己提交的待审批请求，取消后计划状态回退到原状态。

**认证要求**: 需要 Bearer Token，需要 `core.approval.manage` 权限

**请求头**:

```
Authorization: Bearer <access_token>
Content-Type: application/json
```

**路径参数**:

| 参数名     | 类型   | 必填 | 描述       | 示例                                   |
| ---------- | ------ | ---- | ---------- | -------------------------------------- |

**请求示例**:

```bash
curl -X POST http://localhost:3000/v1/approval-center/requests/1h7g0i2f-3e6d-8j5g-2i9h-0e3f5g6h7i8d/cancel \
```

## 完整审批流程示例

### 1. 提交审批

```http
POST /v1/prod/plans/{planId}/approval/submit
{
  "targetStatus": "RELEASED",
  "remarks": "申请下达生产",
  "requiredPermissions": ["prod.production-plan.approval"]
}
```

### 2. 查询待审批请求

```http
GET /v1/prod/plans/{planId}/approval/requests?status=PENDING
```

### 3a. 批准审批（审批人操作）

```http
POST /v1/approval-center/requests/{approvalId}/approve
{
  "decisionRemarks": "审批通过",
  "requiredPermissions": ["prod.production-plan.approval"]
}
```

### 3b. 驳回审批（审批人操作）

```http
POST /v1/approval-center/requests/{approvalId}/reject
{
  "decisionRemarks": "驳回原因说明",
  "requiredPermissions": ["prod.production-plan.approval"]
}
```

### 3c. 取消审批（申请人操作）

```http
POST /v1/approval-center/requests/{approvalId}/cancel
{
  "cancelRemarks": "取消原因"
}
```

---

## 注意事项

1. **审批权限检查**：批准和驳回操作会检查操作人是否拥有 `requiredPermissions` 中定义的权限
2. **状态自动更新**：审批通过后，生产计划状态会自动更新为目标状态
3. **驳回必填字段**：驳回审批时，`decisionRemarks` 是必填项
4. **幂等性**：已处理的审批请求（APPROVED/REJECTED/CANCELLED）不能再次操作
5. **事务一致性**：审批操作和计划状态更新在同一事务中，确保数据一致性
