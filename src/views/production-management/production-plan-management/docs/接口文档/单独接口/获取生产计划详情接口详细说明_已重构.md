## 功能概述

### 所有功能

获取生产计划详情（Get Production Plan Detail）是生产计划管理模块中的核心查询接口，用于获取指定生产计划的完整详细信息，以支持计划查看、编辑准备、审批决策等业务场景。该接口返回计划的主表数据、关联的子计划项列表、变更历史日志等完整信息，为业务操作提供全面的数据支持。

### 关键特性

- ✅ **完整数据加载**：一次请求获取计划主表信息、所有子计划项、变更日志的完整数据
- ✅ **关联数据自动填充**：自动关联产品信息、工艺模板、设备信息等相关数据
- ✅ **子计划有序返回**：子计划项按 `sequence` 字段升序排序，确保业务逻辑顺序正确
- ✅ **变更历史追溯**：包含完整的变更日志，按时间倒序排列，便于追溯操作历史
- ✅ **数据格式化**：自动处理数字精度、敏感字段过滤、JSON序列化等数据格式化
- ✅ **高性能查询**：基于主键查询，使用索引优化，响应速度快

---

### 使用前提

- ✅ **权限要求**：用户必须具有 `prod.production-plan.view` 权限
- ✅ **认证要求**：需要提供有效的 JWT Token 进行身份认证
- ✅ **计划存在性**：请求的计划ID必须存在于系统中且未被删除
- ✅ **参数合法性**：计划ID必须是有效的 UUID v4 格式

### 不适用场景

- ❌ **批量查询多个计划**：如需查询多个计划，应使用 `GET /v1/prod/plans` 列表接口
- ❌ **只需要基本信息**：如只需要计划基本信息而不需要子计划和日志，列表接口更高效
- ❌ **实时进度监控**：如需获取计划执行进度统计，应使用 `GET /v1/prod/plans/progress-report` 接口
- ❌ **可行性评估**：如需评估计划可行性，应使用 `GET /v1/prod/plans/:planId/feasibility` 接口

## 接口文档

### 基本信息

**接口路径**: `GET /v1/prod/plans/:planId`

**功能描述**: 根据计划ID获取生产计划的完整详细信息，包括主表数据、子计划项列表和变更历史记录

**认证要求**: Bearer Token 认证，需要 `prod.production-plan.view` 权限

**请求头**:

```
Authorization: Bearer <access_token>
Content-Type: application/json
```

### 路径参数

| 参数名 | 类型   | 必填 | 限制         | 描述             | 示例                                   |
| ------ | ------ | ---- | ------------ | ---------------- | -------------------------------------- |
| planId | string | 是   | UUID v4 格式 | 生产计划唯一标识 | "123e4567-e89b-12d3-a456-426614174000" |

### 请求示例

#### cURL 命令

```bash
curl -X GET http://localhost:3000/v1/prod/plans/123e4567-e89b-12d3-a456-426614174000 \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..." \
  -H "Content-Type: application/json"
```

#### JavaScript (Axios)

```javascript
const axios = require('axios');

const getPlanDetail = async (planId, token) => {
  try {
    const response = await axios.get(
      `http://localhost:3000/v1/prod/plans/${planId}`,
      {
        headers: {
          'Authorization': `Bearer ${token}`,
          'Content-Type': 'application/json'
        }
      }
    );
    console.log('计划详情:', response.data.data);
    return response.data.data;
  } catch (error) {
    console.error('查询失败:', error.response?.data || error.message);
    throw error;
  }
};

// 使用示例
getPlanDetail('123e4567-e89b-12d3-a456-426614174000', 'your-jwt-token');
```

## ⚡ 数据结构说明

### 子计划项响应结构优化

从 API 最近更新（2025-10-17）开始，子计划项（items）的响应结构进行了优化，重点改进包括：

| 字段              | 变更说明                                                                                                                                                                                 |
| ----------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `remarks`         | ✅ **新增返回** - 子计划备注信息，之前被过滤，现已包含在响应中                                                                                                                            |
| `processTemplate` | ✅ **结构化返回** - 不再返回散落的 `processTemplateId`/`templateName` 等字段，而是返回结构化对象，包含 `id`、`name`（从数据库 `templateName` 字段映射）、`linkType`、`capabilitySnapshot` |
| `equipment`       | ✅ **结构化返回** - 替代原来的 `assignedEquipmentId` 等字段，直接返回设备对象，包含 `id`、`name`、`linkType`、`capabilitySnapshot`                                                        |

**响应中不再包含的字段**：
- `processTemplateId` (被 `processTemplate.id` 替代)
- `processTemplateName` (被 `processTemplate.name` 替代)
- `processTemplateLinkType` (被 `processTemplate.linkType` 替代)
- `processCapabilitySnapshot` (被 `processTemplate.capabilitySnapshot` 替代)
- `assignedEquipmentId` (被 `equipment.id` 替代)
- `equipmentLinkType` (被 `equipment.linkType` 替代)
- `equipmentCapabilitySnapshot` (被 `equipment.capabilitySnapshot` 替代)
- `createdBy`、`updatedBy` (敏感信息已过滤)

### 状态转换规则

```

  ↓
  ├─→ CONFIRMED (已确认)
  │     ↓
  │     ├─→ PARTIALLY_RELEASED (部分发布)
  │     │     ↓
  │     │     └─→ RELEASED (已发布)
  │     │           ↓
  │     │           └─→ IN_PROGRESS (执行中)
  │     │                 ↓
  │     │                 └─→ COMPLETED (已完成)
  │     │
  │     └─→ PENDING_APPROVAL (待审批)
  │           ↓
  │           ├─→ RELEASED (已发布)
  │           └─→ CANCELLED (已取消)
  │
  └─→ PENDING_APPROVAL (待审批)
        ↓
        └─→ CANCELLED (已取消)
```
