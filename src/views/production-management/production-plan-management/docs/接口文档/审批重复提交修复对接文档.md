# 生产计划审批重复提交修复 - 前后端对接文档

## 📋 修复概述

**修复时间**: 2025年10月13日
**修复版本**: v1.2
**修复范围**: 生产计划状态更新接口的审批请求处理逻辑
**核心问题**: 解决审批被拒绝后无法重新提交的业务逻辑错误

## 🎯 问题背景

### 业务场景
1. **第一次操作**: 用户提交生产计划取消请求 → 审批员拒绝 (REJECTED)
2. **第二次操作**: 用户重新提交取消请求 → 系统错误报告"并发冲突"
3. **期望行为**: 被拒绝的审批应允许用户重新提交

### 技术问题
- 数据库唯一约束 `uk_approval_requests_pending_unique` 仅限制 `PENDING` 状态
- 错误处理逻辑过于严格，误判历史审批请求为冲突
- 缺少对 `REJECTED` 状态审批的重新提交支持

## 🛠️ 修复内容

**修复文件**: `src/services/modules/approval/approvalCenter.service.js`

### 2. 错误码优化

| 错误码    | 场景描述                   | 前端处理建议         |
| --------- | -------------------------- | -------------------- |
| `BIZ_030` | 存在待处理的审批请求       | 提示用户等待审批完成 |
| `BIZ_031` | 真实的并发操作冲突         | 提供重试按钮         |
| `BIZ_032` | 操作已被批准，无需重复提交 | 刷新页面显示最新状态 |

### 3. 智能重试机制

- **自动检测**: 识别 `REJECTED` 和 `APPROVED` 状态的历史请求
- **延迟重试**: 100-300ms 随机延迟避免真实并发冲突
- **日志记录**: 详细记录重新提交的上下文信息
- **递归调用**: 自动重试一次，提高成功率

## 💻 前端对接指南

### 1. 错误处理升级

```typescript
interface ApiErrorResponse {
  success: false;
  error: {
    code: string;
    message: string;
    details?: any;
  };
}

function handlePlanStatusError(error: ApiErrorResponse): void {
  const { code, message, details } = error.error;

  switch (code) {
    case 'BIZ_030':
      // 存在待处理审批 - 引导用户查看审批状态
      showApprovalPendingDialog({
        message: '该计划有审批请求正在处理中',
        approvalId: details.approvalId,
        actions: [
          { label: '查看审批详情', action: () => viewApproval(details.approvalId) },
          { label: '撤销审批', action: () => cancelApproval(details.approvalId) },
          { label: '关闭', action: () => closeDialog() }
        ]
      });
      break;

    case 'BIZ_031':
      // 并发冲突 - 提供重试选项 (现在应该很少见到)
      showRetryDialog({
        message: '检测到并发操作，请重试',
        actions: [
          { label: '立即重试', action: () => retryOperation() },
          { label: '刷新页面', action: () => window.location.reload() },
          { label: '取消', action: () => closeDialog() }
        ]
      });
      break;

    case 'BIZ_032':
      // 已被批准 - 刷新状态
      showInfoDialog({
        message: '该操作已被批准，无需重复提交',
        action: () => refreshPlanStatus()
      });
      break;

    default:
      // 其他错误按原有逻辑处理
      showErrorMessage(message);
  }
}
```

### 2. 防重复提交机制

```typescript
class PlanStatusManager {
  private isSubmitting = false;
  private lastSubmitTime = 0;
  private readonly SUBMIT_COOLDOWN = 2000; // 2秒冷却时间

  async updatePlanStatus(planId: string, payload: UpdateStatusPayload): Promise<any> {
    // 防止快速重复点击
    if (this.isSubmitting) {
      throw new Error('请求正在处理中，请勿重复提交');
    }

    // 防止短时间内重复提交
    const now = Date.now();
    if (now - this.lastSubmitTime < this.SUBMIT_COOLDOWN) {
      throw new Error(`请等待 ${Math.ceil((this.SUBMIT_COOLDOWN - (now - this.lastSubmitTime)) / 1000)} 秒后重试`);
    }

    this.isSubmitting = true;
    this.lastSubmitTime = now;

    try {
      const result = await api.patch(`/v1/prod/plans/${planId}/status`, payload);
      return result.data;
    } catch (error) {
      // 处理错误
      handlePlanStatusError(error);
      throw error;
    } finally {
      this.isSubmitting = false;
    }
  }
}
```

```typescript
interface ApprovalStatus {
  id: string;
  status: 'PENDING' | 'APPROVED' | 'REJECTED';
  requestedAction: string;
  requestedAt: string;
}

function ApprovalStatusBanner({ planId }: { planId: string }) {
  const [approvals, setApprovals] = useState<ApprovalStatus[]>([]);

  useEffect(() => {
    // 定期检查审批状态
    const checkApprovalStatus = async () => {
      try {
        const response = await api.get(`/v1/prod/plans/${planId}/approval/requests`);
        const pending = response.data.results.filter((a: ApprovalStatus) => a.status === 'PENDING');
        setApprovals(pending);
      } catch (error) {
        console.warn('检查审批状态失败:', error);
      }
    };

    checkApprovalStatus();
    const interval = setInterval(checkApprovalStatus, 30000); // 30秒检查一次

    return () => clearInterval(interval);
  }, [planId]);

  if (approvals.length === 0) return null;

  return (
    <Alert severity="info" className="mb-4">
      <AlertTitle>审批处理中</AlertTitle>
      <div className="space-y-2">
        {approvals.map((approval) => (
          <div key={approval.id} className="flex justify-between items-center">
            <span>{approval.requestedAction} 审批正在处理中</span>
            <Button
              size="small"
              onClick={() => viewApprovalDetail(approval.id)}
            >
              查看详情
            </Button>
          </div>
        ))}
      </div>
    </Alert>
  );
}
```

#### 智能重试组件
```tsx
function SmartRetryButton({
  onRetry,
  disabled,
  lastError
}: {
  onRetry: () => Promise<void>;
  disabled: boolean;
  lastError?: ApiErrorResponse;
}) {
  const [isRetrying, setIsRetrying] = useState(false);
  const [retryCount, setRetryCount] = useState(0);

  const handleRetry = async () => {
    if (disabled || isRetrying) return;

    setIsRetrying(true);
    setRetryCount(prev => prev + 1);

    try {
      await onRetry();
      setRetryCount(0); // 成功后重置计数
    } catch (error) {
      // 处理重试失败
    } finally {
      setIsRetrying(false);
    }
  };

  // 根据错误类型决定是否显示重试按钮
  const shouldShowRetry = lastError?.error.code === 'BIZ_031';

  if (!shouldShowRetry) return null;

  return (
    <Button
      onClick={handleRetry}
      disabled={disabled || isRetrying || retryCount >= 3}
      startIcon={isRetrying ? <CircularProgress size={16} /> : <RefreshIcon />}
    >
      {isRetrying ? '重试中...' : `重试 ${retryCount > 0 ? `(${retryCount}/3)` : ''}`}
    </Button>
  );
}
```
