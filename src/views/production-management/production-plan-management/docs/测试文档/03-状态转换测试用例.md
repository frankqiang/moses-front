# 03-状态转换测试用例

## 文档说明

本文档基于《生产计划业务流程说明.md》中定义的状态转换规则，详细测试所有合法和非法的状态转换场景。

---

## 状态转换规则图

根据业务流程文档，生产计划状态转换规则如下：

```
RECEIVED（已接收）
    ├→ CONFIRMED（已确认）
    ├→ PENDING_APPROVAL（待审批）
    └→ CANCELLED（已取消）

CONFIRMED（已确认）
    ├→ PARTIALLY_RELEASED（部分发布）
    ├→ PENDING_APPROVAL（待审批）
    ├→ RELEASED（已发布）
    └→ CANCELLED（已取消）

PENDING_APPROVAL（待审批）
    ├→ RELEASED（已发布）
    ├→ CANCELLED（已取消）
    ├→ CONFIRMED（已确认）
    ├→ RECEIVED（已接收）
    ├→ PARTIALLY_RELEASED（部分发布）
    └→ IN_PROGRESS（执行中）

PARTIALLY_RELEASED（部分发布）
    ├→ RELEASED（已发布）
    ├→ IN_PROGRESS（执行中）
    ├→ PENDING_APPROVAL（待审批）
    └→ CANCELLED（已取消）

RELEASED（已发布）
    ├→ IN_PROGRESS（执行中）
    ├→ PENDING_APPROVAL（待审批）
    └→ CANCELLED（已取消）

IN_PROGRESS（执行中）
    ├→ COMPLETED（已完成）
    ├→ PENDING_APPROVAL（待审批）
    └→ CANCELLED（已取消）

COMPLETED（已完成）
    └→ 终态，不可转换

CANCELLED（已取消）
    └→ 终态，不可转换
```

## 1. RECEIVED状态的转换测试

### PLAN-STATE-001：RECEIVED → CONFIRMED（合法）

**优先级**：P0

**前置条件**：
- 计划状态为RECEIVED
- 计划未冻结

**测试步骤**：
1. 调用状态更新接口
2. 目标状态：CONFIRMED
3. 变更描述："确认生产计划"

**预期结果**：
- ✅ 转换成功
- 计划状态变更为CONFIRMED
- 记录确认时间（confirmedAt）
- 记录确认人
- 创建变更日志

**测试数据**：
```json
{
  "targetStatus": "CONFIRMED",
  "changeDescription": "确认生产计划"
}
```

## 9. 特殊场景测试

### PLAN-STATE-037：相同状态转换（幂等性）

**优先级**：P1

**前置条件**：
- 计划当前状态为CONFIRMED

**测试步骤**：
1. 调用状态更新接口
2. 目标状态：CONFIRMED（与当前状态相同）

**预期结果**：
- ✅ 请求成功
- 状态不变，仍为CONFIRMED
- 返回当前计划数据
- 不创建新的变更日志
- 不报错

**说明**：系统应支持幂等性，相同状态转换直接返回成功
