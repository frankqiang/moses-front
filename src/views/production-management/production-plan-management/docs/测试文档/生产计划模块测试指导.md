# 生产计划管理模块测试指导

## 📋 测试环境准备

- 确保已登录系统
- 确保用户具有生产计划管理相关权限
- 准备测试数据：产品主数据、工艺模板

---

## 🎯 核心流程测试

### 流程1：创建并发布生产计划（标准流程）

**测试目标**：验证从创建到发布的完整审批流程

1. **创建计划**
   - 进入"生产计划管理"页面
   - 点击"新建计划"
   - 填写：产品、数量、交期、优先级
   - 提交 → 验证状态为"已接收"

2. **确认计划**
   - 打开计划详情
   - 点击"变更状态"
   - 选择目标状态"已确认"
   - 提交 → 验证状态变更为"已确认"

3. **提交审批**
   - 在详情页点击"提交审批"
   - 选择目标状态"已发布"
   - 填写审批说明
   - 提交 → 验证状态变为"待审批"

4. **审批记录查看**
   - 切换到"审批记录"标签
   - 验证显示最新审批记录
   - 展开详情查看完整信息
   - 验证申请人、审批状态、申请时间正确

5. **批准审批**（需切换到审批人账号）
   - 在审批记录中点击"批准"
   - 填写审批意见
   - 提交 → 验证计划状态变为"已发布"

6. **验证审批记录更新**
   - 查看审批记录状态变为"已通过"
   - 验证审批人、审批意见、审批时间显示

---

### 流程2：计划拆分与子批次管理

**测试目标**：验证计划拆分和子批次管理功能

1. **拆分计划**
   - 创建一个大数量计划（如1000吨）
   - 确认状态后，点击"拆分"
   - 设置拆分方案（如：200, 300, 500）
   - 提交 → 验证生成3个子批次

2. **查看子批次**
   - 在详情页查看"子批次列表"
   - 验证每个子批次数量正确
   - 验证子批次序号递增
   - 验证子批次状态为"草稿"

3. **发布后子批次联动**
   - 提交审批并通过
   - 验证所有子批次状态同步为"已发布"

---

### 流程3：取消计划（审批流程）

**测试目标**：验证取消操作的审批流程

1. **提交取消审批**
   - 在已确认的计划详情页
   - 点击"变更状态"
   - 选择"已取消"
   - **必填**取消原因（如"客户订单取消"）
   - 提交 → 验证状态变为"待审批"

2. **查看取消审批记录**
   - 切换到"审批记录"
   - 验证显示取消类型的审批
   - 验证请求操作为"取消"

3. **批准取消审批**
   - 点击"批准"按钮
   - 提交 → 验证计划状态变为"已取消"

---

### 流程4：审批驳回处理

**测试目标**：验证审批驳回后的状态恢复

1. **提交审批（发布）**
   - 创建并确认计划
   - 提交发布审批
   - 验证状态为"待审批"

2. **驳回审批**（切换到审批人账号）
   - 在审批记录中点击"驳回"
   - 填写驳回理由（如"需补充工艺信息"）
   - 提交 → 验证计划状态恢复为"已确认"

3. **查看审批记录**
   - 验证审批状态为"已驳回"
   - 验证显示驳回理由

4. **重新提交审批**
   - 补充信息后重新提交审批
   - 验证可以再次提交

---

### 流程5：计划合并

**测试目标**：验证多个计划合并功能

1. **创建多个同产品计划**
   - 创建3个相同产品的计划
   - 确认所有计划状态为"已确认"

2. **合并计划**
   - 在列表页选择这3个计划
   - 点击"合并"按钮
   - 选择目标计划
   - 提交 → 验证合并成功

3. **验证结果**
   - 目标计划数量为合并后的总和
   - 其他计划状态变为"已取消"
   - 取消原因显示"已合并到计划XXX"

---

### 流程6：计划调整

**测试目标**：验证计划信息调整功能

1. **调整数量和交期**
   - 打开已确认计划详情
   - 点击"调整"按钮
   - 修改需求数量、计划交期
   - 填写调整原因
   - 提交 → 验证信息更新

2. **查看变更日志**
   - 切换到"变更日志"标签
   - 验证显示调整记录
   - 验证变更前后的数据对比

---

## 🔍 审批记录功能测试

### 测试点1：审批记录列表

- 验证显示所有审批记录
- 验证字段显示：请求操作、审批状态、申请人、申请说明、审批意见、申请时间
- 验证申请人显示姓名和邮箱（两行）

### 测试点2：状态筛选

- 选择"待审批" → 仅显示待审批记录
- 选择"已通过" → 仅显示已通过记录
- 选择"已驳回" → 仅显示已驳回记录
- 点击"重置" → 显示所有记录

### 测试点3：展开详情

- 点击展开按钮
- 验证显示完整字段：
  - 审批ID、资源类型、资源ID
  - 申请人（姓名+邮箱）、申请人ID
  - 审批人（姓名+邮箱）、审批人ID
  - 提交时间、审批决定时间
  - 申请说明、审批意见
  - 记录创建时间、记录更新时间
  - 元数据（JSON格式）

### 测试点4：分页功能

- 切换页码 → 验证数据正确加载
- 修改每页显示数量 → 验证分页重新计算
- 验证总记录数和总页数显示正确

## ⚠️ 注意事项

1. **权限要求**：测试审批功能时需要两个不同账号（申请人和审批人）
2. **状态流转**：确保按照正确的状态流转顺序测试
3. **取消原因**：取消操作必须填写取消原因
4. **审批说明**：虽然是选填，但建议填写以便验证显示
