# 退火任务管理模块前端开发任务清单

## 项目概述

退火任务管理模块是铝箔退火炉车间MES系统的核心功能之一，负责将生产计划分解为具体可执行的退火任务，并管理任务的全生命周期。本模块支持基于生产计划批次自动生成任务和手工创建任务两种方式，提供物料绑定、状态管理、排程协同等完整功能，是连接生产计划与排程执行的关键桥梁。

**核心价值：**
- 将生产计划精确分解为可执行的退火炉次任务
- 智能预览装炉方案，优化炉容利用率（35-42吨范围）
- 支持物料关联和装炉顺序管理
- 提供完整的任务状态流转和进度跟踪
- 为排程模块提供待排程任务队列

**与现有系统集成：**
- 依赖生产计划管理模块（计划批次数据源）
- 对接工艺模板管理模块（自动匹配工艺）
- 为排程模块提供任务数据
- 未来对接库位管理模块（物料绑定功能）

**功能要点（状态流转规则）:**

- draft草稿 → pending-schedule待排程、cancelled已取消
- pending-schedule待排程 → scheduled已排程、draft草稿、cancelled已取消
- scheduled已排程 → waiting-loading待装炉、pending-schedule待排程、paused已暂停、cancelled已取消
- waiting-loading待装炉 → loading装炉中、paused已暂停、cancelled已取消
- loading装炉中 → waiting-execute待执行、waiting-loading待装炉、paused已暂停、terminated异常终止
- waiting-execute待执行 → in-progress执行中、paused已暂停、terminated异常终止
- in-progress执行中 → waiting-unload待出炉、paused已暂停、terminated异常终止
- waiting-unload待出炉 → completed已完成、paused已暂停、terminated异常终止
- paused已暂停 → 可恢复到暂停前状态、cancelled已取消、terminated异常终止
- completed已完成、cancelled已取消、terminated异常终止为终态，不允许再流转

- 第一阶段任务创建后直接进入待排程状态，跳过物料绑定环节

### 关于状态枚举值

所有任务状态枚举值必须与后端保持严格一致：

- `draft` - 草稿
- `pending-schedule` - 待排程
- `scheduled` - 已排程
- `waiting-loading` - 待装炉
- `loading` - 装炉中
- `waiting-execute` - 待执行
- `in-progress` - 执行中
- `waiting-unload` - 待出炉
- `completed` - 已完成
- `paused` - 已暂停
- `cancelled` - 已取消
- `terminated` - 异常终止
