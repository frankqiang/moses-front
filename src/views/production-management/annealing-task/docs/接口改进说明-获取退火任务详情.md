# 获取退火任务详情接口改进说明

## 改进日期
2025-01-22

## 问题描述

用户反馈获取退火任务详情接口（`GET /v1/prod/annealing-tasks/:taskId`）存在以下问题：

1. **创建人、更新人难以辨认**：返回的是用户ID，前端无法直接显示用户姓名
2. **产品信息不完整**：缺少厚度（thickness）、宽度（width）、态别（temper）字段
3. **枚举值难以理解**：生产计划的status、planPriority返回的是英文枚举值，用户不易理解
4. **物料状态难以辨认**：materials中的statusSnapshot返回英文枚举值，用户看不懂

## 解决方案

### 1. 增强用户信息返回

**改进前**：
```json
{
  "createdBy": "a0b1c2d3-e4f5-6789-0abc-def123456789",
  "updatedBy": "b1c2d3e4-f5g6-7890-1bcd-efg234567890"
}
```

**改进后**：
```json
{
  "createdBy": "a0b1c2d3-e4f5-6789-0abc-def123456789",
  "createdByUser": {
    "id": "a0b1c2d3-e4f5-6789-0abc-def123456789",
    "name": "管理员",
    "username": "admin",
    "email": "admin@example.com"
  },
  "updatedBy": "b1c2d3e4-f5g6-7890-1bcd-efg234567890",
  "updatedByUser": {
    "id": "b1c2d3e4-f5g6-7890-1bcd-efg234567890",
    "name": "排程员01",
    "username": "scheduler01",
    "email": "scheduler01@example.com"
  }
}
```

**技术实现**：
- 在查询时关联User模型（creator和updater）
- 保留原有的createdBy和updatedBy字段（向后兼容）
- 新增createdByUser和updatedByUser对象

### 2. 完善产品信息

**改进前**：
```json
{
  "productInfo": {
    "productCode": "AF-1060-O-0.05x1200",
    "productName": "1060铝箔 O态 0.05x1200",
    "alloyGrade": "1060",
    "specifications": {
      "thickness": 0.05,
      "width": 1200,
      "temper": "O"
    }
  }
}
```

**改进后**：
```json
{
  "productInfo": {
    "productCode": "AF-1060-O-0.05x1200",
    "productName": "1060铝箔 O态 0.05x1200",
    "alloyGrade": "1060",
    "temper": "O",
    "thickness": 0.05,
    "width": 1200,
    "specifications": {
      "thickness": 0.05,
      "width": 1200,
      "temper": "O"
    }
  }
}
```

**技术实现**：
- 从AluminumFoilProduct模型中提取temper、thickness、width字段
- 将这些字段提升到顶层，便于前端直接访问
- 保留specifications对象（向后兼容）

### 3. 添加枚举值中文标签

**改进前**：
```json
{
  "task": {
    "status": "scheduled",
    "priority": "normal",
    "source": "plan-split"
  },
  "planInfo": {
    "status": "IN_PROGRESS",
    "planPriority": "HIGH"
  }
}
```

**改进后**：
```json
{
  "task": {
    "status": "scheduled",
    "statusLabel": "已排程",
    "priority": "normal",
    "priorityLabel": "正常",
    "source": "plan-split",
    "sourceLabel": "计划拆分"
  },
  "planInfo": {
    "status": "IN_PROGRESS",
    "statusLabel": "执行中",
    "planPriority": "HIGH",
    "planPriorityLabel": "高"
  }
}
```

**技术实现**：
- 在constants文件中定义枚举值的中文映射字典
- 在返回结果时添加对应的Label字段
- 保留原有的枚举值字段（向后兼容）

### 4. 物料状态快照中文标签

**改进前**：
```json
{
  "materials": [
    {
      "materialCode": "BK-20250108-001",
      "statusSnapshot": "WAITING_ANNEALING"
    }
  ]
}
```

**改进后**：
```json
{
  "materials": [
    {
      "materialCode": "BK-20250108-001",
      "statusSnapshot": "WAITING_ANNEALING",
      "statusSnapshotLabel": "待退火"
    }
  ]
}
```

**技术实现**：
- 从bin.constants.js中导入BIN_STATUS枚举
- 在返回materials时，根据statusSnapshot查找对应的中文标签
- 添加statusSnapshotLabel字段
- 保留原有的statusSnapshot字段（向后兼容）
