# 退火任务管理模块前端测试文档

## 文档说明

**测试目标：** 验证退火任务管理模块的核心业务逻辑和流程能够正常运行

**测试范围：** 功能测试、业务流程测试、数据流转测试

**测试方法：** 手动测试

**不包含：** 性能测试、安全测试、压力测试、兼容性测试

---

## 测试环境准备

### 前置条件

- [ ] 后端服务已启动并可访问
- [ ] 测试账号已创建并具备相关权限（`prod.annealing-task.view`、`prod.annealing-task.manage`、`prod.annealing-task.schedule`）
- [ ] 产品主数据已维护（至少2个产品）
- [ ] 工艺模板已维护且状态为"生效"
- [ ] 生产计划已创建且包含批次数据（用于测试计划拆分生成任务）
- [ ] 浏览器开发者工具可用（用于查看接口调用）

### 测试数据准备

```javascript
// 建议准备的测试数据
产品1：AF-1060-O-0.05（1060合金，0.05mm厚度）
产品2：AF-8011-O-0.08（8011合金，0.08mm厚度）
工艺模板：对应产品的生效工艺模板
生产计划批次：总重量120吨的批次（用于拆分测试）
```
