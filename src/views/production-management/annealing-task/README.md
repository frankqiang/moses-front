# 退火任务管理模块

## 模块概述

退火任务管理模块是铝箔退火炉车间MES系统的核心功能之一，负责将生产计划分解为具体可执行的退火任务，并管理任务的全生命周期。

## 技术实现

### 架构设计

- **分层架构**：API层、常量层、组件层、页面层
- **组件复用**：使用全局组件（BaseTable、TableToolbar、SearchForm、StatusTag、ActionButtons）
- **配置驱动**：表格列、搜索表单、状态标签等均通过配置文件驱动

### 核心组件

1. **TaskTable.vue** - 表格组件
   - 基于BaseTable和TableToolbar实现
   - 支持列设置、刷新、排序、分页
   - 自定义插槽实现特殊列展示

2. **TaskSearch.vue** - 搜索组件
   - 基于SearchForm实现
   - 支持主要筛选和高级筛选折叠
   - 自动处理搜索参数格式化

3. **index.vue** - 主页面
   - 集成搜索和表格组件
   - 处理数据加载和状态管理
   - 统一错误处理

### API接口

- **fetchAnnealingTaskList** - 获取退火任务列表
  - 接口路径：`GET /v1/prod/annealing-tasks`
  - 支持分页、排序、多维度筛选
