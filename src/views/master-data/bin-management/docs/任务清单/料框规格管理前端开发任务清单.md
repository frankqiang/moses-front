# 料框规格管理前端开发任务清单

## 项目概述

基于项目需求文档中的"3.1.1. 料框规格管理"章节，本模块负责维护车间使用的各种料框的基础信息，为料框注册、库位分配、退火物流调度等业务提供规格参考。模块采用现有Vue前端架构和全局组件体系，实现规格代码、尺寸参数、载重能力、材质信息等核心数据的完整管理，确保规格数据的唯一性、准确性和状态控制。
