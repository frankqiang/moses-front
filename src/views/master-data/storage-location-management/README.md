# 库位管理模块

## 模块概述

库位管理模块是主数据管理系统的核心子模块,负责管理车间内所有物理存储位置的信息。本模块包含库区管理和库位管理两大功能板块,为库位分配优化、物流调度、退火任务执行等业务提供空间基础数据支持。

## 使用指南

### 访问入口

通过系统左侧菜单进入:
```
主数据管理 -> 库区管理  (独立页面)
主数据管理 -> 库位管理  (独立页面)
```

### 库区管理功能

#### 1. 查询库区
- **关键词搜索**: 支持按库区代码或名称模糊搜索
- **类型筛选**: 可选择DA/YA/HC/ZJ/BLT库区类型
- **状态筛选**: 可选择启用/禁用状态
- **排序**: 支持按创建时间、库区代码等字段排序

#### 2. 创建库区
点击"创建"按钮,填写以下信息:
- **库区代码**: 必填,1-50字符,仅支持大写字母、数字和中划线(自动转大写)
- **库区名称**: 必填,1-200字符
- **库区类型**: 必选,从预定义类型中选择
- **库区描述**: 选填,最多500字符

**注意**: 库区代码创建后不可修改

#### 3. 编辑库区
点击操作列的"编辑"按钮,可修改:
- 库区名称
- 库区描述
- 库区状态

**注意**: 库区代码和类型不可修改

#### 4. 查看详情
点击操作列的"详情"按钮,查看:
- 库区基本信息
- 关联库位统计
- 系统创建/更新信息

#### 5. 状态切换
点击操作列的"启用"/"禁用"按钮:
- 启用 → 禁用: 确认后禁用,禁用后无法添加新库位
- 禁用 → 启用: 确认后启用

### 库位管理功能

#### 1. 查询库位
- **关键词搜索**: 支持按库位ID模糊搜索
- **所属库区筛选**: 下拉选择库区
- **占用状态筛选**: 可选择空闲/占用/预留/禁用/维护
- **库位类型筛选**: 可选择地面堆垛区/固定货架/备料台工位/炉口虚拟位
- **排序**: 支持按创建时间等字段排序

#### 2. 创建库位
点击"创建库位"按钮,分区域填写信息:

**基本信息区**:
- **库位ID**: 必填,1-100字符,自动转大写,创建后不可修改
- **所属库区**: 必选,下拉选择(仅显示启用状态的库区)
- **库位类型**: 必选,下拉选择
- **承重限制**: 必填,0.01-100000kg

**空间坐标区**(选填):
- **X坐标**: -100000~100000cm
- **Y坐标**: -100000~100000cm
- **Z坐标**: 0~10000cm

**尺寸限制区**(选填):
- **长度限制**: 0.01-10000cm
- **宽度限制**: 0.01-10000cm
- **高度限制**: 0.01-10000cm

**其他参数区**:
- **适用料框规格**: 多选或标签输入,支持自定义
- **最大堆叠高度**: 1-20层,仅地面堆垛区有效

**注意**: 创建成功后库位默认为空闲状态

#### 3. 编辑库位
点击操作列的"编辑"按钮,可修改:
- 空间坐标(X/Y/Z)
- 尺寸限制(长/宽/高)
- 承重限制
- 适用料框规格
- 最大堆叠高度

**注意**: 库位ID、所属库区、库位类型创建后不可修改

#### 4. 查看详情
点击操作列的"详情"按钮,查看:
- 库位基本信息(ID、类型、所属库区、占用状态、承重)
- 空间坐标详情
- 尺寸限制详情
- 其他参数(料框规格、堆叠高度)
- 系统创建/更新信息

#### 5. 占用状态管理
提供三种状态切换方式:

1. **快速占用**: 空闲状态库位显示"占用"按钮
2. **快速释放**: 占用状态库位显示"释放"按钮
3. **状态变更**: 其他状态显示"状态变更"按钮,打开对话框选择目标状态

**状态转换规则**:
- 空闲 → 占用/预留/禁用/维护
- 占用 → 空闲/禁用/维护
- 预留 → 占用/空闲/禁用
- 禁用 → 空闲/维护
- 维护 → 空闲/禁用

**特殊规则**: 占用状态的库位不能直接禁用,必须先释放

#### 6. 占用状态颜色标记
- 空闲: 绿色
- 占用: 红色
- 预留: 橙色
- 禁用: 灰色
- 维护: 蓝色

## 业务规则

### 库区代码规则
- 全局唯一
- 创建后不可修改
- 自动转换为大写
- 只能包含大写字母、数字和中划线

### 库区类型说明
- `DA` - 待退火区: 存放待退火的铝箔料框
- `YA` - 已退火区: 存放已退火的铝箔料框
- `HC` - 缓存区: 临时存储区域
- `ZJ` - 质检区: 质量检验区域
- `BLT` - 备料台区域: 备料准备区域

### 状态说明
- `启用`: 库区可正常使用,可添加库位
- `禁用`: 库区暂停使用,不可添加新库位(已有库位不受影响)

## 错误处理

系统采用**后端消息优先**的策略:

1. **成功消息**: 优先使用`response.message`,备用消息仅作为fallback
2. **错误消息**: 优先使用`error.error.message`或`error.message`,备用消息仅作为fallback
3. **不硬编码**: 前端不维护错误码到消息的映射表,直接展示后端返回的用户友好消息

**错误处理模式**:
```javascript
// 优先使用后端返回的消息
const errorMsg = error.error?.message || error.message || '操作失败'
this.$message.error(errorMsg)
```

## 性能优化

1. **防抖处理**: 刷新操作使用300ms防抖
2. **分页加载**: 默认每页10条,支持调整
3. **虚拟滚动**: BaseTable支持大数据量渲染
4. **按需加载**: 路由懒加载,减少初始加载时间
