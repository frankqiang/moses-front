# 库位管理模块前端开发任务清单

## 项目概述

库位管理模块是主数据管理系统的核心子模块,负责管理车间内所有物理存储位置的信息。本模块包含库区管理和库位管理两大功能板块,为库位分配优化、物流调度、退火任务执行等业务提供空间基础数据支持。模块基于统一的权限控制体系,实现库区与库位的全生命周期管理。

- 实现排序功能，支持按创建时间、库区代码等字段升序或降序排序，默认按创建时间降序

- 编辑对话框加载时显示当前库区的完整信息
- 实现状态切换功能，在列表中通过按钮或开关快速启用/禁用库区
- 状态切换时显示确认对话框，成功后刷新列表
- 实现权限控制：查看列表需要`mdm.storage-area.view`权限，创建和编辑需要`mdm.storage-area.manage`权限
- 处理接口错误响应，针对不同错误码（STR_001库区代码已存在、STR_002代码格式不正确、STR_008状态无效等）显示对应的用户友好提示

### TASK003: 库位批量生成工具开发 🟡 **P1**

**任务名称:** 实现按规则批量创建库位的工具功能

**任务描述:**

- **需求文档参考:** `3.1.4. 库位主数据管理 - 批量生成`
- **接口文档参考:**
  - **主要接口文档:** [库位管理模块接口文档](../接口文档/接口文档.md)
  - **具体接口:**
    - [`5. 创建库位`](../接口文档/接口文档.md#5-创建库位) `(POST /v1/mdm/storage-locations)` - 批量调用创建接口
    - [`2. 查询库区列表`](../接口文档/接口文档.md#2-查询库区列表) `(GET /v1/mdm/storage-areas)` - 获取库区选项

- 实现批量生成对话框，提供批量创建库位的向导式界面
- 第一步：选择目标库区，通过下拉选择，只显示启用状态的库区
- 第二步：配置生成规则，库位ID命名规则（如库区代码-行号-列号-层号）
- 支持行号、列号、层号的起始值、结束值、步长配置
- 支持行号、列号、层号的格式配置（补零位数、使用字母等）
- 第三步：配置公共属性，所有生成的库位共享的属性：库位类型、承重限制、尺寸限制、适用料框规格代码、最大堆叠高度
- 第四步：配置坐标规则（可选），支持自动计算坐标或手动指定起始坐标和间距
- 自动计算模式：指定X/Y/Z起始坐标、每行/列/层间距，系统自动计算每个库位坐标
- 手动模式：生成后不设置坐标，由用户后续手动编辑
- 第五步：预览生成结果，表格展示即将生成的库位列表，包含库位ID、坐标、类型等信息
- 预览中显示生成数量、预计耗时提示
- 提供编辑功能，允许用户修改预览列表中的个别库位参数或删除不需要的库位
- 第六步：执行生成，点击确认后批量调用创建接口
- 实现进度显示，显示已创建数量/总数量和百分比进度条
- 采用批次提交策略，每批提交一定数量（如10个）以避免接口超时
- 单个库位创建失败不影响其他库位，记录失败信息
- 生成完成后显示结果报告：成功数量、失败数量、失败原因列表
- 失败的库位可导出为文件，便于用户手动处理
- 实现规则模板保存功能，允许用户保存常用的生成规则配置，下次使用时快速加载
- 实现输入验证：行列层号范围合理性校验、命名规则冲突检测、坐标间距合理性校验
- 实现权限控制：需要`mdm.storage-location.manage`权限才能使用批量生成工具

**版本:** v1.0

**状态:** 📋 计划中
