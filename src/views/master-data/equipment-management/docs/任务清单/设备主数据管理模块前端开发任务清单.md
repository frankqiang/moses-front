# 设备主数据管理前端开发任务清单

## 项目概述

基于《20-MDM-主数据管理》中3.1.5节设备主数据管理功能定义，本模块需提供对退火炉、行车、自动料车、备料台等关键设备档案的统一维护能力，覆盖基础信息、类型化详情、通讯参数、维护计划等要素。前端需复用项目全局组件体系（`SearchForm`、`TableToolbar`、`BaseTable`、`EnhancedForm`、`Drawer`、`ActionButtons`、`StatusTag` 等），遵循 `process-management/operations` 模块的目录结构与配置驱动模式，确保交互体验、代码风格与现有主数据模块保持一致。

## 🚨 紧急开发模式说明

**开发原则：** 当前处于紧急交付阶段，坚持“核心流程先通”的策略，优先落地设备档案的查询、创建、编辑与类型化详情维护，后续再迭代高级体验与可视化能力。

**优先级说明：**

- 🔴 **P0 - 核心必需（立即实施）**
- 🟡 **P1 - 重要功能（第二阶段）**
- 🟢 **P2 - 优化功能（后续完善）**
