# Moses API 设备管理模块接口文档

## 概述

本文档详细说明了 Moses API 设备管理模块的所有接口，包括请求方法、路径、参数、请求与响应数据结构、功能描述、错误码和返回示例。本文档严格基于当前代码实现编写，确保前端和集成端能够准确对接。

### API 基础信息

- **基础 URL**: `http://localhost:3000/v1`
- **API 版本**: v1
- **认证方式**: JWT Bearer Token
- **数据格式**: JSON
- **字符编码**: UTF-8
- **Content-Type**: application/json

### Swagger 文档

项目已集成 Swagger 文档，可通过以下地址访问：

- **开发环境**: http://localhost:3000/v1/docs
- **在线文档**: 提供完整的 API 接口说明、参数定义和示例

## 统一响应格式

### 成功响应格式

所有成功的 API 调用都会返回以下统一格式：

```json
{
  "success": true,
  "data": {
    // 具体业务数据
  },
  "message": "操作成功的描述信息",
  "meta": {
    "timestamp": "2025-09-28T10:30:00.000Z",
    "requestId": "req-1234567890-abcdef",
    "version": "v1"
  }
}
```

### 错误响应格式

所有失败的 API 调用都会返回以下统一格式：

```json
{
  "success": false,
  "error": {
    "code": "ERROR_CODE",
    "message": "用户友好的错误描述",
    "details": {
      "field": "发生错误的字段名（可选）",
      "value": "错误的字段值（可选）",

  "meta": {
    "timestamp": "2025-09-28T10:30:00.000Z",
    "requestId": "req-1234567890-abcdef",
    "version": "v1"

}

## 设备管理接口详细说明

### 1. 创建设备档案

**接口路径**: `POST /v1/mdm/equipments`

**功能描述**: 根据设备类型创建设备基础信息和类型化详情（退火炉、行车、自动料车、备料台），完成通讯参数校验、唯一性校验，并自动脱敏敏感字段。

**认证要求**: 需要 Bearer Token，且需具备 `manage:mdm-equipment` 权限。

**请求头**:

```
Authorization: Bearer <access_token>
Content-Type: application/json
```

**请求参数**:

| 参数名                | 类型   | 必填 | 限制                                                                | 描述                             | 示例                                           |
| --------------------- | ------ | ---- | ------------------------------------------------------------------- | -------------------------------- | ---------------------------------------------- |
| equipmentCode         | string | 是   | 长度 ≤ 100；自动转为大写                                            | 设备编号，必须唯一               | "AF-001"                                       |
| name                  | string | 是   | 长度 ≤ 200                                                          | 设备名称                         | "1号退火炉"                                    |
| equipmentType         | string | 是   | 枚举：annealing_furnace、crane、automatic_cart、preparation_station | 设备类型                         | "annealing_furnace"                            |
| status                | string | 否   | 枚举：enabled、disabled、maintenance；默认 enabled                  | 设备状态                         | "enabled"                                      |
| model                 | string | 否   | 长度 ≤ 150                                                          | 设备型号                         | "AF-2000"                                      |
| manufacturer          | string | 否   | 长度 ≤ 150                                                          | 制造商                           | "工业制造有限公司"                             |
| locationDescription   | string | 否   | 长度 ≤ 255                                                          | 设备位置描述                     | "车间A-1号位"                                  |
| installationDate      | string | 否   | ISO 日期                                                            | 安装日期                         | "2025-01-15"                                   |
| maintenanceCycleDays  | number | 否   | 整数 ≥ 1                                                            | 推荐维护周期（天）               | 30                                             |
| lastMaintenanceDate   | string | 否   | ISO 日期                                                            | 上次维护日期                     | "2025-08-15"                                   |
| nextMaintenanceDate   | string | 否   | ISO 日期                                                            | 下次维护日期                     | "2025-09-15"                                   |
| communicationEndpoint | string | 是   | 长度 ≤ 255                                                          | 通讯接口地址                     | "opc.tcp://192.168.1.100:4840"                 |
| communicationParams   | object | 是   | 需为非空对象                                                        | 通讯参数配置（敏感字段会被脱敏） | {"username":"operator","password":"secret123"} |
| plcNodeId             | string | 否   | 长度 ≤ 150                                                          | PLC 节点 ID（退火炉必填）        | "ns=2;i=1001"                                  |
| controlSystemAddress  | string | 否   | 长度 ≤ 255                                                          | 控制系统地址                     | "http://192.168.1.101/api"                     |
| remark                | string | 否   | 长度 ≤ 1000                                                         | 备注                             | "属于铝箔退火线"                               |
| metadata              | object | 否   | -                                                                   | 扩展字段                         | {"customTag":"A1"}                             |
| detail                | object | 是   | 根据设备类型校验；创建时仍以 detail 提交，但服务会映射到固定字段    | 对应设备类型的详情字段           | 见下方详情                                     |

**detail 字段说明（按设备类型）**：

| 设备类型            | 必填字段                                                                                                             | 可选字段                                                                | 说明                                    |
| ------------------- | -------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------- | --------------------------------------- |
| annealing_furnace   | ratedCapacityTon、maxOperatingTemperatureC、ratedPowerKw、plcNodeId                                                  | chamberLengthCm、chamberWidthCm、chamberHeightCm、supportGasType、notes | 退火炉详情，PLC 节点必填                |
| crane               | ratedLiftCapacityTon、maxSpeedMps、controlInterfaceParams                                                            | minSpeedMps、serviceAreaDescription、notes                              | 行车详情，需提供控制接口参数            |
| automatic_cart      | loadCapacityTon、maxSpeedMps、navigationType、batteryCapacityKwh、lowBatteryThresholdPercent、controlInterfaceParams | minSpeedMps、chargingStrategy、notes                                    | 自动料车详情，速度需满足最小值 ≤ 最大值 |
| preparation_station | maxLoadCapacityTon、maxBinCount                                                                                      | positionDescription、associatedAnnealingFurnaceCode、notes              | 备料台详情，可关联退火炉编号            |

**请求示例**:

```
curl -X POST http://localhost:3000/v1/mdm/equipments \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <access_token>" \

    "equipmentType": "annealing_furnace",
    "status": "enabled",

### 2. 查询设备列表

**接口路径**: `GET /v1/mdm/equipments`

**功能描述**: 分页查询设备信息，支持设备类型、状态、关键字、安装日期、维护日期等多条件筛选，可按字段排序，支持控制是否返回类型化详情。

**认证要求**: 需要 Bearer Token，需具备 `view:mdm-equipment` 权限。

**请求头**:

```
Authorization: Bearer <access_token>
```

**查询参数**:

| 参数名                  | 类型    | 必填 | 限制                                                                | 描述                      | 示例                |
| ----------------------- | ------- | ---- | ------------------------------------------------------------------- | ------------------------- | ------------------- |
| equipmentType           | string  | 否   | 枚举：annealing_furnace、crane、automatic_cart、preparation_station | 设备类型筛选              | "annealing_furnace" |
| status                  | string  | 否   | 枚举：enabled、disabled、maintenance                                | 设备状态筛选              | "enabled"           |
| equipmentCode           | string  | 否   | 长度 ≤ 100                                                          | 设备编号（模糊匹配）      | "AF"                |
| name                    | string  | 否   | 长度 ≤ 200                                                          | 设备名称（模糊匹配）      | "退火"              |
| model                   | string  | 否   | 长度 ≤ 150                                                          | 型号（模糊匹配）          | "AF-2000"           |
| manufacturer            | string  | 否   | 长度 ≤ 150                                                          | 制造商（模糊匹配）        | "工业制造"          |
| search                  | string  | 否   | 长度 ≤ 200                                                          | 编号/名称关键字模糊搜索   | "退火炉"            |
| installationDateFrom    | string  | 否   | ISO 日期                                                            | 安装日期起始              | "2025-01-01"        |
| installationDateTo      | string  | 否   | ISO 日期                                                            | 安装日期结束              | "2025-12-31"        |
| nextMaintenanceDateFrom | string  | 否   | ISO 日期                                                            | 下次维护起始              | "2025-09-01"        |
| nextMaintenanceDateTo   | string  | 否   | ISO 日期                                                            | 下次维护结束              | "2025-10-31"        |
| includeDetails          | boolean | 否   | 默认为 true；接受 true/false 字符串                                 | 是否返回设备详情          | true                |
| sortBy                  | string  | 否   | 默认 `createdAt:desc`；支持多字段，逗号分隔                         | 排序规则（字段:asc/desc） | "name:asc"          |
| limit                   | number  | 否   | 1-100；默认 10                                                      | 每页条数                  | 10                  |
| page                    | number  | 否   | ≥1；默认 1                                                          | 页码                      | 1                   |

**请求示例**:

```
curl -X GET "http://localhost:3000/v1/mdm/equipments?equipmentType=annealing_furnace&status=enabled&includeDetails=true&limit=10&page=1" \
  -H "Authorization: Bearer <access_token>"
```

### 4. 更新设备信息

**接口路径**: `PATCH /v1/mdm/equipments/{equipmentId}`

**功能描述**: 根据设备 ID 对基础信息或详情字段进行部分更新。支持更新通讯配置（带校验）、详情字段（要求提供设备类型），并记录操作日志。通讯参数更新会重新脱敏敏感字段。

**认证要求**: 需要 Bearer Token，需具备 `manage:mdm-equipment` 权限。

**路径参数**:

| 参数名      | 类型   | 必填 | 描述      |
| ----------- | ------ | ---- | --------- |
| equipmentId | string | 是   | 设备 UUID |

**请求体字段（至少提供一个）**:

| 参数名                | 类型   | 限制                                                 | 描述                             |
| --------------------- | ------ | ---------------------------------------------------- | -------------------------------- |
| equipmentCode         | string | 长度 ≤ 100                                           | 新设备编号；更新时仍需唯一       |
| name                  | string | 长度 ≤ 200                                           | 设备名称                         |
| status                | string | 枚举：enabled、disabled、maintenance；按服务规则校验 | 设备状态，变更会验证合法性       |
| model                 | string | 长度 ≤ 150                                           | 型号                             |
| manufacturer          | string | 长度 ≤ 150                                           | 制造商                           |
| locationDescription   | string | 长度 ≤ 255                                           | 位置描述                         |
| installationDate      | string | ISO 日期                                             | 安装日期                         |
| maintenanceCycleDays  | number | 整数 ≥ 1                                             | 维护周期（天）                   |
| lastMaintenanceDate   | string | ISO 日期                                             | 上次维护日期                     |
| nextMaintenanceDate   | string | ISO 日期                                             | 下次维护日期                     |
| communicationEndpoint | string | 长度 ≤ 255；更新时仍需非空                           | 通讯接口地址                     |

| plcNodeId             | string | 长度 ≤ 150                                           | PLC 节点 ID（退火炉会同步详情）  |

### 设备主数据模型（Equipment）

```json
{
  "id": "string",
  "equipmentCode": "string",
  "name": "string",
  "equipmentType": "string",
  "status": "string",
  "model": "string | null",
  "manufacturer": "string | null",

  "installationDate": "string | null",
  "maintenanceCycleDays": 30,
  "lastMaintenanceDate": "string | null",
  "nextMaintenanceDate": "string | null",
  "communicationEndpoint": "string",
  "communicationParams": {
    "username": "string"
    // 敏感字段已从响应中移除
  },
  "plcNodeIdMasked": "string | null", // 计算字段，展示脱敏后的 PLC 节点
  "controlSystemAddress": "string | null",
  "remark": "string | null",
  "metadata": { },
  "annealingFurnaceDetail": { },
  "craneDetail": null,
  "automaticCartDetail": null,

  "createdAt": "2025-09-28T02:15:00.000Z",
  "updatedAt": "2025-09-28T02:35:00.000Z"

```

- `communicationParams`：通过模型的 `toJSON` 脱敏函数会移除 `password`、`secret`、`api_key`、`token` 等敏感键。
- `plcNodeIdMasked`：模型计算字段，仅在原始 `plcNodeId` 存在时返回；真实值不会直接暴露。
- 类型化详情字段说明：根据 `equipmentType`，仅以下字段之一会返回对象，其余为 `null`
  - 退火炉（`annealing_furnace`）：`annealingFurnaceDetail`
  - 行车（`crane`）：`craneDetail`
  - 自动料车（`automatic_cart`）：`automaticCartDetail`
  - 备料台（`preparation_station`）：`preparationStationDetail`

### 设备详情模型字段分类

| 模型                              | 必填字段                                                                                                             | 其他字段                                                                | 备注                                                      |
| --------------------------------- | -------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------- | --------------------------------------------------------- |
| EquipmentAnnealingFurnaceDetail   | ratedCapacityTon、maxOperatingTemperatureC、ratedPowerKw、plcNodeId                                                  | chamberLengthCm、chamberWidthCm、chamberHeightCm、supportGasType、notes | 所有数值字段以 number 返回                                |
| EquipmentCraneDetail              | ratedLiftCapacityTon、maxSpeedMps、controlInterfaceParams                                                            | minSpeedMps、serviceAreaDescription、notes                              | `controlInterfaceParams` 将原样返回，但敏感键会被递归移除 |
| EquipmentAutomaticCartDetail      | loadCapacityTon、maxSpeedMps、navigationType、batteryCapacityKwh、lowBatteryThresholdPercent、controlInterfaceParams | minSpeedMps、chargingStrategy、notes                                    | `lowBatteryThresholdPercent` 响应为 number                |
| EquipmentPreparationStationDetail | maxLoadCapacityTon、maxBinCount                                                                                      | positionDescription、associatedAnnealingFurnaceCode、notes              | 位置与关联退火炉编号会自动去空格并转为大写                |

### 字段类型说明

- 所有日期时间字段采用 ISO 8601 字符串，例如 `2025-09-28T02:35:00.000Z`。
- 分页响应中的 `page`、`limit`、`totalPages`、`totalResults` 均为整数。
- detail 对象内的数值字段在响应中已经转换为 `number` 类型。

## 安全说明

- 所有设备接口均需使用 JWT Bearer Token 进行访问控制。
- 创建设备与更新设备接口需要 `manage:mdm-equipment` 权限；查询接口需要 `view:mdm-equipment` 权限。
- 模型自动脱敏通讯参数中的敏感字段，并仅返回 `plcNodeIdMasked`，确保通讯和 PLC 安全信息不会泄露到前端。

本文档覆盖了设备管理模块的 4 个核心接口：创建设备、分页查询、详情查询与设备更新。文档严格基于实际实现，包含完整的请求/响应结构、错误码定义、字段说明和安全要求，便于前端及集成系统准确调用。如需了解更多通用错误码与认证处理方式，请结合登录与权限模块文档一并参考。
