# 设备管理API参数规范说明

## 📋 接口地址
`/mdm/equipments`

## 🔑 关键参数值规范

### 1. equipmentType（设备类型）

**必须使用小写下划线格式**，不能使用大写或驼峰格式！

| ✅ 正确格式 | ❌ 错误格式 | 说明 |
|-----------|-----------|------|
| `annealing_furnace` | `ANNEALING_FURNACE` | 退火炉 |
| `crane` | `CRANE` | 行车 |
| `automatic_cart` | `AUTOMATIC_CART` | 自动小车 |
| `preparation_station` | `PREPARATION_STATION` | 备料工位 |

### 2. status（设备状态）

**必须使用小写英文单词**，不能使用其他格式！

| ✅ 正确格式 | ❌ 错误格式 | 说明 |
|-----------|-----------|------|
| `enabled` | `ACTIVE`、`ENABLED` | 启用状态 |
| `disabled` | `INACTIVE`、`DISABLED` | 禁用状态 |
| `maintenance` | `MAINTENANCE` | 维护中 |

## 💡 使用示例

### ✅ 正确示例

```javascript
import { fetchEquipmentList } from '@/views/master-data/equipment-management/api/equipment-management'

// 获取启用状态的退火炉
const response = await fetchEquipmentList({
  equipmentType: 'annealing_furnace',  // ✅ 小写下划线
  status: 'enabled',                    // ✅ 小写英文
  includeDetails: false,
  limit: 100,
  page: 1
})

// 获取所有行车
const response2 = await fetchEquipmentList({
  equipmentType: 'crane',  // ✅ 小写下划线
  limit: 50
})
```

### ❌ 错误示例

```javascript
// 错误1：设备类型使用大写
const response = await fetchEquipmentList({
  equipmentType: 'ANNEALING_FURNACE',  // ❌ 错误！应该是 'annealing_furnace'
  status: 'enabled'
})

// 错误2：状态使用大写或其他值
const response2 = await fetchEquipmentList({
  equipmentType: 'annealing_furnace',
  status: 'ACTIVE'  // ❌ 错误！应该是 'enabled'
})

// 错误3：设备类型使用驼峰
const response3 = await fetchEquipmentList({
  equipmentType: 'annealingFurnace',  // ❌ 错误！应该是 'annealing_furnace'
  status: 'enabled'
})
```

## 🔍 完整参数列表

### 查询参数（fetchEquipmentList）

| 参数名 | 类型 | 必填 | 格式要求 | 示例 |
|--------|------|------|---------|------|
| `equipmentType` | string | 否 | 小写下划线 | `'annealing_furnace'` |
| `status` | string | 否 | 小写英文 | `'enabled'` |
| `equipmentCode` | string | 否 | - | `'AF-001'` |
| `name` | string | 否 | - | `'退火炉1号'` |
| `search` | string | 否 | - | `'退火'` |
| `installationDateFrom` | string | 否 | ISO 8601 | `'2024-01-01'` |
| `installationDateTo` | string | 否 | ISO 8601 | `'2024-12-31'` |
| `nextMaintenanceDateFrom` | string | 否 | ISO 8601 | `'2024-01-01'` |
| `nextMaintenanceDateTo` | string | 否 | ISO 8601 | `'2024-12-31'` |
| `includeDetails` | boolean | 否 | - | `false` |
| `sortBy` | string | 否 | - | `'createdAt:desc'` |
| `page` | number | 否 | - | `1` |
| `limit` | number | 否 | - | `20` |

## ⚠️ 常见错误与解决方案

### 错误1：设备类型格式错误

**错误提示**：
```json
{
  "field": "query.equipmentType",
  "description": "设备类型必须为：annealing_furnace、crane、automatic_cart、preparation_station"
}
```

**原因**：使用了大写或驼峰格式
**解决**：改为小写下划线格式

```javascript
// ❌ 错误
equipmentType: 'ANNEALING_FURNACE'
equipmentType: 'annealingFurnace'

// ✅ 正确
equipmentType: 'annealing_furnace'
```

---

### 错误2：设备状态格式错误

**错误提示**：
```json
{
  "field": "query.status",
  "description": "设备状态必须为：enabled、disabled、maintenance"
}
```

**原因**：使用了错误的状态值
**解决**：使用正确的小写英文状态值

```javascript
// ❌ 错误
status: 'ACTIVE'
status: 'ENABLED'
status: 'INACTIVE'

// ✅ 正确
status: 'enabled'
status: 'disabled'
status: 'maintenance'
```
