# 工序管理模块

## 功能概述

工序管理模块用于管理生产工艺中的基础工序定义，包括工序的创建、编辑、状态变更和删除等功能。工序是工艺路线的基础组成部分，定义了生产过程中的各个步骤。

## 主要功能

1. **工序列表展示**：以表格形式展示所有工序，包括工序代码、名称、类型、报告点和状态等信息。
2. **搜索与筛选**：支持按工序代码或名称进行搜索，按工序类型和状态进行筛选。
3. **排序功能**：支持对表格列进行排序。
4. **分页功能**：支持前端分页，提高大数据量下的渲染性能。
5. **工序状态管理**：支持启用/禁用工序。
6. **工序删除**：支持删除未被工艺路线使用的工序。

## 组件结构

```
operations/
├── index.vue                 # 主页面组件
├── README.md                 # 模块说明文档
└── components/               # 子组件目录
    ├── SearchForm.vue        # 搜索表单组件
    └── OperationTable.vue    # 工序表格组件
```

## 使用的全局组件

- **SearchForm**：搜索表单组件，用于实现工序的搜索和筛选功能。
- **BaseTable**：表格组件，用于展示工序列表，支持排序、分页等功能。
- **TableToolbar**：表格工具栏组件，用于实现批量操作、列设置等功能。
- **StatusTag**：状态标签组件，用于展示工序的状态（启用/禁用）。
- **ActionButtons**：操作按钮组件，用于实现工序的编辑、状态变更和删除等操作。

## 数据结构

工序对象包含以下字段：

```javascript
{
  id: 'op-001',             // 工序ID
  code: 'ROLLING',          // 工序代码
  name: '热轧',             // 工序名称
  type: 'Production',       // 工序类型
  description: '...',       // 工序描述
  reportingPoint: 'Start/End', // 报告点
  associatedResourceType: ['Rolling Mill'], // 关联资源类型
  status: 'Enabled'         // 工序状态
}
```

## API接口

- **getOperationList**：获取工序列表
- **getOperationDetail**：获取工序详情
- **createOperation**：创建工序
- **updateOperation**：更新工序
- **updateOperationStatus**：更新工序状态
- **deleteOperation**：删除工序

## 使用说明

1. 访问路由 `/master-data/operations` 进入工序管理页面。
2. 使用搜索表单进行工序搜索和筛选。
3. 点击表格中的操作按钮进行工序的编辑、状态变更和删除等操作。
4. 点击"新建工序"按钮创建新的工序。

## 注意事项

1. 工序代码必须全局唯一，创建后不可修改。
2. 已被工艺路线使用的工序不可删除。
3. 工序状态变更会影响其在工艺路线中的可用性。
