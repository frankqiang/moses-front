# 设备主数据管理模块需求文档

## 1. 模块概述

设备主数据管理模块是MES系统中主数据管理的重要组成部分，用于管理公司所有的生产设备基础信息。该模块提供设备信息的增删改查、状态管理、数据导入导出等功能，为设备维护、生产管理等模块提供基础数据支持。

## 2. 功能需求

### 2.1 设备列表管理

- **功能描述**：展示系统中所有设备的基本信息，包括设备ID、名称、型号、安装日期、供应商、特定参数和状态等。
- **搜索功能**：支持按设备ID、名称、型号和状态进行搜索。
- **分页功能**：支持分页显示，用户可自定义每页显示记录数。
- **列设置功能**：支持用户自定义显示列，并保存设置。

### 2.2 设备信息维护

- **新增设备**：添加新的设备信息，根据不同设备类型录入相应的参数信息。
- **编辑设备**：修改现有设备的基本信息和参数。
- **删除设备**：支持单个删除和批量删除设备记录。
- **状态管理**：支持启用/禁用设备，以及批量启用/禁用功能。

### 2.3 数据导入导出

- **数据导入**：支持通过Excel模板批量导入设备数据，并提供导入结果反馈。
- **数据导出**：支持将设备数据导出为Excel文件。
- **模板下载**：提供设备数据导入模板下载功能。

## 4. 接口设计

### 4.1 获取设备列表

- **请求方式**：GET
- **接口路径**：/mes/master-data/equipment/list
- **请求参数**：

| 参数名 | 类型 | 是否必填 | 描述 |
|-------|------|---------|------|
| page | Integer | 否 | 页码，默认1 |
| limit | Integer | 否 | 每页记录数，默认10 |
| equipmentId | String | 否 | 设备ID（模糊查询） |
| name | String | 否 | 设备名称（模糊查询） |
| equipmentType | String | 否 | 设备类型 |
| status | Integer | 否 | 状态：1-启用，0-禁用 |

- **响应参数**：

```json
{
  "code": 20000,
  "data": {
    "total": 100,
    "items": [
      {
        "id": 1,
        "equipmentId": "FURNACE-001",
        "name": "1号退火炉",
        "model": "TAL-3000",
        "equipmentType": "FURNACE",
        "equipmentTypeText": "退火炉",
        "installDate": "2023-01-01",
        "supplier": "上海重型机械厂",
        "capacity": 3000,
        "maxTemperature": 1200,
        "ratedPower": 500,
        "plcAddress": "192.168.1.100",
        "maintenanceCycle": 30,
        "status": 1,
        "remarks": "主要用于钢材退火",
        "createTime": "2023-01-01T00:00:00",
        "updateTime": "2023-01-01T00:00:00"
      }
    ]
  }
}
```

## 5. 页面设计

### 5.1 设备列表页面

- **页面功能**：展示设备列表，提供搜索、新增、编辑、删除、状态管理等功能。
- **页面元素**：
  - 设备类型导航：支持快速切换不同类型的设备列表。
  - 搜索区域：包含设备ID、名称、状态等搜索条件。
  - 操作区域：包含新增、批量删除、批量状态管理等按钮。
  - 表格区域：展示设备列表数据，支持列设置。
  - 分页区域：提供分页导航。

### 5.2 设备新增/编辑页面

- **页面功能**：提供设备信息的新增和编辑功能。
- **页面元素**：
  - 基本信息：设备ID、名称、型号、安装日期、供应商等。
  - 特定参数：根据设备类型显示不同的参数表单。
  - 操作按钮：保存、保存并继续、取消。

## 6. 业务规则

1. 设备ID必须唯一，不允许重复。
2. 设备状态为禁用时，该设备不应被分配新的生产任务。
3. 不同类型的设备有其特定的参数要求。
4. 设备删除前需要检查是否有关联的生产任务，如有则不允许删除。
5. 设备类型一旦设置，不允许更改。

## 7. 与其他模块的关联

1. **生产管理模块**：设备是生产任务的重要资源。
2. **设备维护模块**：基于设备信息进行维护计划制定和执行。
3. **质量管理模块**：设备状态会影响产品质量的判定。
4. **报表统计模块**：提供设备相关的统计数据。

## 8. 权限控制

| 权限代码 | 权限名称 | 权限描述 |
|---------|---------|---------|
| equipment:view | 设备查看 | 允许查看设备列表和详情 |
| equipment:add | 设备新增 | 允许新增设备 |
| equipment:edit | 设备编辑 | 允许编辑设备信息 |
| equipment:delete | 设备删除 | 允许删除设备 |
| equipment:status | 设备状态管理 | 允许管理设备状态 |

## 9. 非功能需求

1. **性能需求**：
   - 列表页面加载时间不超过2秒
   - 数据操作响应时间不超过1秒
   - 支持大量设备数据的高效管理

2. **安全需求**：
   - 所有操作需要进行权限控制
   - 敏感操作需要记录操作日志
   - 设备参数修改需要留痕

3. **可用性需求**：
   - 界面设计符合用户习惯
   - 提供便捷的列设置功能
   - 支持快速切换设备类型

4. **兼容性需求**：
   - 支持主流浏览器
   - 适配不同分辨率的显示设备

## 10. 测试要点

1. 设备的增删改查功能是否正常。
2. 设备ID唯一性校验是否有效。
3. 不同类型设备的参数录入和显示是否正确。
4. 状态管理功能是否正常。
5. 列设置功能是否正常工作。
6. 与生产管理等相关模块的联动是否正常。
7. 权限控制是否有效。
8. 在大数据量下的性能表现。
