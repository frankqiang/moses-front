# 仓库管理模块需求文档

## 1. 模块概述

仓库管理模块是MES系统中主数据管理的重要组成部分，用于管理公司所有的仓库基础信息。该模块提供仓库信息的增删改查、状态管理、数据导入导出等功能，为库位管理、库存管理等模块提供基础数据支持。

## 2. 功能需求

### 2.1 仓库列表管理

- **功能描述**：展示系统中所有仓库的基本信息，包括仓库编码、名称、类型、地址、面积、负责人、联系方式、容量信息和状态等。
- **搜索功能**：支持按仓库编码、名称、类型和状态进行搜索。
- **分页功能**：支持分页显示，用户可自定义每页显示记录数。
- **排序功能**：支持按不同字段排序。

### 2.2 仓库信息维护

- **新增仓库**：添加新的仓库信息，包括仓库编码、名称、类型、地址、面积、负责人、联系方式、最大容量等信息。
- **编辑仓库**：修改现有仓库的基本信息。
- **删除仓库**：支持单个删除和批量删除仓库记录。
- **状态管理**：支持启用/禁用仓库，以及批量启用/禁用功能。

### 2.3 数据导入导出

- **数据导入**：支持通过Excel模板批量导入仓库数据，并提供导入结果反馈。
- **数据导出**：支持将仓库数据导出为Excel文件。
- **模板下载**：提供仓库数据导入模板下载功能。

## 3. 数据结构

### 3.1 仓库信息表

| 字段名 | 类型 | 是否必填 | 描述 |
|-------|------|---------|------|
| id | Integer | 是 | 主键ID |
| code | String | 是 | 仓库编码，唯一标识 |
| name | String | 是 | 仓库名称 |
| warehouseType | String | 是 | 仓库类型（RAW-原材料仓库，FINISHED-成品仓库，SEMI-半成品仓库，CONSUMABLE-耗材仓库，SPARE_PARTS-备件仓库） |
| address | String | 是 | 仓库地址 |
| area | Decimal | 是 | 仓库面积（平方米） |
| manager | String | 是 | 负责人 |
| contact | String | 是 | 联系方式 |
| maxCapacity | Integer | 是 | 最大容量 |
| currentUsage | Integer | 否 | 当前使用量 |
| description | String | 否 | 仓库描述 |
| status | Integer | 是 | 状态：1-启用，0-禁用 |
| createTime | DateTime | 是 | 创建时间 |
| updateTime | DateTime | 是 | 更新时间 |

### 3.2 仓库类型枚举

| 代码 | 描述 |
|------|------|
| RAW | 原材料仓库 |
| FINISHED | 成品仓库 |
| SEMI | 半成品仓库 |
| CONSUMABLE | 耗材仓库 |
| SPARE_PARTS | 备件仓库 |

## 5. 页面设计

### 5.1 仓库列表页面

- **页面功能**：展示仓库列表，提供搜索、新增、编辑、删除、状态管理、导入导出等功能。
- **页面元素**：
  - 搜索区域：包含仓库编码、名称、类型、状态等搜索条件。
  - 操作区域：包含新增、批量删除、批量状态管理、导入导出等按钮。
  - 表格区域：展示仓库列表数据，包含编辑、状态切换等操作按钮。
  - 分页区域：提供分页导航。

### 5.2 仓库新增/编辑页面

- **页面功能**：提供仓库信息的新增和编辑功能。
- **页面元素**：
  - 表单区域：包含仓库编码、名称、类型、地址、面积、负责人、联系方式、最大容量、描述、状态等字段。
  - 操作按钮：保存、取消。

### 5.3 仓库导入页面

- **页面功能**：提供仓库数据的批量导入功能。
- **页面元素**：
  - 文件上传区域：支持拖拽上传和点击上传。
  - 模板下载链接：提供导入模板下载。
  - 导入结果展示：显示导入成功和失败的记录数，以及失败原因。

## 6. 业务规则

1. 仓库编码必须唯一，不允许重复。
2. 仓库状态为禁用时，该仓库下的库位不应被分配新的库存。
3. 仓库的当前使用量不能超过最大容量。
4. 仓库删除前需要检查是否有关联的库位和库存，如有则不允许删除。
5. 仓库类型一旦设置，不建议频繁更改，以免影响库存管理。

## 7. 与其他模块的关联

1. **库位管理模块**：仓库是库位的上级组织单元，一个仓库可以包含多个库位。
2. **库存管理模块**：仓库是库存管理的重要维度，用于统计各仓库的库存情况。
3. **收发货管理模块**：收发货操作需要指定相关的仓库。
4. **盘点管理模块**：盘点任务通常以仓库为单位进行划分。

## 8. 权限控制

| 权限代码 | 权限名称 | 权限描述 |
|---------|---------|---------|
| warehouse:view | 仓库查看 | 允许查看仓库列表和详情 |
| warehouse:add | 仓库新增 | 允许新增仓库 |
| warehouse:edit | 仓库编辑 | 允许编辑仓库信息 |
| warehouse:delete | 仓库删除 | 允许删除仓库 |
| warehouse:import | 仓库导入 | 允许导入仓库数据 |
| warehouse:export | 仓库导出 | 允许导出仓库数据 |
| warehouse:status | 仓库状态管理 | 允许管理仓库状态 |

## 9. 非功能需求

1. **性能需求**：列表页面加载时间不超过2秒，数据操作响应时间不超过1秒。
2. **安全需求**：所有操作需要进行权限控制，敏感操作需要记录操作日志。
3. **可用性需求**：界面设计符合用户习惯，操作流程简单明了。
4. **兼容性需求**：支持主流浏览器，包括Chrome、Firefox、Edge等。

## 10. 测试要点

1. 仓库的增删改查功能是否正常。
2. 仓库编码唯一性校验是否有效。
3. 状态管理功能是否正常。
4. 导入导出功能是否正常，导入时的数据验证是否有效。
5. 与库位管理等相关模块的联动是否正常。
6. 权限控制是否有效。
7. 在大数据量下的性能表现。
