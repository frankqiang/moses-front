# 质量标准配置模块详细设计文档

**版本:** 1.0  
**日期:** 2024-01-15  
**设计人员:** foil-master  

## 1. 概述

### 1.1 模块定位
质量标准配置模块是铝箔退火炉车间MES系统主数据管理的核心组成部分，负责配置不同产品的质量检验标准和判定规则，为质量检验执行模块提供标准依据。

### 1.2 设计目标
- 建立完整的质量标准体系，支持多层次、多维度的质量标准配置
- 实现质量标准的版本化管理和审批流程
- 提供灵活的检验项目和判定规则配置能力
- 确保质量标准与产品、工序、工艺路线的有效关联
- 支持质量标准的继承和复用机制

## 3. 详细功能设计

### 3.1 检验项目管理

#### 3.1.1 检验项目定义

**功能描述：** 建立完整的检验项目库，支持多维度分类管理。

**核心功能：**
1. **项目分类体系**
   - 物理性能：硬度、抗拉强度、延伸率、弹性模量等
   - 化学成分：合金元素含量、杂质元素控制等
   - 外观质量：表面缺陷、色差、光泽度等
   - 尺寸精度：厚度偏差、宽度偏差、平直度等
   - 包装质量：包装完整性、标识正确性等

2. **检验方法配置**
   - 标准检验方法：GB/T、ASTM、JIS等国际标准
   - 企业内部方法：自定义检验程序和标准
   - 检验设备要求：指定检验设备类型和精度要求
   - 环境条件要求：温度、湿度、光照等环境参数

3. **数据类型支持**
   - 数值型：支持小数位数配置、单位换算
   - 布尔型：合格/不合格、是/否判断
   - 文本型：描述性检验结果
   - 枚举型：预定义选项列表

#### 3.1.2 检验设备关联

**功能描述：** 建立检验项目与检验设备的关联关系。

**实现逻辑：**
1. **设备能力匹配**
   - 根据检验项目的精度要求匹配合适的检验设备
   - 支持设备替代方案配置
   - 设备状态检查（可用/维护/故障）

2. **设备校准管理**
   - 校准周期跟踪
   - 校准状态验证
   - 超期设备预警

### 3.2 质量标准配置

#### 3.2.1 产品质量标准

**功能描述：** 为不同产品配置专属的质量检验标准。

**配置维度：**
1. **产品维度**
   - 按产品编码精确配置
   - 按产品系列批量配置
   - 按合金牌号通用配置
   - 按规格范围区间配置

2. **工艺状态维度**
   - 退火前检验标准
   - 退火后检验标准
   - 包装前检验标准
   - 出厂检验标准

3. **客户要求维度**
   - 标准客户要求
   - 特殊客户要求
   - 出口产品要求
   - 内销产品要求

#### 3.2.2 工序质量标准

**功能描述：** 为不同工序配置过程质量控制标准。

**关联工序：**
1. **退火工序**
   - 装炉前检验：料框完整性、标识正确性
   - 退火过程监控：温度曲线符合性、气氛纯度
   - 出炉后检验：外观质量、尺寸稳定性

2. **物流工序**
   - 搬运质量：无损伤、无污染
   - 存储质量：环境条件、堆垛规范
   - 标识质量：标签完整、信息准确

#### 3.2.3 标准继承机制

**功能描述：** 支持质量标准的继承和复用，提高配置效率。

**继承类型：**
1. **完全继承（FULL）**
   - 子标准完全继承父标准的所有检验项目和判定规则
   - 适用于产品系列化管理

2. **部分继承（PARTIAL）**
   - 选择性继承父标准的部分检验项目
   - 可添加子标准特有的检验项目

3. **覆盖继承（OVERRIDE）**
   - 继承父标准结构，但可修改具体的判定规则
   - 适用于相似产品的差异化管理

#### 3.2.4 判定规则设置

**功能描述：** 配置灵活的质量判定规则和逻辑。

**规则类型：**
1. **单项判定规则**
   ```
   简单比较：result >= min_value AND result <= max_value
   范围判定：target_value - tolerance_minus <= result <= target_value + tolerance_plus
   枚举判定：result IN ('合格', '优良', '优秀')
   正则匹配：result MATCHES '^[A-Z]{2}[0-9]{4}$'
   ```

2. **复合判定规则**
   ```
   逻辑与：(硬度 >= 60) AND (延伸率 >= 2.0)
   逻辑或：(表面质量 = '优良') OR (客户接受 = true)
   条件判定：IF (厚度 < 0.01) THEN (抗拉强度 >= 100) ELSE (抗拉强度 >= 80)
   ```

3. **统计判定规则**
   ```
   均值控制：AVG(sample_values) BETWEEN (target - 2*sigma, target + 2*sigma)
   极差控制：MAX(sample_values) - MIN(sample_values) <= max_range
   Cpk计算：Cpk >= 1.33
   ```

### 3.3 抽检规则管理

#### 3.3.1 抽检策略配置

**功能描述：** 配置多样化的抽检策略，平衡检验成本和质量风险。

**抽检策略：**
1. **比例抽检**
   - 固定比例：每批次抽检5%
   - 动态比例：根据历史质量表现调整抽检比例
   - 分层抽检：不同风险等级采用不同抽检比例

2. **数量抽检**
   - 固定数量：每批次抽检3个样品
   - 最小样本：确保统计有效性的最小样本量
   - 最大样本：控制检验成本的最大样本量

3. **特殊抽检**
   - 首末件检验：每批次首件和末件必检
   - 随机抽检：系统随机选择检验对象
   - 风险导向：重点抽检高风险产品和工序

#### 3.3.2 抽检频率设置

**功能描述：** 设置检验频率和触发条件。

**频率类型：**
1. **时间频率**
   - 定时检验：每2小时检验一次
   - 班次检验：每班次开始和结束时检验
   - 日检验：每日定时检验

2. **数量频率**
   - 批次检验：每完成一个批次检验
   - 数量检验：每生产100吨检验一次
   - 料框检验：每10个料框检验一次

3. **事件频率**
   - 工艺变更：工艺参数调整后检验
   - 设备维护：设备维护后首件检验
   - 异常恢复：质量异常恢复后加强检验

### 3.4 标准版本管理

#### 3.4.1 版本创建与编辑

**功能描述：** 支持质量标准的版本化管理，确保标准变更的可追溯性。

**版本管理机制：**
1. **版本号规则**
   - 主版本号：重大变更（如检验项目增减）
   - 次版本号：一般变更（如判定规则调整）
   - 修订号：轻微变更（如描述文字修正）

2. **版本创建方式**
   - 基于现有版本创建：复制现有版本进行修改
   - 全新创建：从零开始创建新标准
   - 批量升级：批量升级多个相关标准

3. **变更记录**
   - 变更内容：详细记录每次变更的具体内容
   - 变更原因：记录变更的业务原因和依据
   - 影响分析：评估变更对现有生产的影响

#### 3.4.2 审批流程管理

**功能描述：** 建立严格的质量标准审批流程，确保标准的权威性和准确性。

**审批流程：**
1. **一级审批流程**
   - 适用范围：轻微变更、例行更新
   - 审批人员：质量工程师、车间主管
   - 审批时限：2个工作日

2. **二级审批流程**
   - 适用范围：重要变更、新标准制定
   - 审批人员：质量经理、技术总监
   - 审批时限：5个工作日

3. **三级审批流程**
   - 适用范围：重大变更、关键标准
   - 审批人员：总工程师、总经理
   - 审批时限：10个工作日

**审批控制：**
- 审批权限矩阵：不同级别人员的审批权限范围
- 审批状态跟踪：实时跟踪审批进度和状态
- 审批意见记录：完整记录审批意见和建议
- 驳回处理机制：驳回后的修改和重新提交流程

### 3.5 标准应用管理

#### 3.5.1 标准生效控制

**功能描述：** 控制质量标准的生效时间和应用范围。

**生效机制：**
1. **定时生效**
   - 设定具体的生效日期和时间
   - 支持延迟生效和提前生效
   - 自动切换新旧标准

2. **条件生效**
   - 基于特定条件触发生效（如设备升级完成）
   - 支持多条件组合判断
   - 人工确认生效

3. **渐进生效**
   - 分阶段逐步应用新标准
   - 新旧标准并行运行期
   - 平滑过渡机制

#### 3.5.2 异常处理规则

**功能描述：** 定义质量标准应用过程中的异常处理规则。

**异常类型：**
1. **标准缺失异常**
   - 产品无对应质量标准
   - 处理方式：使用默认标准、暂停生产、人工指定

2. **标准冲突异常**
   - 多个标准同时适用
   - 处理方式：优先级判断、人工选择、合并应用

3. **标准过期异常**
   - 标准已过有效期
   - 处理方式：自动延期、使用备用标准、停止应用
