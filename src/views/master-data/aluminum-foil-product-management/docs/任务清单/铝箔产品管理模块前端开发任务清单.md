# 铝箔产品管理前端开发任务清单

## 项目概述

基于《20-MDM-主数据管理》中3.1.2节铝箔产品管理功能定义，本模块需提供铝箔产品主数据的完整维护能力，覆盖产品编码、规格参数、生命周期状态以及工艺模板、质量标准关联等核心信息。前端将依托现有Vue 2架构与Element UI体系，严格复用项目全局组件（`SearchForm`、`TableToolbar`、`BaseTable`、`DrawerForm`、`ActionButtons`、`StatusTag` 等），并遵循 `user-management` 模块的目录结构和配置驱动模式，确保与现有主数据模块的交互体验、代码风格保持一致。

## 🎯 紧急开发模式总结

### ✅ 当前阶段必须完成（P0）：

- 完成 API 服务层、配置分层、搜索、表格、表单、页面集成六大任务
- 确保 CRUD 主流程可用，消息提示与错误处理符合后端规范
- 严格使用全局组件体系，禁用 Mock、权限检查

### ⏳ 可以简化实现的功能：

- 关联资源选择可先使用静态提示，占位远程检索能力
- 搜索条件记忆、URL 同步可延期
- 表格高级操作（批量、导出、列偏好）可暂不开放

### ❌ 可以完全暂缓的功能：

- 智能推荐、嵌套新建关联资源等高级体验
- 自动化测试扩展（E2E、视觉回归）
- 复杂性能监控、埋点统计

### 🚀 开发建议：

1. **接口优先：** 先完成 API 对接，确保数据可用。
2. **配置驱动：** 搜索、表格、表单统一走配置，减少重复开发。
3. **统一消息：** 所有成功/失败提示使用后端返回信息，保持一致性。
4. **组件复用：** 严格复用全局组件，避免重复造轮子。
5. **联调同步：** 与工艺、质量模块保持沟通，及早确认关联数据获取方案。

**预期效果：** 完成 P0 阶段后，铝箔产品主数据可以在系统内被检索、维护并提供下游模块使用；P1 阶段进一步完善关联体验与质量保障，为后续优化奠定基础。
