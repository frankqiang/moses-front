# Moses API 铝箔产品管理模块接口文档

## 概述

本文档详细说明了 Moses API 铝箔产品管理模块的所有接口，包括请求方法、路径、参数、请求和响应数据结构、功能描述、错误码和返回示例。**本文档严格基于实际代码实现编写**，确保前端开发人员能够准确对接。

⚠️ **特别注意**：
- **🔗 关联对象完整性**：接口返回的数据结构完全按照实际模型实现，包含所有字段
- **📊 计算字段说明**：数值字段（厚度、宽度、单位重量）通过 toJSON 方法转换为数字类型
- **🧮 数据格式标注**：产品编码支持自动大写转换，字符串字段支持自动去除空白

### API 基础信息

- **基础 URL**: `http://localhost:3000/v1` (开发环境)
- **API 版本**: v1
- **认证方式**: JWT Bearer Token

- **字符编码**: UTF-8
- **Content-Type**: application/json

### 权限要求

- **查看权限**: `view_aluminum_foil_products`
- **管理权限**: `manage_aluminum_foil_products`

## 统一响应格式

### 成功响应格式

所有成功的 API 调用都会返回以下统一格式：

```json
{
  "success": true,
  "data": {
    // 具体的业务数据，根据接口而不同
  },
  "message": "操作成功的描述信息",
  "meta": {
    "timestamp": "2024-01-20T10:30:00.000Z",
    "requestId": "req-1234567890-abcdef",
    "version": "v1"
  }
}
```

### 错误响应格式

所有错误的 API 调用都会返回以下统一格式：

```json
{
  "success": false,
  "error": {
    "code": "ERROR_CODE",
    "message": "用户友好的错误描述",
    "details": {
      "field": "发生错误的字段名（可选）",
      "value": "错误的字段值（可选）",
      "retryAfter": 300,
      "traceId": "req-1234567890-abcdef"
    }
  },
  "meta": {
    "timestamp": "2024-01-20T10:30:00.000Z",
    "requestId": "req-1234567890-abcdef",
    "version": "v1"
  }
}
```

**响应字段说明**：

- `success`: 布尔值，表示请求是否成功
- `data`: 成功时包含业务数据，失败时为 null
- `error`: 失败时包含错误信息，成功时为 null
- `message`: 成功时的操作描述
- `error.code`: 标准化的错误码，用于程序化处理
- `error.message`: 用户友好的错误描述，可直接展示给用户
- `error.details`: 可选的错误详细信息
- `meta`: 元数据信息，包含时间戳、请求 ID 和版本号

## 铝箔产品管理接口详细说明

### 1. 创建铝箔产品

**接口路径**: `POST /v1/aluminum-foil-products`

**功能描述**: 创建新的铝箔产品，包含完整的业务验证和数据校验。支持产品编码唯一性校验、格式验证、数值范围验证等业务规则。产品编码会自动转换为大写格式。

**认证要求**: 需要 Bearer Token 和 `manage_aluminum_foil_products` 权限

**请求头**:

```
Authorization: Bearer <access_token>
Content-Type: application/json
```

**请求参数**:

| 参数名             | 类型   | 必填 | 限制                         | 描述                           | 示例                                     |
| ------------------ | ------ | ---- | ---------------------------- | ------------------------------ | ---------------------------------------- |
| productCode        | string | 是   | 格式：AF-合金-硬度-厚度x宽度 | 产品编码，全局唯一，自动转大写 | "AF-1100-H18-0.006x1200"                 |
| productName        | string | 是   | 1-200字符                    | 产品名称                       | "1100合金H18态双零箔"                    |
| rawMaterialType    | string | 是   | 1-100字符                    | 原材料类型                     | "铝合金板"                               |
| alloyGrade         | string | 是   | 1-50字符，字母数字           | 合金牌号，自动转大写           | "1100"                                   |
| temper             | string | 是   | 1-50字符，字母数字           | 状态/硬度，自动转大写          | "H18"                                    |
| thickness          | number | 是   | 0.001-100，精度6位小数       | 规格-厚度(mm)                  | 0.006                                    |
| width              | number | 是   | 1-10000，精度3位小数         | 规格-宽度(mm)                  | 1200                                     |
| unitWeight         | number | 是   | 0.001-10000，精度6位小数     | 单位重量                       | 19.4                                     |
| unitWeightType     | string | 是   | "kg/卷"或"kg/m²"             | 单位重量类型                   | "kg/卷"                                  |
| processTemplateIds | array  | 否   | UUID数组                     | 关联标准退火工艺模板ID列表     | ["456e4567-e89b-12d3-a456-426614174000"] |
| qualityStandardId  | string | 否   | UUID格式                     | 关联质量标准ID                 | "789e4567-e89b-12d3-a456-426614174000"   |
| lifecycleStatus    | string | 否   | 试产/量产/停产               | 产品生命周期状态，默认"试产"   | "试产"                                   |
| description        | string | 否   | 最多500字符                  | 产品描述                       | "高质量铝箔产品，适用于包装行业"         |

**请求示例**:

```bash
curl -X POST http://localhost:3000/v1/aluminum-foil-products \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..." \
  -d '{
    "productCode": "AF-1100-H18-0.006x1200",
    "productName": "1100合金H18态双零箔",
    "rawMaterialType": "铝合金板",
    "alloyGrade": "1100",
    "temper": "H18",

    "qualityStandardId": "789e4567-e89b-12d3-a456-426614174000",
    "lifecycleStatus": "试产",
    "description": "高质量铝箔产品，适用于包装行业"

```

**接口路径**: `GET /v1/aluminum-foil-products`

**认证要求**: 需要 Bearer Token 和 `view_aluminum_foil_products` 权限

系统使用统一的错误码体系，便于客户端处理和日志追踪。错误码格式：模块前缀\_数字编号。

### 铝箔产品管理相关错误码 (AFP_xxx)

| 错误码  | HTTP 状态码 | 错误消息                                         | 说明                                   | 处理建议                                 |
| ------- | ----------- | ------------------------------------------------ | -------------------------------------- | ---------------------------------------- |
| AFP_001 | 400         | 产品编码已存在                                   | 尝试创建或更新产品时编码与现有产品冲突 | 检查产品编码是否重复，更换唯一编码       |

| AFP_003 | 400         | 产品编码不能为空                                 | 创建产品时未提供产品编码               | 提供有效的产品编码                       |
| AFP_004 | 404         | 产品不存在                                       | 根据ID查询或更新产品时产品不存在       | 检查产品ID是否正确，确认产品未被删除     |

| AFP_011 | 400         | 宽度必须为正数                                   | 宽度参数小于等于0或不是数字            | 提供大于1的有效宽度值                    |
| AFP_012 | 400         | 单位重量必须为正数                               | 单位重量参数小于等于0或不是数字        | 提供大于0.001的有效单位重量值            |

### 通用错误码

**参考认证模块文档中的通用错误码部分，包括：**
- 认证相关错误码 (AUTH_xxx)
- 验证相关错误码 (VAL_xxx)
- 系统错误码 (SYS_xxx)

### 错误处理最佳实践

1. **统一错误处理**: 前端应根据错误码进行统一处理，而不是依赖 HTTP 状态码

2. **错误码模式识别**: 建议根据错误码前缀进行模式识别处理
   - `AUTH_`: 认证相关错误，可能需要重新登录或刷新令牌
   - `VAL_`: 验证相关错误，需要检查输入参数
   - `AFP_`: 铝箔产品业务逻辑错误，需要根据具体错误码处理
   - `SYS_`: 系统错误，通常需要重试或联系支持

3. **错误消息展示**: 直接使用 `error.message` 字段的内容，无需前端硬编码错误消息

4. **重试机制**: 对于系统错误（5xx状态码），建议实现指数退避重试机制

5. **日志记录**: 使用 `traceId` 进行错误追踪和问题排查

  "width": "number",                                       // 规格-宽度(mm)，计算字段，DECIMAL转数字

  "unitWeightType": "string",                              // 单位重量类型：kg/卷 | kg/m²

⚠️ **模型文档编写要求**：
1. **数据转换**: 数值字段（thickness、width、unitWeight）通过 toJSON 方法自动转换为数字类型
2. **字符串处理**: 产品编码、合金牌号、硬度状态自动转换为大写格式
3. **JSON存储**: processTemplateIds 使用 TEXT 字段存储 JSON 数组，get/set 方法自动序列化
4. **唯一约束**: 产品编码在未删除记录中全局唯一
5. **软删除**: 使用 isDeleted 字段实现软删除，删除的记录不参与唯一性约束

### 字段说明

**日期时间格式**:
- 所有日期时间字段均使用 ISO 8601 格式：`YYYY-MM-DDTHH:mm:ss.sssZ`
- 示例：`"2025-09-23T10:00:00.000Z"`

**数值字段精度**:
- `thickness`: DECIMAL(10,6)，支持最多6位小数，范围0.001-100
- `width`: DECIMAL(10,3)，支持最多3位小数，范围1-10000
- `unitWeight`: DECIMAL(10,6)，支持最多6位小数，范围0.001-10000

**枚举字段**:
- `unitWeightType`: "kg/卷" | "kg/m²"
- `lifecycleStatus`: "试产" | "量产" | "停产"

**格式验证**:
- `productCode`: 正则表达式 `/^AF-[A-Z0-9-]+-[A-Z0-9-]+-[\d.]+X[\d.]+$/`
- `alloyGrade`: 正则表达式 `/^[A-Z0-9]+$/`
- `temper`: 正则表达式 `/^[A-Z0-9]+$/`

## 业务规则说明

### 产品编码规则
1. **格式要求**: AF-合金-硬度-厚度x宽度
2. **示例**: AF-1100-H18-0.006X1200
3. **自动处理**: 输入时自动转换为大写格式
4. **唯一性**: 在未删除记录中必须唯一

### 数值验证规则
1. **厚度**: 必须大于0.001mm，小于等于100mm
2. **宽度**: 必须大于1mm，小于等于10000mm
3. **单位重量**: 必须大于0.001kg，小于等于10000kg

### 生命周期状态管理
1. **试产**: 新产品默认状态，用于试验性生产
2. **量产**: 正式投入批量生产的产品
3. **停产**: 已停止生产的产品

### 关联数据处理
1. **工艺模板**: 支持关联多个标准退火工艺模板
2. **质量标准**: 支持关联一个质量标准
3. **扩展性**: 预留了与工艺模板和质量标准模块的关联能力

## 安全说明

### 认证机制

本模块所有接口均需要 JWT Bearer Token 认证，认证机制参考登录模块：
- 请求头必须包含 `Authorization: Bearer <token>`
- Token 过期时间根据系统配置
- Token 无效时返回 401 错误

### 权限控制

接口权限分为两级：
- **查看权限** (`view_aluminum_foil_products`): 查询产品列表和详情
- **管理权限** (`manage_aluminum_foil_products`): 创建、更新产品信息

### 数据安全特性

1. **软删除**: 使用 isDeleted 字段实现软删除，保护数据安全
2. **操作记录**: 记录创建人和更新人信息，支持操作追踪
3. **数据验证**: 多层验证机制，防止无效数据入库
4. **事务处理**: 关键操作使用数据库事务，确保数据一致性

### 使用建议

1. **权限管理**: 根据用户角色合理分配查看和管理权限
2. **数据备份**: 定期备份产品主数据，防止意外丢失
3. **编码规范**: 严格遵循产品编码格式，避免数据混乱
4. **操作审计**: 利用创建人和更新人信息进行操作审计
