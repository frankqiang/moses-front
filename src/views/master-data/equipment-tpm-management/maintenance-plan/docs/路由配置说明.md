## 权限配置

### 开发阶段
- ✅ 当前处于开发阶段，所有权限检查已禁用
- ✅ 所有用户可以访问所有页面
- ✅ 权限点已配置但未激活（在meta中以注释形式保留）

### 生产环境权限点

#### 查看权限
- **权限点**: `mdm.tpm.maintenance-plan.view`
- **适用页面**:
  - 维护计划列表页
  - 维护计划详情页

#### 管理权限
- **权限点**: `mdm.tpm.maintenance-plan.manage`
- **适用页面**:

1. 在 `src/store/modules/permission.js` 中取消注释权限过滤函数
2. 在路由meta中取消注释权限配置
3. 确保后端权限点与前端配置一致

## 路由特性

### 1. 懒加载 ✅
所有路由组件使用动态导入（`import()`），实现按需加载：
```javascript
component: () => import('@/views/master-data/equipment-tpm-management/maintenance-plan/index')
```

### 2. 路由切换动画 ✅
在 `src/layout/components/AppMain.vue` 中配置了 `fade-transform` 过渡效果：
```vue
<transition name="fade-transform" mode="out-in">
  <router-view :key="key" />
</transition>
```

### 3. 路由参数传递 ✅
详情页和编辑页支持通过URL参数传递计划ID：
```javascript
// 详情页路由
path: 'maintenance-plans/:id'

// 组件中获取参数
this.$route.params.id
```

### 4. 面包屑导航 ✅
通过路由meta配置自动生成面包屑：
```javascript
meta: {
  title: '维护计划管理',
  icon: 'el-icon-date'
}
```

### 5. 页面标题 ✅
路由meta中的title字段用于设置浏览器标题栏：
```javascript
meta: {
  title: '维护计划管理'
}
```

### 6. 激活菜单高亮 ✅
隐藏路由通过 `activeMenu` 配置激活对应的菜单项：
```javascript
meta: {
  activeMenu: '/master-data/equipment-tpm/maintenance-plans'
}
```

### 7. 路由状态清理 ✅
通过 `router-view` 的 `:key="key"` 绑定，确保路由切换时正确清理组件状态：
```javascript
computed: {
  key() {
    return this.$route.path
  }
}
```

## 路由导航示例

### 编程式导航

```javascript
// 跳转到列表页
this.$router.push('/master-data/equipment-tpm/maintenance-plans')

// 跳转到创建页
this.$router.push('/master-data/equipment-tpm/maintenance-plans/create')

// 跳转到详情页
this.$router.push({
  name: 'MaintenancePlanDetail',
  params: { id: planId }
})

// 跳转到编辑页
this.$router.push({
  name: 'MaintenancePlanEdit',
  params: { id: planId }
})

// 返回上一页
this.$router.go(-1)
// 或
this.$router.back()
```

### 声明式导航

```vue
<!-- 列表页链接 -->
<router-link to="/master-data/equipment-tpm/maintenance-plans">
  维护计划管理
</router-link>

<!-- 详情页链接 -->
<router-link :to="`/master-data/equipment-tpm/maintenance-plans/${planId}`">
  查看详情
</router-link>

<!-- 编辑页链接 -->
<router-link :to="{ name: 'MaintenancePlanEdit', params: { id: planId } }">
  编辑
</router-link>
```

## 路由守卫

### 全局守卫
路由守卫在 `src/permission.js` 中配置：
1. 检查Token是否存在
2. 获取用户信息和角色
3. 根据角色生成可访问路由
4. 无权限时重定向到403或登录页

### 开发阶段行为
- ✅ 所有用户可访问所有路由
- ✅ 无需登录即可访问（白名单）
- ✅ 权限检查已禁用

### 生产环境行为（待激活）
- ⏳ 根据用户角色过滤路由
- ⏳ 无权限访问时重定向到403页面
- ⏳ Token过期自动刷新或重定向到登录页

## 注意事项

1. **路径命名规范**
   - 使用小写字母和中划线
   - 保持URL语义化
   - 与后端API路径保持一致

2. **组件命名规范**
   - 使用PascalCase
   - 与路由名称保持一致
   - 具有明确的语义

3. **权限配置**
   - 开发阶段权限已禁用
   - 生产环境需要激活权限检查
   - 权限点需要与后端保持一致

4. **路由参数**
   - 使用动态路由参数传递ID
   - 在组件中通过 `$route.params` 获取
   - 参数验证在组件内部进行

5. **面包屑和标题**
   - 通过meta.title配置
   - 自动生成面包屑导航
   - 自动设置浏览器标题
