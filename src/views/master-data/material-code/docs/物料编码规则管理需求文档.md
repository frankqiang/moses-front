# 物料编码规则管理需求文档

## 1. 模块概述

物料编码规则管理模块用于配置和管理物料编码的生成规则，包括不同类型的编码规则（纯数字流水号、前缀+流水号、自定义规则等），以及相关的二维码配置。该模块是物料管理系统的基础配置模块，支持用户灵活定义不同类型物料的编码规则，确保编码的唯一性和可识别性。

## 2. 功能需求

### 2.1 规则列表管理

- **查询规则列表**：支持按规则名称和规则类型查询规则列表
- **创建规则**：支持创建新的编码规则，包括填写规则信息和预览生成的编码
- **编辑规则**：支持编辑现有的编码规则，修改规则配置
- **设置默认规则**：支持将某个规则设置为默认规则
- **批量删除**：支持批量删除选中的规则
- **列设置**：支持自定义列表显示的列
- **导入导出**：支持导入导出规则配置

### 2.2 规则配置功能

- **基础信息配置**：配置规则名称、类型等基础信息
- **流水号配置**：配置流水号的位数、当前值、步长等参数
- **前缀配置**：配置编码前缀（适用于"前缀+流水号"类型）
- **自定义规则配置**：配置自定义编码规则（适用于"自定义规则"类型）
- **二维码配置**：配置编码对应的二维码内容、尺寸、纠错级别等参数

## 3. 数据结构

### 3.1 物料编码规则表

| 字段名 | 类型 | 说明 | 示例值 |
| --- | --- | --- | --- |
| id | Integer | 规则ID | 1 |
| name | String | 规则名称 | "标准料框编码规则" |
| type | String | 规则类型 | "prefix_numeric" |
| prefix | String | 前缀 | "BIN-" |
| sequenceLength | Integer | 序列号长度 | 6 |
| currentValue | Integer | 当前值 | 1 |
| stepValue | Integer | 步长 | 1 |
| customRule | String | 自定义规则说明 | "年月日+三位流水号" |
| qrCodeContent | String | 二维码内容 | "id_only" |
| qrCodeSize | String | 二维码尺寸 | "medium" |
| errorCorrectionLevel | String | 纠错级别 | "M" |
| isDefault | Boolean | 是否默认 | true |
| createTime | DateTime | 创建时间 | "2023-10-01T14:00:00Z" |
| updateTime | DateTime | 更新时间 | "2023-10-01T14:00:00Z" |

## 4. 接口设计

### 4.1 获取物料编码规则列表

- **URL**: `/mes/master-data/material-code/list`
- **方法**: GET
- **参数**:
  - ruleName: 规则名称（可选，模糊匹配）
  - ruleType: 规则类型（可选，精确匹配）
  - page: 页码（可选，默认1）
  - limit: 每页条数（可选，默认10）
- **响应**:
  ```json
  {
    "code": 20000,
    "data": {
      "items": [
        {
          "id": 1,
          "name": "标准料框编码规则",
          "type": "prefix_numeric",
          "prefix": "BIN-",
          "sequenceLength": 6,
          "currentValue": 1,
          "stepValue": 1,
          "customRule": "",
          "qrCodeContent": "id_only",
          "qrCodeSize": "medium",
          "errorCorrectionLevel": "M",
          "isDefault": true,
          "createTime": "2023-10-01T14:00:00.000Z",
          "updateTime": "2023-10-01T14:00:00.000Z"
        }
      ],
      "total": 1
    }
  }
  ```

### 4.2 获取物料编码规则详情

- **URL**: `/mes/master-data/material-code/detail/:id`
- **方法**: GET
- **参数**: 无（ID在URL中）
- **响应**:
  ```json
  {
    "code": 20000,
    "data": {
      "id": 1,
      "name": "标准料框编码规则",
      "type": "prefix_numeric",
      "prefix": "BIN-",
      "sequenceLength": 6,
      "currentValue": 1,
      "stepValue": 1,
      "customRule": "",
      "qrCodeContent": "id_only",
      "qrCodeSize": "medium",
      "errorCorrectionLevel": "M",
      "isDefault": true,
      "createTime": "2023-10-01T14:00:00.000Z",
      "updateTime": "2023-10-01T14:00:00.000Z"
    }
  }
  ```

### 4.3 创建物料编码规则

- **URL**: `/mes/master-data/material-code/create`
- **方法**: POST
- **参数**:
  ```json
  {
    "name": "新料框编码规则",
    "type": "prefix_numeric",
    "prefix": "NEW-",
    "sequenceLength": 6,
    "currentValue": 1,
    "stepValue": 1,
    "customRule": "",
    "qrCodeContent": "id_only",
    "qrCodeSize": "medium",
    "errorCorrectionLevel": "M",
    "isDefault": false
  }
  ```
- **响应**:
  ```json
  {
    "code": 20000,
    "data": {
      "id": 2
    }
  }
  ```

### 4.4 更新物料编码规则

- **URL**: `/mes/master-data/material-code/update`
- **方法**: PUT
- **参数**:
  ```json
  {
    "id": 2,
    "name": "更新后的编码规则",
    "type": "prefix_numeric",
    "prefix": "UPD-",
    "sequenceLength": 6,
    "currentValue": 100,
    "stepValue": 5,
    "customRule": "",
    "qrCodeContent": "id_only",
    "qrCodeSize": "large",
    "errorCorrectionLevel": "H",
    "isDefault": false
  }
  ```
- **响应**:
  ```json
  {
    "code": 20000,
    "data": {
      "id": 2
    }
  }
  ```

### 4.5 设置默认规则

- **URL**: `/mes/master-data/material-code/set-default`
- **方法**: PUT
- **参数**:
  ```json
  {
    "id": 2
  }
  ```
- **响应**:
  ```json
  {
    "code": 20000,
    "data": {
      "id": 2
    }
  }
  ```

### 4.6 生成预览编码

- **URL**: `/mes/master-data/material-code/preview`
- **方法**: POST
- **参数**:
  ```json
  {
    "type": "prefix_numeric",
    "prefix": "TEST-",
    "sequenceLength": 6,
    "currentValue": 1
  }
  ```
- **响应**:
  ```json
  {
    "code": 20000,
    "data": {
      "previewCode": "TEST-000001"
    }
  }
  ```

## 5. 页面设计

### 5.1 规则列表页

- **主要组件**：
  - 搜索表单：用于输入查询条件
  - 表格工具栏：包含新增、批量删除、导入导出、列设置等功能
  - 数据表格：展示规则列表，包含操作列
  - 分页：控制页码和每页显示条数

- **列表操作按钮**：
  - 编辑：打开编辑抽屉
  - 设为默认：将规则设置为默认规则（非默认规则才显示）

### 5.2 规则编辑表单

- **表单字段**：
  - 规则名称：输入框
  - 规则类型：单选框（纯数字流水号/前缀+流水号/自定义规则）
  - 前缀：输入框（仅当类型为"前缀+流水号"时显示）
  - 序列号长度：数字输入框
  - 当前值：数字输入框
  - 步长：数字输入框
  - 自定义规则说明：文本域（仅当类型为"自定义规则"时显示）
  - 二维码内容：选择框
  - 二维码尺寸：选择框
  - 纠错级别：选择框
  - 是否默认：开关

## 6. 业务规则

- 系统中必须有且只有一个默认规则
- 当设置某个规则为默认时，之前的默认规则会自动变为非默认
- 序列号长度最小为1，最大为12
- 当前值必须大于等于0
- 步长必须大于等于1
- 规则名称不可重复
- 规则类型为"自定义规则"时，不需要配置序列号相关参数，但必须填写自定义规则说明

## 7. 与其他模块的关联

- **物料管理模块**：使用配置的编码规则生成物料编码
- **仓库管理模块**：使用配置的编码规则生成库位编码
- **打印管理模块**：使用配置的二维码参数生成二维码

## 8. 权限控制

- **查看权限**：允许查看物料编码规则列表和详情
- **编辑权限**：允许创建、编辑、设置默认规则
- **删除权限**：允许删除规则
- **导入导出权限**：允许导入导出规则数据

## 9. 非功能需求

- **性能要求**：
  - 列表查询响应时间不超过2秒
  - 编辑保存响应时间不超过1秒
  - 预览生成编码响应时间不超过0.5秒

- **兼容性**：
  - 支持Chrome、Firefox、Edge浏览器最新版本
  - 支持1366x768及以上分辨率显示

- **安全性**：
  - 所有接口需经过身份验证和权限验证
  - 敏感操作（如设置默认规则）需进行二次确认

## 10. 测试要点

- 验证各种规则类型下编码生成的正确性
- 验证规则设置为默认后，其他规则是否正确变为非默认
- 验证批量操作功能是否正常
- 验证列设置和本地存储功能是否正常
- 验证导入导出功能是否正常
- 验证表单验证规则是否正确
- 验证各种边界条件下系统的稳定性
