# 工艺参数管理前端开发任务清单

## 项目概述

基于《20-MDM-主数据管理》中3.1.6节工艺参数管理需求，本模块需提供铝箔退火工艺模板的全流程维护能力，覆盖模板主数据、版本管理、温度曲线段、保护气氛、循环风机等关键参数，并与铝箔产品主数据实现关联。前端实现必须复用项目全局组件体系（`SearchForm`、`TableToolbar`、`BaseTable`、`EnhancedForm`、`Drawer`、`ActionButtons`、`StatusTag`、`OverflowTagsPopover`、`ColumnSettings`、`ExportButton` 等），遵循 `process-management/operations` 模块的目录结构与配置驱动模式，确保交互体验、代码风格、消息提示与现有主数据模块保持一致。

## 🚨 紧急开发模式说明

**开发原则：** 在紧急阶段优先打通模板查询、创建、版本审批、温度曲线管理的核心流程；复杂交互（拖拽编辑、智能推荐等）视后续阶段逐步实现。所有操作遵循统一响应格式，优先展示后端 `message`，禁止添加权限校验与 Mock 数据。

**优先级说明：**

- 🔴 **P0 - 核心必需（立即实施）**
- 🟡 **P1 - 重要功能（第二阶段）**
- 🟢 **P2 - 优化功能（后续完善）**

## 🎯 紧急开发模式总结

### ✅ 当前阶段必须完成（P0）：

- 完成 API、配置、搜索、列表、表单、版本中心、曲线可视化、页面集成八大核心任务。

- 严格使用全局组件体系，禁止 Mock、权限判断、硬编码提示。

### ⏳ 可以简化实现的功能：

- 曲线拖拽编辑、版本差异高亮可暂用基础实现占位。
- 搜索条件记忆、路由 Query 同步、批量操作可后续补齐。
- 危险操作日志、埋点监控可在上线前集中补充。

### ❌ 可以完全暂缓的功能：

- 智能推荐、自动参数校验策略、嵌套新建关联资源。
- 高级导出（PDF、Excel 模板）、视觉回归测试。
- 权限体系集成（上线前统一补齐）。

### 🚀 开发建议：

1. **接口优先：** 先完成 API 封装与联调，确保数据源稳定。
2. **配置驱动：** 搜索、表单、表格、曲线参数统一通过配置管理，减少重复实现。
3. **统一消息：** 所有成功/失败提示使用后端返回信息，配合项目兜底文案。
4. **组件复用：** 严格复用全局组件，组件不足时先评估复用或扩展现有组件。
5. **联调同步：** 与铝箔产品、生产计划团队保持沟通，确认关联接口、审批流程，定期更新自测记录。
