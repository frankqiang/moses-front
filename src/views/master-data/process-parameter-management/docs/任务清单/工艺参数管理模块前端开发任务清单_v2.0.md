# 工艺参数管理模块前端开发任务清单 v2.0

## 项目概述

基于退火车间实际工艺执行需求，开发工艺参数管理功能的前端界面。该模块负责展示和管理铝箔退火工艺模板，每个模板包含固定12个控温段，每段包含炉温、料温、时间、循环风机、负压风机、吹洗风机等完整参数。模块集成Vue 2.x + Element UI，提供直观的工艺参数配置界面、版本管理、审批流程可视化，支持工艺模板的创建、编辑、复制、对比等功能，为退火任务执行提供标准化的工艺参数配置平台。

## 📖 后端接口文档参考

### 主要接口文档

本模块所有接口均已在后端实现（v2.0架构），接口定义参见：
- **路由文件**: `src/routes/v1/modules/mdm/processTemplate.route.js`
- **控制器文件**: `src/controllers/modules/mdm/processTemplate.controller.js`
- **Swagger定义**: `src/docs/components/modules/mdm/processTemplate/`

### 核心接口列表

1. **创建工艺模板**: `POST /v1/mdm/process-templates`
2. **查询模板列表**: `GET /v1/mdm/process-templates`
3. **获取模板详情**: `GET /v1/mdm/process-templates/:templateId`
4. **更新版本参数**: `PATCH /v1/mdm/process-templates/:templateId/versions/:versionId`
5. **提交审批**: `PATCH /v1/mdm/process-templates/:templateId/versions/:versionId/submit-approval`
6. **审批通过**: `POST /v1/mdm/process-templates/:templateId/versions/:versionId/approve`
7. **审批驳回**: `POST /v1/mdm/process-templates/:templateId/versions/:versionId/reject`
8. **撤回审批**: `POST /v1/mdm/process-templates/:templateId/versions/:versionId/withdraw`
9. **作废版本**: `POST /v1/mdm/process-templates/:templateId/versions/:versionId/void`
10. **查询版本历史**: `GET /v1/mdm/process-templates/:templateId/versions`
11. **对比版本**: `GET /v1/mdm/process-templates/:templateId/versions/compare`
12. **复制模板**: `POST /v1/mdm/process-templates/:templateId/copy`
13. **创建新版本**: `POST /v1/mdm/process-templates/:templateId/versions/create`
14. **快速生效**: `POST /v1/mdm/process-templates/:templateId/versions/:versionId/activate`
15. **查询引用情况**: `GET /v1/mdm/process-templates/:templateId/usage`
16. **删除模板**: `DELETE /v1/mdm/process-templates/:templateId`

## 🚨 紧急开发模式说明

**开发原则：** 在当前项目时间紧张的情况下，采用"能用即可"的原则，优先确保核心功能的可用性和主要业务流程的正常执行。

**优先级说明：**

- 🔴 **P0 - 核心必需（立即实施）：** 系统基本运行的最低要求，必须在第一阶段完成
- 🟡 **P1 - 重要功能（第二阶段）：** 影响用户体验但不阻塞主流程的功能
- 🟢 **P2 - 优化功能（后续完善）：** 可以暂缓实现，待后续优化阶段逐步完善

## 🔑 关键业务规则提醒

1. **12段固定结构：** 每个模板必须包含且仅包含12段，段序号1-12连续不跳号
2. **料温限制：** 料温设置不能高于炉温设置，建议低于10-20℃
3. **状态流转：** 草稿 → 待审批 → 生效 → 历史，驳回后回到草稿
4. **版本控制：** 同一模板可有多个版本，但同时只能有一个生效版本
5. **引用保护：** 被生产计划引用的模板不允许删除或禁用
6. **权限控制：** 查看、管理、审批三级权限清晰分离
7. **参数精度：** 所有小数参数保留2位小数
8. **控温方式：** v2.0版本固定为"定时定温"
9. **运行时间：** 创建时可为空，在任务执行时填写实际值
10. **循环风机：** 只有三个档位（低速/中速/高速）
