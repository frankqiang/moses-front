# Moses API 工艺参数管理模块接口文档

## 概述

本文档详细说明了 Moses API 工艺参数管理模块的所有接口，包括工艺模板的创建、查询、版本维护、审批流、复制、快速生效、引用检查以及删除操作。**本文档严格基于实际代码实现编写**，确保前端及上下游系统能够准确对接。

该模块用于集中管理铝箔退火工艺模板，支持模板主数据、温度曲线分段、保护气氛参数、循环风机参数以及与产品主数据的关联，保障生产排程与执行环节获取一致的标准化工艺参数。

### API 基础信息

- **基础 URL**: `http://localhost:3000/v1` (开发环境)
- **API 版本**: v1
- **认证方式**: JWT Bearer Token
- **数据格式**: JSON
- **字符编码**: UTF-8
- **Content-Type**: application/json

### Swagger 文档

项目已集成 Swagger 文档，可通过以下地址访问：

- **开发环境**: http://localhost:3000/v1/docs

Swagger 中的标签 `ProcessTemplates` 与本文档保持一致，所有 Schema 和 Response 组件均已在 `src/docs` 目录下定义。

**响应字段说明**：

- `success`: 布尔值，表示请求是否成功
- `data`: 成功时返回具体业务数据，失败时为空
- `error`: 失败时返回错误信息，成功时为空
- `message`: 成功时的提示信息
- `error.code`: 标准化错误码，见本文档错误码章节
- `error.details.validationErrors`: 参数校验错误列表（当验证失败时返回）
- `meta`: 请求元信息，包含时间戳、请求 ID 与版本号

## 工艺参数管理接口详细说明

> **权限约定**：
> - `mdm.process-template.manage`：模板创建、编辑、复制、快速生效、删除
> - `mdm.process-template.view`：模板查询、详情、版本列表、对比、引用检查
> - `mdm.process-template.approval`：提交审批、审批通过/驳回、撤回、作废

### 1. 创建工艺模板及首个版本

**接口路径**: `POST /v1/mdm/process-templates`

**功能描述**: 创建工艺模板主体信息，并在事务中同时创建首个版本及其温度段、保护气氛、风机参数配置。创建完成后，模板处于“草稿”状态，版本标记为最新版本。

**认证要求**: 需要 Bearer Token，需具备 `mdm.process-template.manage` 权限。

**请求头**:

```
Authorization: Bearer <access_token>
Content-Type: application/json
```

**请求参数**:

| 参数名                   | 类型     | 必填 | 限制                      | 描述                               | 示例                       |
| ------------------------ | -------- | ---- | ------------------------- | ---------------------------------- | -------------------------- |
| templateCode             | string   | 是   | `PT-` 开头，最大 100 字符 | 工艺模板编码，系统内唯一           | "PT-1100-H18-ANNEALING-V1" |
| templateName             | string   | 是   | 最大 200 字符             | 工艺模板名称                       | "铝箔退火工艺模板"         |
| description              | string   | 否   | 最大 2000 字符            | 模板描述                           | "退火炉 1# 使用"           |
| applicableProductIds     | string[] | 否   | UUID 列表                 | 适用的产品 ID 集合，需存在且未停产 | ["f3f...", "c9b..."]       |
| applicableAlloyGrades    | string[] | 否   | 每项最大 50 字符          | 适用合金牌号                       | ["1100", "8011"]           |
| applicableThicknessRange | string   | 否   | `min-max` 格式            | 适用厚度范围 (mm)                  | "0.005-0.007"              |
| applicableWidthRange     | string   | 否   | `min-max` 格式            | 适用宽度范围 (mm)                  | "1000-1600"                |
| versionNumber            | string   | 是   | `v1.0` / `1.0` 格式       | 首个版本号                         | "v1.0"                     |
| versionDescription       | string   | 否   | 最大 2000 字符            | 首个版本描述                       | "首次建立"                 |
| segments                 | object[] | 是   | 至少 1 段                 | 温度曲线段配置，详见下表           | -                          |
| atmosphereSettings       | object[] | 是   | 至少 1 条                 | 保护气氛参数配置                   | -                          |
| fanSettings              | object[] | 是   | 至少 1 条                 | 循环风机参数配置                   | -                          |

**segments 元素字段**:

| 字段              | 类型    | 必填 | 描述                              | 示例           |
| ----------------- | ------- | ---- | --------------------------------- | -------------- |
| segmentOrder      | integer | 是   | 段序号，从 1 开始连续递增         | 1              |
| segmentType       | string  | 是   | `升温`/`保温`/`降温`/`快速冷却`   | "升温"         |
| targetTemperature | number  | 是   | -100 ~ 1500，单位 °C              | 450            |
| duration          | integer | 是   | 1 ~ 10080，单位分钟               | 240            |
| heatingRate       | number  | 否   | 升温段需填，0.1~500 °C/h          | 30             |
| coolingRate       | number  | 否   | 降温/快速冷却段需填，0.1~500 °C/h | 25             |
| description       | string  | 否   | 最大 500 字符                     | "升温到 450°C" |

**atmosphereSettings 元素字段**:

| 字段             | 类型    | 必填 | 描述                                             | 示例       |
| ---------------- | ------- | ---- | ------------------------------------------------ | ---------- |
| atmosphereType   | string  | 是   | `纯氮气`/`氢氮混合气`/`氩气`/`氮氢混合气`/`其他` | "纯氮气"   |
| flowRate         | number  | 是   | 0.1 ~ 1000 (m³/h)                                | 80         |
| flowRateMin      | number  | 否   | 0.1 ~ 1000，<= flowRateMax                       | 60         |
| flowRateMax      | number  | 否   | 0.1 ~ 1000                                       | 100        |
| pressure         | number  | 否   | 0 ~ 100000 (Pa)                                  | 101325     |
| pressureMin      | number  | 否   | 0 ~ 100000，<= pressureMax                       | 101000     |
| pressureMax      | number  | 否   | 0 ~ 100000                                       | 102000     |
| supportsHydrogen | boolean | 否   | 氢气混合气类型时必须为 true                      | true       |
| description      | string  | 否   | 最大 500 字符                                    | "氮气保护" |

**fanSettings 元素字段**:

| 字段         | 类型    | 必填 | 描述                                 | 示例         |
| ------------ | ------- | ---- | ------------------------------------ | ------------ |
| frequency    | number  | 是   | 0.1 ~ 100 Hz                         | 45           |
| frequencyMin | number  | 否   | 0.1 ~ 100，<= frequencyMax           | 35           |
| frequencyMax | number  | 否   | 0.1 ~ 100                            | 55           |
| segmentOrder | integer | 否   | 指定适用段序号，1~1000，为空表示全局 | 1            |
| mode         | string  | 否   | 默认 `变频`                          | "联动"       |
| description  | string  | 否   | 最大 500 字符                        | "升温段风机" |

### 4. 更新工艺模板草稿/驳回版本

**接口路径**: `PATCH /v1/mdm/process-templates/{templateId}/versions/{versionId}`

**功能描述**: 在模板处于草稿/待审批/历史状态且版本处于草稿/驳回时，允许更新模板主数据与指定版本的参数配置。更新操作使用事务实现全量替换。

**认证要求**: 需要 Bearer Token，需具备 `mdm.process-template.manage` 权限。

**路径参数**: 同上。

**请求体**: 字段与创建接口一致，均为可选；若未提供将保持原值。`segments`/`atmosphereSettings`/`fanSettings` 存在时将整体替换。

**成功响应** (HTTP 200): 返回更新后的版本详情，结构同创建响应中的 `latestVersion`。

- 模板状态必须在 `草稿/待审批/历史`，否则返回 `PTM_011`。
- 版本状态必须为 `草稿/驳回`，否则返回 `PTM_006`。

### 5. 提交工艺模板版本审批

**接口路径**: `PATCH /v1/mdm/process-templates/{templateId}/versions/{versionId}/submit-approval`

**功能描述**: 将草稿/驳回版本提交至审批流程。系统会校验同一模板是否存在其他“待审批”版本，避免并行审批冲突。

| 字段            | 类型   | 必填 | 描述                                            | 示例         |

### 15. 删除工艺模板

**接口路径**: `DELETE /v1/mdm/process-templates/{templateId}`

**功能描述**: 对指定工艺模板执行软删除。删除前需确保模板未处于生效状态且不存在引用关系。操作会在事务中将模板版本及相关段/气氛/风机参数标记为删除，并解除与产品的关联。

**认证要求**: 需要 Bearer Token，需具备 `mdm.process-template.manage` 权限。

**业务规则**:

1. 若模板状态为 `生效`，直接返回错误 (`PTM_011`) 并提示先撤销生效版本。
2. 会调用引用检查 (`processTemplateReferenceService.assertProcessTemplateNotInUse`)，若存在引用返回 `PTM_016`。
3. 删除操作标记模板及其版本、段、气氛、风机参数的 `isDeleted = true`。

## 安全与权限说明

- 所有接口默认要求通过 `auth` 中间件验证 JWT Token。
- 新增、编辑、删除、复制、快速生效等敏感操作需具备 `mdm.process-template.manage` 权限。
- 审批相关操作需具备 `mdm.process-template.approval` 权限，通过审批服务验证操作者身份。
- 查询类接口需具备 `mdm.process-template.view` 权限。
- 审批日志、引用校验均在服务层记录 `operatorId` 与操作结果，便于审计追踪。

## 使用建议

1. 创建模板后建议立即提交审批或复制基础模板，避免重复录入。
2. 修改草稿/驳回版本时请注意全量替换段、气氛、风机参数；若仅需小幅调整，可先读取详情再提交完整数据。
3. 生效版本作废或删除模板前务必确认引用情况，避免影响生产计划。
4. 审批流程支持单级审批；如需多级审批扩展，可在审批服务新增策略。
5. 引用日志 (`processTemplateReferenceService.logActivationChange`) 可用于与生产计划、设备通讯等模块联动。
