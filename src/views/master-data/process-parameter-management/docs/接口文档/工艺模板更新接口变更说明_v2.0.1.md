# 工艺模板更新接口变更说明文档 v2.0.1

> **版本**：v2.0.1
> **更新日期**：2025-10-16
> **目标读者**：前端开发人员
> **文档目的**：说明工艺模板更新接口的业务规则变更和新增接口

---

## 📌 变更概述

### 变更背景

在 v2.0 版本中，我们发现了一个**严重的业务逻辑问题**：

- 原来的"更新版本接口"允许同时修改**模板级别信息**（如模板名称、适用产品）和**版本级别信息**（如版本描述、工艺参数）
- 这导致一个危险场景：当模板有多个版本（如 v1.0 生效中，v2.0 草稿中），用户在编辑 v2.0 时修改了模板名称，结果 v1.0 的模板名称也被改了
- 因为模板名称是**所有版本共享**的信息，不应该在编辑草稿版本时随意修改

### 解决方案

**v2.0.1 版本实施了严格的职责分离**：

1. **更新版本接口**：只允许修改版本独有的信息（版本描述、工艺参数）
2. **更新模板接口**（新增）：专门用于修改所有版本共享的信息（模板名称、适用产品等）

### 影响范围

✅ **不影响现有功能**：
- 查询接口无变化
- 创建接口无变化
- 审批流程接口无变化

⚠️ **需要调整的功能**：
- 编辑工艺模板/版本的页面
- 需要区分"编辑模板信息"和"编辑版本信息"

## 🔄 接口变更详情

### 变更 1：更新版本接口限制（原有接口）

**接口路径**：`PATCH /v1/mdm/process-templates/{templateId}/versions/{versionId}`

#### 变更前（v2.0）

```
✅ 允许修改：templateName, description, versionDescription, segments,
            applicableProductIds, applicableAlloyGrades,
            applicableThicknessRange, applicableWidthRange
```

#### 变更后（v2.0.1）

```
✅ 仅允许修改：versionDescription（版本描述）, segments（12段工艺参数）
❌ 禁止修改：templateName, description, applicableProductIds,
            applicableAlloyGrades, applicableThicknessRange,
            applicableWidthRange
```

#### 错误响应变化

如果尝试修改模板级别字段，会返回 **400 错误**：

```json
{
  "success": false,
  "error": {
    "code": "PTM_011",
    "message": "更新版本接口不允许修改模板级别的信息（模板信息为所有版本共享）",
    "details": {
      "rejectedFields": ["templateName"],
      "allowedFields": ["versionDescription", "segments"],
      "hint": "如需修改模板名称、描述等共享信息，请使用更新模板接口"
    }
  }
}
```

---

### 变更 2：新增更新模板接口

**接口路径**：`PATCH /v1/mdm/process-templates/{templateId}`

**功能说明**：专门用于修改所有版本共享的模板信息

#### 允许修改的字段

```
✅ 允许修改：templateName（模板名称）
            description（模板描述）
            applicableProductIds（适用产品ID列表）
            applicableAlloyGrades（适用合金牌号）
            applicableThicknessRange（适用厚度范围）
            applicableWidthRange（适用宽度范围）

❌ 禁止修改：versionDescription（版本描述）
            segments（工艺参数）
```

#### 状态限制

**重要**：此接口只允许在特定模板状态下调用：

| 模板状态 | 是否允许 | 原因                                       |
| -------- | -------- | ------------------------------------------ |
| 草稿     | ✅ 允许   | 模板还未正式使用，可以自由修改             |
| 历史     | ✅ 允许   | 模板已过期，修改不会影响生产               |
| 生效     | ❌ 禁止   | 有版本正在生产使用中，禁止修改避免影响生产 |
| 待审批   | ❌ 禁止   | 有版本在审批流程中，禁止修改避免影响审批   |

#### 错误响应

**场景 1**：尝试修改版本级别字段

```json
{
  "success": false,
  "error": {
    "code": "PTM_011",
    "message": "更新模板接口不允许修改版本级别的信息，请使用更新版本接口",
    "details": {
      "rejectedFields": ["segments"],
      "allowedFields": ["templateName", "description", ...]
    }
  }
}
```

**场景 2**：模板状态不允许修改

```json
{
  "success": false,
  "error": {
    "code": "PTM_011",
    "message": "仅草稿或历史状态的模板允许修改模板信息（避免影响生效版本和审批流程）",
    "details": {
      "templateId": "...",
      "currentStatus": "生效",
      "allowedStatuses": ["草稿", "历史"],
      "hint": "如果模板有生效版本或待审批版本，请先处理这些版本"
    }
  }
}
```

## 📊 两个接口的对比

| 特性         | 更新模板接口                                                                                                           | 更新版本接口                             |
| ------------ | ---------------------------------------------------------------------------------------------------------------------- | ---------------------------------------- |
| **接口路径** | `PATCH /:templateId`                                                                                                   | `PATCH /:templateId/versions/:versionId` |
| **修改范围** | 模板级别（所有版本共享）                                                                                               | 版本级别（单个版本独有）                 |
| **允许修改** | templateName, description, applicableProductIds, applicableAlloyGrades, applicableThicknessRange, applicableWidthRange | versionDescription, segments             |
| **状态要求** | 草稿 或 历史                                                                                                           | 草稿 或 驳回                             |
| **影响范围** | 影响该模板下的**所有版本**                                                                                             | 仅影响**当前版本**                       |
| **权限要求** | mdm.process-template.manage                                                                                            | mdm.process-template.manage              |

## 🎯 业务场景说明

### 场景 1：创建新工艺模板

**流程**：

1. 用户填写模板基本信息（模板名称、描述、适用产品等）
2. 填写首个版本信息（版本号、版本描述）
3. 配置 12 段工艺参数
4. 调用创建接口 `POST /v1/mdm/process-templates`

**涉及接口**：
- `POST /v1/mdm/process-templates` - 创建模板

**状态变化**：
- 模板状态：草稿
- 版本状态：草稿

---

### 场景 2：编辑草稿模板（模板信息）

**前提条件**：
- 模板状态必须是"草稿"或"历史"
- 用户有 manage 权限

**流程**：

1. 用户在模板详情页点击"编辑模板信息"
2. 修改模板名称、描述、适用产品等
3. 调用更新模板接口 `PATCH /v1/mdm/process-templates/{templateId}`
4. 保存成功后，所有版本看到的模板信息都会更新

**涉及接口**：
- `PATCH /v1/mdm/process-templates/{templateId}` - 更新模板信息

**影响范围**：
- ⚠️ 修改会影响该模板下的**所有版本**

---

### 场景 3：编辑草稿版本（版本信息和工艺参数）

**前提条件**：
- 版本状态必须是"草稿"或"驳回"
- 用户有 manage 权限

**流程**：

1. 用户在版本详情页点击"编辑版本"
2. 修改版本描述
3. 调整 12 段工艺参数（温度、时间、风机等）
4. 调用更新版本接口 `PATCH /v1/mdm/process-templates/{templateId}/versions/{versionId}`
5. 保存成功后，只有当前版本的信息被更新

**涉及接口**：
- `PATCH /v1/mdm/process-templates/{templateId}/versions/{versionId}` - 更新版本信息

**影响范围**：
- ✅ 仅影响**当前版本**，不影响其他版本

---

### 场景 4：在生效模板下创建新版本草稿

**前提条件**：
- 模板状态：生效（有 v1.0 生效版本在使用）
- 用户有 manage 权限

**流程**：

1. 用户在模板详情页点击"创建新版本"
2. 基于 v1.0 复制创建 v2.0（状态：草稿）
3. **可以修改 v2.0 的版本信息和工艺参数**
4. **不能修改模板信息**（因为模板状态是"生效"）
5. v2.0 编辑完成后提交审批
6. 审批通过后，v2.0 变为生效，v1.0 变为历史

**涉及接口**：
- `POST /v1/mdm/process-templates/{templateId}/versions/create` - 创建新版本
- `PATCH /v1/mdm/process-templates/{templateId}/versions/{versionId}` - 编辑 v2.0 草稿
- ❌ **不能调用**：`PATCH /v1/mdm/process-templates/{templateId}` （模板状态不允许）

**关键点**：
- ✅ v1.0 生效中时，可以创建和编辑 v2.0 草稿
- ❌ 但不能修改模板信息（避免影响 v1.0）
- ✅ v2.0 审批通过后，模板信息仍然保持不变

---

### 场景 5：修改历史模板的信息

**前提条件**：
- 模板状态：历史（所有版本都已过期）
- 用户有 manage 权限

**流程**：

1. 用户查看历史模板，发现模板名称有误
2. 点击"编辑模板信息"
3. 修改模板名称和描述
4. 调用更新模板接口 `PATCH /v1/mdm/process-templates/{templateId}`
5. 保存成功后，历史记录的模板信息被修正

**涉及接口**：
- `PATCH /v1/mdm/process-templates/{templateId}` - 更新模板信息

**使用场景**：
- 修正历史数据的错误
- 完善历史模板的文档信息

## 📝 接口调用清单

### 查询操作

| 功能         | 接口                                              | 方法 | 说明   |
| ------------ | ------------------------------------------------- | ---- | ------ |
| 查询模板列表 | `/v1/mdm/process-templates`                       | GET  | 无变化 |
| 查询模板详情 | `/v1/mdm/process-templates/{templateId}`          | GET  | 无变化 |
| 查询版本列表 | `/v1/mdm/process-templates/{templateId}/versions` | GET  | 无变化 |

### 创建操作

| 功能       | 接口                                                     | 方法 | 说明   |
| ---------- | -------------------------------------------------------- | ---- | ------ |
| 创建模板   | `/v1/mdm/process-templates`                              | POST | 无变化 |
| 创建新版本 | `/v1/mdm/process-templates/{templateId}/versions/create` | POST | 无变化 |

### 更新操作（⚠️ 有变化）

| 功能         | 接口                                                          | 方法  | 变化     | 允许修改     |
| ------------ | ------------------------------------------------------------- | ----- | -------- | ------------ |
| 更新模板信息 | `/v1/mdm/process-templates/{templateId}`                      | PATCH | **新增** | 模板级别字段 |
| 更新版本信息 | `/v1/mdm/process-templates/{templateId}/versions/{versionId}` | PATCH | **限制** | 版本级别字段 |

### 审批操作

| 功能     | 接口                                                                          | 方法  | 说明   |
| -------- | ----------------------------------------------------------------------------- | ----- | ------ |
| 提交审批 | `/v1/mdm/process-templates/{templateId}/versions/{versionId}/submit-approval` | PATCH | 无变化 |
| 审批通过 | `/v1/mdm/process-templates/{templateId}/versions/{versionId}/approve`         | POST  | 无变化 |
| 审批驳回 | `/v1/mdm/process-templates/{templateId}/versions/{versionId}/reject`          | POST  | 无变化 |
