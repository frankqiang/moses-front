### 4. 更新工艺模板基本信息

**接口路径**: `PATCH /v1/mdm/process-templates/{templateId}`

**功能描述**:

更新模板级别的共享信息（模板名称、描述、适用产品等）。此接口用于修改所有版本共享的模板信息，与更新版本接口形成职责分离。

**业务规则**:

- ✅ **允许修改**：`templateName`（模板名称）、`description`（模板描述）、`applicableProductIds`（适用产品）、`applicableAlloyGrades`（适用合金牌号）、`applicableThicknessRange`（适用厚度范围）、`applicableWidthRange`（适用宽度范围）
- ❌ **禁止修改**：`versionDescription`（版本描述）、`segments`（12段工艺参数）
- ⚠️ **状态限制**：仅在模板状态为"草稿"或"历史"时允许修改
- 📌 **影响范围**：修改会影响该模板下的**所有版本**（因为这些信息是共享的）

**认证要求**: 需要 Bearer Token，需要 `mdm.process-template.manage` 权限

**请求头**:

```
Authorization: Bearer <access_token>
Content-Type: application/json
```

**路径参数**:

| 参数名     | 类型   | 必填 | 描述         | 示例                |
| ---------- | ------ | ---- | ------------ | ------------------- |
| templateId | string | 是   | 模板ID(UUID) | "template-uuid-001" |

**请求参数**:

| 参数名                   | 类型   | 必填 | 限制            | 描述           | 示例                     |
| ------------------------ | ------ | ---- | --------------- | -------------- | ------------------------ |
| templateName             | string | 否   | 最大200字符     | 工艺模板名称   | "1100合金标准退火工艺V2" |
| description              | string | 否   | 最大2000字符    | 工艺模板描述   | "优化后的退火工艺"       |
| applicableProductIds     | array  | 否   | UUID数组        | 适用产品ID列表 | ["uuid1", "uuid2"]       |
| applicableAlloyGrades    | string | 否   | 最大500字符     | 适用合金牌号   | "1100,8011,3003"         |
| applicableThicknessRange | string | 否   | 格式：0.005-0.1 | 适用厚度范围   | "0.005-0.15"             |
| applicableWidthRange     | string | 否   | 格式：500-1500  | 适用宽度范围   | "500-1800"               |

**请求示例**:

```bash
curl -X PATCH http://localhost:3000/v1/mdm/process-templates/template-uuid-001 \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..." \
  -d '{
    "templateName": "1100合金标准退火工艺V2",
    "description": "优化版本，提升效率",
    "applicableAlloyGrades": "1100,8011"
  }'
```

**错误示例 - 尝试修改版本级别信息**:

```bash
# ❌ 错误：不允许修改版本信息
curl -X PATCH http://localhost:3000/v1/mdm/process-templates/template-uuid-001 \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..." \
  -d '{
    "templateName": "新名称",
    "segments": []
  }'

# 响应 400 Bad Request:
{
  "success": false,
  "error": {
    "code": "PTM_011",
    "message": "更新模板接口不允许修改版本级别的信息，请使用更新版本接口",
    "details": {
      "rejectedFields": ["segments"],
      "allowedFields": ["templateName", "description", "applicableProductIds", "applicableAlloyGrades", "applicableThicknessRange", "applicableWidthRange"]
    }
  }
}
```

**成功响应** (HTTP 200):

响应数据结构与"获取工艺模板详情"接口相同，返回更新后的完整模板信息（包括所有版本列表）。

**错误响应**:

| HTTP状态码 | 错误码           | 错误消息                   | 说明                                          | 处理建议                                         |
| ---------- | ---------------- | -------------------------- | --------------------------------------------- | ------------------------------------------------ |
| 400        | VALIDATION_ERROR | 请求参数验证失败           | 请求参数不符合验证规则                        | 检查请求参数格式和必填字段                       |
| 400        | PTM_011          | 操作不允许（版本级别字段） | 提供了版本级别字段（如segments）              | 仅允许修改模板级别字段，版本信息使用更新版本接口 |
| 400        | PTM_011          | 操作不允许（模板状态限制） | 模板状态不是草稿或历史                        | 仅草稿和历史状态允许修改                         |
| 401        | UNAUTHORIZED     | 未授权，Token无效或过期    | 未提供认证Token或Token已失效                  | 重新登录获取有效Token                            |
| 403        | FORBIDDEN        | 无权限执行此操作           | 当前用户没有`mdm.process-template.manage`权限 | 联系管理员分配相应权限                           |
| 404        | PTM_003          | 工艺模板不存在             | 请求的模板未找到                              | 检查模板ID是否正确                               |
| 500        | PTM_005          | 更新工艺模板失败           | 服务器内部错误，操作执行失败                  | 查看日志定位问题或联系技术支持                   |

**业务规则说明**:

- **模板级别 vs 版本级别**：此接口仅允许修改模板级别的共享信息，不允许修改版本独有的信息
- **为什么这样设计**：
  - 模板级别信息（如模板名称、适用产品）被所有版本共享
  - 修改会影响该模板下的所有版本（包括已生效的版本）
  - 需要更严格的状态控制，避免影响生产和审批流程
- **状态限制原因**：
  - 草稿状态：模板还未正式使用，可以自由修改
  - 历史状态：模板已过期，修改不会影响生产
  - 生效状态：有版本正在生产使用中，禁止修改避免影响生产
  - 待审批状态：有版本在审批流程中，禁止修改避免影响审批
- **与更新版本接口的区别**：
  - 更新模板接口：修改所有版本共享的信息（模板名称、适用产品等）
  - 更新版本接口：修改单个版本独有的信息（版本描述、工艺参数等）

**使用场景**:

1. **修改模板名称或描述**：当需要更准确地描述工艺模板用途时
2. **调整适用产品范围**：当工艺适用产品范围发生变化时
3. **更新适用规格范围**：当合金牌号、厚度或宽度范围需要调整时
4. **历史模板信息修正**：对已过期的历史模板进行信息修正

### 5. 更新工艺模板草稿/驳回版本

**接口路径**: `PATCH /v1/mdm/process-templates/{templateId}/versions/{versionId}`

**功能描述**:

允许在草稿或被驳回状态下修改**版本级别**的信息（版本描述和12段工艺参数）。仅草稿和驳回状态的版本允许编辑，生效和历史版本不可修改。

**⚠️ 重要业务规则变更（v2.0.1）**:

- ✅ **允许修改**：`versionDescription`（版本描述）、`segments`（12段工艺参数）
- ❌ **禁止修改**：`templateName`、`description`、`applicableProductIds`、`applicableAlloyGrades`、`applicableThicknessRange`、`applicableWidthRange`
- **原因**：模板级别信息（如模板名称、适用产品等）为所有版本共享，修改会影响该模板下的所有版本（包括已生效的版本）
- **替代方案**：如需修改模板级别信息，请使用专门的**更新模板接口**（参见第4节）

**认证要求**: 需要 Bearer Token，需要 `mdm.process-template.manage` 权限

**请求头**:

```
Authorization: Bearer <access_token>
Content-Type: application/json
```

**路径参数**:

| 参数名     | 类型   | 必填 | 描述         | 示例                |
| ---------- | ------ | ---- | ------------ | ------------------- |
| templateId | string | 是   | 模板ID(UUID) | "template-uuid-001" |
| versionId  | string | 是   | 版本ID(UUID) | "version-uuid-001"  |

**请求参数**:

| 参数名             | 类型   | 必填 | 限制         | 描述                         | 示例                       |
| ------------------ | ------ | ---- | ------------ | ---------------------------- | -------------------------- |
| versionDescription | string | 否   | 最大2000字符 | 版本描述                     | "修正第3段参数"            |
| segments           | array  | 否   | 必须12个元素 | 12段工艺参数配置（完整替换） | 见创建接口的段参数对象说明 |

**已移除的参数（不再支持）**:

| 参数名                   | 原类型 | 说明                                     |
| ------------------------ | ------ | ---------------------------------------- |
| templateName             | string | ❌ 模板级别信息，不允许在更新版本接口修改 |
| description              | string | ❌ 模板级别信息，不允许在更新版本接口修改 |
| applicableProductIds     | array  | ❌ 模板级别信息，不允许在更新版本接口修改 |
| applicableAlloyGrades    | string | ❌ 模板级别信息，不允许在更新版本接口修改 |
| applicableThicknessRange | string | ❌ 模板级别信息，不允许在更新版本接口修改 |
| applicableWidthRange     | string | ❌ 模板级别信息，不允许在更新版本接口修改 |

**请求示例**:

```bash
curl -X PATCH http://localhost:3000/v1/mdm/process-templates/template-uuid-001/versions/version-uuid-001 \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..." \
  -d '{
    "versionDescription": "修正第3段参数，优化升温曲线",
    "segments": [
      // 完整的12段参数数组（必须包含全部12段）
      {
        "segmentOrder": 1,
        "controlMode": "定时定温",
        "furnaceTemperature": 250.0,
        "materialTemperature": 240.0,
        // ... 其他段参数字段
      }
      // ... 剩余11段
    ]
  }'
```

**错误示例 - 尝试修改模板级别信息**:

```bash
# ❌ 错误：不允许修改模板名称
curl -X PATCH http://localhost:3000/v1/mdm/process-templates/template-uuid-001/versions/version-uuid-001 \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..." \
  -d '{
    "templateName": "新的模板名称",
    "versionDescription": "修正第3段参数"
  }'

# 响应 400 Bad Request:
{
  "success": false,
  "error": {
    "code": "PTM_011",
    "message": "更新版本接口不允许修改模板级别的信息（模板信息为所有版本共享）",
    "details": {
      "rejectedFields": ["templateName"],
      "allowedFields": ["versionDescription", "segments"],
      "hint": "如需修改模板名称、描述等共享信息，请使用更新模板接口"
    }
  }
}
```

**成功响应** (HTTP 200):

响应数据结构与"获取工艺模板详情"接口相同，返回更新后的完整版本详情（包含12段参数）。

**错误响应**:

- **版本级别 vs 模板级别**：此接口仅允许修改版本独有的信息（版本描述、工艺参数），不允许修改所有版本共享的模板信息
- **为什么这样设计**：模板级别信息（如模板名称、适用产品）被所有版本共享，修改会影响该模板下的所有版本（包括已生效的版本），可能导致生产数据混乱
- **如何修改模板信息**：请使用专门的**更新模板接口** `PATCH /v1/mdm/process-templates/{templateId}`（参见第4节），该接口会有更严格的状态检查
- **与更新模板接口的区别**：
  - 更新版本接口（本接口）：修改单个版本独有的信息（版本描述、工艺参数等）
  - 更新模板接口（第4节）：修改所有版本共享的信息（模板名称、适用产品等）

### 6. 提交工艺模板版本审批

**接口路径**: `PATCH /v1/mdm/process-templates/{templateId}/versions/{versionId}/submit-approval`

**认证要求**: 需要 Bearer Token，需要 `mdm.process-template.approval` 权限

**请求头**:

```
Authorization: Bearer <access_token>
Content-Type: application/json
```

**路径参数**:

| 参数名     | 类型   | 必填 | 描述         | 示例                |
| ---------- | ------ | ---- | ------------ | ------------------- |
| templateId | string | 是   | 模板ID(UUID) | "template-uuid-001" |
| versionId  | string | 是   | 版本ID(UUID) | "version-uuid-001"  |

| --------------- | ------ | ---- | ----------- | ------------ | ------------------ |
| approvalComment | string | 否   | 最大500字符 | 提交审批备注 | "请审批该工艺模板" |

### 7. 审批通过工艺模板版本

**接口路径**: `POST /v1/mdm/process-templates/{templateId}/versions/{versionId}/approve`

**功能描述**:

审批通过待审批状态的版本，版本状态变为"生效"。审批通过后，如果存在其他生效版本，会自动将其转为"历史"状态。可设置生效日期和失效日期，支持填写审批意见。

**认证要求**: 需要 Bearer Token，需要 `mdm.process-template.approval` 权限

**请求头**:

```
Authorization: Bearer <access_token>
Content-Type: application/json
```

**路径参数**:

| 参数名     | 类型   | 必填 | 描述         | 示例                |
| ---------- | ------ | ---- | ------------ | ------------------- |
| templateId | string | 是   | 模板ID(UUID) | "template-uuid-001" |
| versionId  | string | 是   | 版本ID(UUID) | "version-uuid-001"  |

**请求参数**:

| 参数名          | 类型   | 必填 | 限制             | 描述                       | 示例                       |
| --------------- | ------ | ---- | ---------------- | -------------------------- | -------------------------- |
| approvalComment | string | 否   | 最大500字符      | 审批意见                   | "审批通过，工艺参数合理"   |
| effectiveDate   | string | 否   | ISO 8601日期格式 | 生效日期，默认当前时间     | "2024-01-20T12:00:00.000Z" |
| expiryDate      | string | 否   | ISO 8601日期格式 | 失效日期，必须晚于生效日期 | "2025-01-20T12:00:00.000Z" |

**请求示例**:

```bash
curl -X POST http://localhost:3000/v1/mdm/process-templates/template-uuid-001/versions/version-uuid-001/approve \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..." \
  -d '{
    "approvalComment": "审批通过，工艺参数合理",
    "effectiveDate": "2024-01-20T12:00:00.000Z"
  }'
```

### 通用错误码

**参考认证模块文档中的通用错误码部分，包括：**
- **认证相关错误码 (AUTH_xxx)**：Token验证、权限校验等
- **验证相关错误码 (VAL_xxx / VALIDATION_ERROR)**：参数格式验证等
- **业务逻辑错误码 (BIZ_xxx)**：业务规则校验等
- **系统错误码 (SYS_xxx)**：系统级错误等

### 错误处理最佳实践

1. **统一错误处理**: 前端应根据错误码进行统一处理，而不是依赖 HTTP 状态码

2. **错误码模式识别**: 建议根据错误码前缀进行模式识别处理
   - `PTM_`: 工艺模板相关错误，根据具体错误码提示用户
   - `AUTH_`: 认证相关错误，可能需要重新登录或刷新令牌
   - `VALIDATION_ERROR`: 验证相关错误，需要检查输入参数

3. **错误消息展示**: 直接使用 `error.message` 字段的内容，无需前端硬编码错误消息

4. **重试机制**: 对于包含 `retryAfter` 字段的错误，应按照指定时间后重试

5. **日志记录**: 使用 `traceId` 进行错误追踪和问题排查

## 安全说明

### 认证机制

所有工艺参数管理接口均需要JWT Bearer Token认证。Token包含用户身份和权限信息。

**获取Token**: 通过登录接口 `POST /v1/auth/login` 获取access_token

**使用Token**: 在请求头中添加 `Authorization: Bearer <access_token>`

**Token过期**: access_token有效期为30分钟，过期后需要使用refresh_token刷新

### 权限控制

工艺参数管理模块实施细粒度权限控制：

- **查询权限 (`mdm.process-template.view`)**：查询模板列表、详情、版本历史、对比、引用情况
- **管理权限 (`mdm.process-template.manage`)**：创建、编辑、删除、复制、快速生效模板
- **审批权限 (`mdm.process-template.approval`)**：提交审批、审批通过、驳回、撤回、作废

### 数据安全

1. **软删除机制**：删除操作仅设置isDeleted标志，数据仍保留在数据库中
2. **审批流程**：生效版本需经过审批流程，确保工艺参数准确性
3. **版本控制**：所有修改创建新版本，保留完整历史记录
4. **引用检查**：删除前自动检查引用关系，防止误删
5. **参数校验**：12段参数完整性和合理性自动校验

### 使用建议

1. **权限最小化原则**：仅授予必要的权限给用户
2. **审批流程规范**：重要工艺参数变更应经过审批
3. **版本管理规范**：合理使用版本号，如v1.0、v1.1、v2.0
4. **参数验证**：前端应实施参数格式预验证，提升用户体验
5. **错误处理**：根据错误码提供友好的错误提示
6. **引用关系**：删除或停用模板前检查引用情况
