# Moses API 工艺参数管理模块接口文档 v2.0

## 概述

本文档详细说明了 Moses API 工艺参数管理模块的所有接口，包括请求方法、路径、参数、请求和响应数据结构、功能描述、错误码和返回示例。**本文档严格基于实际代码实现编写**（基于v2.0重构版本），确保前端开发人员能够准确对接。

### 模块功能说明

工艺参数管理模块用于管理铝箔退火工艺模板，采用**固定12段控温结构**设计，每个工艺模板包含固定12个控温段，每段包含炉温、料温、时间、风机等完整工艺参数。模块支持工艺模板的版本管理、审批流程，并为退火任务执行、设备通讯提供标准化工艺参数。

**v2.0重构核心变更：**
- 从4个参数表（段、气氛、风机、其他）合并为1个统一的12段工艺参数表
- 固定12个控温段设计，符合实际退火炉工艺
- 每段包含10个具体参数字段，完全匹配实际工艺需求
- 简化数据模型，提高查询和维护效率

- `success`: 布尔值，表示请求是否成功

- `error.details`: 可选的错误详细信息
- `meta`: 元数据信息，包含时间戳、请求 ID 和版本号

## 业务流程说明

### 工艺模板完整生命周期

```
创建模板(草稿) → 编辑12段参数 → 提交审批(待审批) → 审批通过(生效) → 创建新版本
                     ↓                    ↓
                  可重复编辑            驳回(驳回状态)
                                         ↓
                                      修改后重新提交

生效中版本 → 作废 / 创建新版本生效后自动转历史
```

### 核心业务流程

**步骤1：创建工艺模板**
- 接口：`POST /v1/mdm/process-templates`
- 创建模板主体信息和首个版本（v1.0）
- 可选择使用预设模板（标准/快速/空白）或自定义12段参数

**步骤2：编辑工艺参数**（可选）
- 接口：`PATCH /v1/mdm/process-templates/{templateId}/versions/{versionId}`
- 修改模板基本信息和12段工艺参数
- 仅草稿和驳回状态允许编辑

**步骤3：提交审批**
- 接口：`PATCH /v1/mdm/process-templates/{templateId}/versions/{versionId}/submit-approval`
- 将草稿版本提交至审批流程
- 提交后状态变为"待审批"

**步骤4：审批处理**
- 审批通过：`POST /v1/mdm/process-templates/{templateId}/versions/{versionId}/approve`
- 审批驳回：`POST /v1/mdm/process-templates/{templateId}/versions/{versionId}/reject`
- 撤回审批：`POST /v1/mdm/process-templates/{templateId}/versions/{versionId}/withdraw`

**步骤5：版本管理**
- 创建新版本：`POST /v1/mdm/process-templates/{templateId}/versions/create`
- 复制模板：`POST /v1/mdm/process-templates/{templateId}/copy`
- 快速生效：`POST /v1/mdm/process-templates/{templateId}/versions/{versionId}/activate`

**步骤6：查询和对比**
- 查询模板列表：`GET /v1/mdm/process-templates`
- 查询模板详情：`GET /v1/mdm/process-templates/{templateId}`
- 查询版本历史：`GET /v1/mdm/process-templates/{templateId}/versions`
- 版本对比：`GET /v1/mdm/process-templates/{templateId}/versions/compare`

## 工艺参数管理接口详细说明

### 1. 创建工艺模板及首个版本

**接口路径**: `POST /v1/mdm/process-templates`

**功能描述**:

创建工艺模板主体信息与首个版本，采用固定12段控温结构。每个工艺模板必须包含12个控温段，每段包含完整工艺参数（炉温、料温、时间、风机等）。可选择使用预设模板（标准退火/快速退火/空白模板）或自定义12段参数。创建成功后返回完整的模板详情，包括所有12段参数配置。

**认证要求**: 需要 Bearer Token，需要 `mdm.process-template.manage` 权限

**请求头**:

```
Authorization: Bearer <access_token>
Content-Type: application/json
```

**请求参数**:

| 参数名                   | 类型   | 必填 | 限制                 | 描述                                          | 示例                           |
| ------------------------ | ------ | ---- | -------------------- | --------------------------------------------- | ------------------------------ |
| templateCode             | string | 是   | 大写字母数字横线     | 工艺模板编码，全局唯一                        | "TPL-AF-001"                   |
| templateName             | string | 是   | 最大200字符          | 工艺模板名称                                  | "1100合金标准退火工艺"         |
| description              | string | 否   | 最大2000字符         | 工艺模板描述                                  | "适用于1100合金的标准退火工艺" |
| versionNumber            | string | 是   | 格式：v1.0 或 1.0    | 版本号                                        | "v1.0"                         |
| versionDescription       | string | 否   | 最大2000字符         | 版本描述                                      | "初始版本"                     |
| applicableProductIds     | array  | 否   | UUID数组，不重复     | 适用产品ID列表                                | ["uuid1", "uuid2"]             |
| applicableAlloyGrades    | string | 否   | 最大500字符          | 适用合金牌号，逗号分隔                        | "1100,8011"                    |
| applicableThicknessRange | string | 否   | 格式：0.005-0.1      | 适用厚度范围（mm）                            | "0.005-0.1"                    |
| applicableWidthRange     | string | 否   | 格式：500-1500       | 适用宽度范围（mm）                            | "500-1500"                     |
| segments                 | array  | 否   | 必须12个元素         | 12段工艺参数配置，若为空则使用presetTemplate  | 见下方段参数对象               |
| presetTemplate           | string | 否   | standard/quick/blank | 预设模板名称，当segments为空时使用，默认blank | "standard"                     |

**段参数对象（segments数组元素）字段说明**:

| 参数名              | 类型   | 必填 | 限制             | 描述                                   | 示例       |
| ------------------- | ------ | ---- | ---------------- | -------------------------------------- | ---------- |
| segmentOrder        | number | 是   | 1-12，不重复     | 段序号                                 | 1          |
| controlMode         | string | 否   | 固定值"定时定温" | 控温方式，默认"定时定温"               | "定时定温" |
| furnaceTemperature  | number | 是   | 0-1500，精度2位  | 炉温设置（℃）                          | 450.00     |
| materialTemperature | number | 是   | 0-1500，精度2位  | 料温设置（℃），不能高于炉温            | 430.00     |
| timeSet             | number | 是   | 0-999，精度2位   | 时间设置（小时）                       | 2.50       |
| runTime             | number | 否   | 0-999，精度2位   | 运行时间（小时），执行时填写，默认null | null       |
| circulationFanSpeed | string | 是   | 低速/中速/高速   | 循环风机速度                           | "中速"     |
| negativePressureFan | number | 是   | 0-100，精度2位   | 负压风机频率（Hz）                     | 25.00      |
| cleaningFan         | number | 是   | 0-100，精度2位   | 吹洗风机频率（Hz）                     | 20.00      |
| cleaningTime        | number | 是   | 0-999，精度2位   | 吹洗时间（分钟）                       | 30.00      |
