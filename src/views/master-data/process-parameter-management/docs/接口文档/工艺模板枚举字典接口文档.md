# 工艺模板枚举字典接口文档

## 📋 概述

工艺模板模块的枚举字典接口，提供所有工艺相关的枚举值和中文标签。前端应在应用启动时调用并缓存到 localStorage，避免重复请求。

**创建日期**: 2025-10-15
**参照实现**: 生产计划模块字典接口

### 2. 获取特定类型枚举字典

**接口路径**: `GET /v1/mdm/process-templates/dictionaries/:type`
**权限要求**: `mdm.process-template.view`
**描述**: 返回指定类型的枚举字典

#### 路径参数

| 参数名 | 类型   | 必填 | 说明                   |
| ------ | ------ | ---- | ---------------------- |
| type   | string | 是   | 字典类型，见下方可选值 |

#### 字典类型可选值

| 类型值                    | 说明             | 枚举值数量 |
| ------------------------- | ---------------- | ---------- |
| `templateStatuses`        | 工艺模板状态     | 4          |
| `templateVersionStatuses` | 工艺模板版本状态 | 6          |

| `circulationFanSpeeds`    | 循环风机速度     | 3          |
| `controlModes`            | 控温方式         | 1          |

## 📦 枚举值详细说明

### 1. 工艺模板状态 (templateStatuses)

| 枚举键           | 中文值 | 说明                 |
| ---------------- | ------ | -------------------- |
| DRAFT            | 草稿   | 模板初始状态，可编辑 |
| PENDING_APPROVAL | 待审批 | 已提交审批，等待审批 |
| EFFECTIVE        | 生效   | 审批通过，正式使用   |
| HISTORY          | 历史   | 已过期或被新版本替代 |

### 2. 工艺模板版本状态 (templateVersionStatuses)

| 枚举键           | 中文值 | 说明                 |
| ---------------- | ------ | -------------------- |
| DRAFT            | 草稿   | 版本初始状态，可编辑 |
| PENDING_APPROVAL | 待审批 | 已提交审批流程       |
| EFFECTIVE        | 生效   | 当前生效版本         |
| HISTORY          | 历史   | 已被新版本替代       |
| REJECTED         | 驳回   | 审批未通过           |
| OBSOLETE         | 作废   | 手动作废的版本       |

### 3. 保护气氛类型 (atmosphereTypes)

| 枚举键                | 中文值     | 说明                  |
| --------------------- | ---------- | --------------------- |
| PURE_NITROGEN         | 纯氮气     | 100%氮气保护气氛      |
| HYDROGEN_NITROGEN_MIX | 氢氮混合气 | 氢气+氮气混合保护气氛 |
| ARGON                 | 氩气       | 惰性气体保护气氛      |
| NITROGEN_HYDROGEN_MIX | 氮氢混合气 | 氮气为主的混合气体    |
| OTHER                 | 其他       | 其他类型保护气氛      |

### 4. 循环风机速度 (circulationFanSpeeds)

| 枚举键 | 中文值 | 说明     |
| ------ | ------ | -------- |
| LOW    | 低速   | 低速运转 |
| MEDIUM | 中速   | 中速运转 |
| HIGH   | 高速   | 高速运转 |

### 5. 控温方式 (controlModes)

| 枚举键    | 中文值   | 说明             |
| --------- | -------- | ---------------- |
| TIME_TEMP | 定时定温 | 按时间和温度控制 |

## 🎯 前端使用指南

### 1. 应用启动时缓存

```javascript
// 在应用初始化时获取并缓存
async function initDictionaries() {
  try {
    const response = await axios.get('/v1/mdm/process-templates/dictionaries');

    // 缓存到 localStorage
    localStorage.setItem('processTemplateDictionaries', JSON.stringify(response.data.data));

    // 或缓存到 Vuex/Redux
    store.commit('SET_PROCESS_TEMPLATE_DICTIONARIES', response.data.data);

    console.log('工艺模板字典缓存成功');
  } catch (error) {
    console.error('获取工艺模板字典失败:', error);
  }
}
```

### 2. 使用缓存的字典数据

```javascript
// 从缓存获取字典
function getDictionaries() {
  const cached = localStorage.getItem('processTemplateDictionaries');
  return cached ? JSON.parse(cached) : null;
}

// 获取特定类型的标签
function getLabel(type, value) {
  const dictionaries = getDictionaries();
  return dictionaries?.[type]?.labels?.[value] || value;
}

// 使用示例
const statusLabel = getLabel('templateStatuses', '草稿');
console.log(statusLabel); // 输出: "草稿"
```

### 3. 生成下拉选项

```javascript
// 将枚举转换为 Select 组件选项
function getDictionaryOptions(type) {
  const dictionaries = getDictionaries();
  const dict = dictionaries?.[type];

  if (!dict) return [];

  return Object.entries(dict.values).map(([key, value]) => ({
    label: value,
    value: key,
  }));
}

// Vue 使用示例
<template>
  <el-select v-model="form.status" placeholder="请选择状态">
    <el-option
      v-for="item in statusOptions"
      :key="item.value"
      :label="item.label"
      :value="item.value"
    />
  </el-select>
</template>

<script>
export default {
  data() {
    return {
      form: { status: '' },
      statusOptions: getDictionaryOptions('templateStatuses')
    };
  }
};
</script>
```

### 4. 表格列显示转换

```javascript
// Element UI 表格列格式化
<el-table-column
  prop="status"
  label="状态"
  :formatter="(row) => getLabel('templateStatuses', row.status)"
/>

// 或使用自定义插槽
<el-table-column prop="status" label="状态">
  <template #default="{ row }">
    <el-tag :type="getStatusType(row.status)">
      {{ getLabel('templateStatuses', row.status) }}
    </el-tag>
  </template>
</el-table-column>
```

## 🔄 更新策略

### 何时更新缓存？

1. **应用启动时**: 首次加载必须获取
2. **版本更新后**: 清除旧缓存，重新获取
3. **定期刷新**: 每24小时刷新一次（可选）
4. **手动刷新**: 提供手动刷新按钮（可选）

### 版本控制示例

```javascript
const DICTIONARY_VERSION = '1.0.0'; // 在应用配置中定义

function checkDictionaryVersion() {
  const cachedVersion = localStorage.getItem('dictionaryVersion');

  if (cachedVersion !== DICTIONARY_VERSION) {
    // 版本不匹配，清除旧缓存
    localStorage.removeItem('processTemplateDictionaries');
    localStorage.setItem('dictionaryVersion', DICTIONARY_VERSION);

    // 重新获取
    return initDictionaries();
  }
}
```

## ⚠️ 注意事项

1. **权限要求**: 需要 `mdm.process-template.view` 权限，确保用户已登录且有相应权限
2. **缓存策略**: 建议在应用启动时获取并缓存，避免每次请求
3. **错误处理**: 如果获取失败，应有降级方案（使用默认值或本地备份）
4. **数据一致性**: 枚举值与数据库 ENUM 定义保持一致
5. **向后兼容**: 新增枚举值不会影响现有代码，但删除枚举值需谨慎
