# Moses API 工艺模板枚举字典接口文档

## 概述

本文档详细说明了 Moses API 工艺模板模块的枚举字典接口，包括请求方法、路径、参数、请求和响应数据结构、功能描述、错误码和返回示例。**本文档严格基于实际代码实现编写**，确保前端开发人员能够准确对接。

### API 基础信息

- **基础 URL**: `http://localhost:3000/v1` (开发环境)
- **API 版本**: v1
- **认证方式**: JWT Bearer Token
- **数据格式**: JSON
- **字符编码**: UTF-8
- **Content-Type**: application/json

### Swagger 文档

项目已集成 Swagger 文档，可通过以下地址访问：

- **开发环境**: http://localhost:3000/v1/docs
- **在线文档**: 提供完整的 API 接口说明、参数定义和示例

### 权限约定

- `mdm.process-template.view`：查看工艺模板及相关枚举字典的权限
- `mdm.process-template.manage`：管理工艺模板的权限（字典接口无需此权限）

## 统一响应格式

### 成功响应格式

所有成功的 API 调用都会返回以下统一格式：

```json
{
  "success": true,
  "data": {
    // 具体的业务数据，根据接口而不同
  },
  "message": "操作成功的描述信息",
  "meta": {
    "timestamp": "2025-10-16T10:30:00.000Z",
    "requestId": "req-1234567890-abcdef",
    "version": "v1"
  }
}
```

### 错误响应格式

所有错误的 API 调用都会返回以下统一格式：

```json
{
  "success": false,
  "error": {
    "code": "ERROR_CODE",
    "message": "用户友好的错误描述",
    "details": {
      "field": "发生错误的字段名（可选）",
      "value": "错误的字段值（可选）"
    }
  },
  "meta": {
    "timestamp": "2025-10-16T10:30:00.000Z",
    "requestId": "req-1234567890-abcdef",
    "version": "v1"
  }
}
```

**响应字段说明**：

- `success`: 布尔值，表示请求是否成功
- `data`: 成功时包含业务数据，失败时为 null
- `error`: 失败时包含错误信息，成功时为 null
- `message`: 成功时的操作描述
- `error.code`: 标准化的错误码，用于程序化处理
- `error.message`: 用户友好的错误描述，可直接展示给用户
- `error.details`: 可选的错误详细信息
- `meta`: 元数据信息，包含时间戳、请求 ID 和版本号

## 工艺模板枚举字典接口详细说明

### 1. 获取所有枚举字典

**接口路径**: `GET /v1/mdm/process-templates/dictionaries`

**功能描述**: 一次性返回工艺模板模块所有枚举类型的字典数据，用于系统初始化或缓存刷新。返回的数据包含工艺模板状态、版本状态、保护气氛类型、循环风机速度、控温方式等所有工艺相关的枚举值和中文标签映射。

**认证要求**: 需要 Bearer Token

**请求头**:

```
Authorization: Bearer <access_token>
Content-Type: application/json
```

**查询参数**: 无

**请求参数**: 无

**请求示例**:

```bash
curl -X GET http://localhost:3000/v1/mdm/process-templates/dictionaries \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
```

**成功响应** (HTTP 200):

```json
{
  "success": true,
  "data": {
    "templateStatuses": {
      "DRAFT": "草稿",
      "PENDING_APPROVAL": "待审批",
      "EFFECTIVE": "生效",
      "HISTORY": "历史"
    },
    "templateVersionStatuses": {
      "DRAFT": "草稿",
      "PENDING_APPROVAL": "待审批",
      "EFFECTIVE": "生效",
      "HISTORY": "历史",
      "REJECTED": "驳回",
      "OBSOLETE": "作废"
    },
    "atmosphereTypes": {
      "PURE_NITROGEN": "纯氮气",
      "HYDROGEN_NITROGEN_MIX": "氢氮混合气",
      "ARGON": "氩气",
      "NITROGEN_HYDROGEN_MIX": "氮氢混合气",
      "OTHER": "其他"
    },
    "circulationFanSpeeds": {
      "LOW": "低速",
      "MEDIUM": "中速",
      "HIGH": "高速"
    },
    "controlModes": {
      "TIME_TEMP": "定时定温"
    }
  },
  "message": "获取枚举字典成功",
  "meta": {
    "timestamp": "2025-10-16T10:30:00.000Z",
    "version": "v1"
  }
}
```

**响应字段说明**:

| 字段名                       | 类型    | 描述                                    | 示例                       |
| ---------------------------- | ------- | --------------------------------------- | -------------------------- |
| success                      | boolean | 请求是否成功                            | true                       |
| data                         | object  | 字典数据对象，包含所有枚举类型          | {...}                      |
| data.templateStatuses        | object  | 工艺模板状态枚举 (CODE -> 中文标签)     | {...}                      |
| data.templateVersionStatuses | object  | 工艺模板版本状态枚举 (CODE -> 中文标签) | {...}                      |
| data.atmosphereTypes         | object  | 保护气氛类型枚举 (CODE -> 中文标签)     | {...}                      |
| data.circulationFanSpeeds    | object  | 循环风机速度枚举 (CODE -> 中文标签)     | {...}                      |
| data.controlModes            | object  | 控温方式枚举 (CODE -> 中文标签)         | {...}                      |
| message                      | string  | 操作结果描述                            | "获取枚举字典成功"         |
| meta.timestamp               | string  | 响应时间戳 (ISO 8601格式)               | "2025-10-16T10:30:00.000Z" |
| meta.version                 | string  | API版本号                               | "v1"                       |

**枚举对象字段说明** (以 templateStatuses 为例):

| 字段名（枚举CODE） | 类型   | 描述                 | 示例     |
| ------------------ | ------ | -------------------- | -------- |
| DRAFT              | string | 草稿状态的中文标签   | "草稿"   |
| PENDING_APPROVAL   | string | 待审批状态的中文标签 | "待审批" |
| EFFECTIVE          | string | 生效状态的中文标签   | "生效"   |
| HISTORY            | string | 历史状态的中文标签   | "历史"   |

**错误响应**:

**错误码列表**:

| HTTP状态码 | 错误码         | 错误消息                | 说明                         | 处理建议               |
| ---------- | -------------- | ----------------------- | ---------------------------- | ---------------------- |
| 401        | UNAUTHORIZED   | 未授权，Token无效或过期 | 未提供认证Token或Token已失效 | 重新登录获取有效Token  |
| 403        | FORBIDDEN      | 无权限执行此操作        | 当前用户没有查看权限         | 联系管理员分配相应权限 |

### 2. 获取特定类型枚举字典

**接口路径**: `GET /v1/mdm/process-templates/dictionaries/:type`

**功能描述**: 返回指定类型的枚举字典。如果只需要某一种枚举类型（如只需要工艺模板状态），可以使用此接口减少数据传输量。接口会根据type参数返回对应的枚举值到中文标签的映射。

**认证要求**: 需要 Bearer Token

**请求头**:

```
Authorization: Bearer <access_token>
Content-Type: application/json
```

**路径参数**:

| 参数名 | 类型   | 必填 | 限制               | 描述                                   | 示例             |
| ------ | ------ | ---- | ------------------ | -------------------------------------- | ---------------- |
| type   | string | 是   | 见下方"可选值"列表 | 字典类型标识，用于指定要获取的枚举类型 | templateStatuses |

**type 参数可选值**:

| 值                      | 说明             | 枚举数量 |
| ----------------------- | ---------------- | -------- |
| templateStatuses        | 工艺模板状态     | 4        |
| templateVersionStatuses | 工艺模板版本状态 | 6        |
| atmosphereTypes         | 保护气氛类型     | 5        |
| circulationFanSpeeds    | 循环风机速度     | 3        |
| controlModes            | 控温方式         | 1        |

**查询参数**: 无

**请求参数**: 无

**请求示例**:

```bash
curl -X GET http://localhost:3000/v1/mdm/process-templates/dictionaries/templateStatuses \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
```

**成功响应** (HTTP 200):

```json
{
  "success": true,

    "DRAFT": "草稿",
    "PENDING_APPROVAL": "待审批",

    "timestamp": "2025-10-16T10:30:00.000Z",
    "version": "v1"
  }
}
```

**响应字段说明**:

| 字段名         | 类型    | 描述                           | 示例                       |
| -------------- | ------- | ------------------------------ | -------------------------- |
| success        | boolean | 请求是否成功                   | true                       |
| data           | object  | 枚举CODE到中文标签的键值对映射 | {"DRAFT": "草稿", ...}     |
| data.{CODE}    | string  | 枚举CODE对应的中文标签         | "草稿"                     |
| message        | string  | 操作结果描述                   | "获取工艺模板状态字典成功" |
| meta.timestamp | string  | 响应时间戳 (ISO 8601格式)      | "2025-10-16T10:30:00.000Z" |
| meta.version   | string  | API版本号                      | "v1"                       |

**错误响应**:

## 错误码说明

### 工艺模板字典相关错误码

| 错误码               | HTTP 状态码 | 错误消息       | 说明                   | 处理建议             |
| -------------------- | ----------- | -------------- | ---------------------- | -------------------- |
| DICTIONARY_NOT_FOUND | 404         | 字典类型不存在 | 请求的字典类型标识无效 | 检查type参数是否正确 |

### 通用错误码

| 错误码         | HTTP 状态码 | 错误消息                | 说明                         | 处理建议               |
| -------------- | ----------- | ----------------------- | ---------------------------- | ---------------------- |
| UNAUTHORIZED   | 401         | 未授权，Token无效或过期 | 未提供认证Token或Token已失效 | 重新登录获取有效Token  |
| FORBIDDEN      | 403         | 无权限执行此操作        | 当前用户没有该操作的权限     | 联系管理员分配相应权限 |
| INTERNAL_ERROR | 500         | 服务器内部错误          | 服务器处理请求时发生异常     | 联系技术支持           |

### 错误处理最佳实践

1. **统一错误处理**: 建议根据错误码进行统一处理，而不是依赖 HTTP 状态码

2. **错误码模式识别**: 建议根据错误码前缀进行模式识别处理
   - `AUTH_`: 认证相关错误，可能需要重新登录或刷新令牌
   - `DICTIONARY_`: 字典相关错误，需要检查参数有效性

3. **错误消息展示**: 直接使用 `error.message` 字段的内容，无需客户端硬编码错误消息

## 数据模型

### 枚举字典数据结构

枚举字典采用简洁的键值对格式，其中键为枚举CODE（大写英文，下划线分隔），值为对应的中文标签。

**通用结构**:

```json
{
  "{枚举类型}": {
    "{CODE1}": "{中文标签1}",
    "{CODE2}": "{中文标签2}"
  }
}
```

### 枚举类型详细定义

#### 1. 工艺模板状态 (templateStatuses)

**数据结构**:
```json
{
  "DRAFT": "草稿",
  "PENDING_APPROVAL": "待审批",
  "EFFECTIVE": "生效",
  "HISTORY": "历史"
}
```

**字段说明**:

| 枚举CODE         | 中文标签 | 说明                 | 业务场景             |
| ---------------- | -------- | -------------------- | -------------------- |
| DRAFT            | 草稿     | 模板初始状态，可编辑 | 模板创建后的初始状态 |
| PENDING_APPROVAL | 待审批   | 已提交审批，等待审批 | 模板提交审批流程     |
| EFFECTIVE        | 生效     | 审批通过，正式使用   | 审批通过后的状态     |
| HISTORY          | 历史     | 已过期或被新版本替代 | 版本更新后的旧模板   |

#### 2. 工艺模板版本状态 (templateVersionStatuses)

**数据结构**:
```json
{
  "DRAFT": "草稿",
  "PENDING_APPROVAL": "待审批",
  "EFFECTIVE": "生效",
  "HISTORY": "历史",
  "REJECTED": "驳回",
  "OBSOLETE": "作废"
}
```

**字段说明**:

| 枚举CODE         | 中文标签 | 说明                 | 业务场景             |
| ---------------- | -------- | -------------------- | -------------------- |
| DRAFT            | 草稿     | 版本初始状态，可编辑 | 版本创建后的初始状态 |
| PENDING_APPROVAL | 待审批   | 已提交审批流程       | 版本提交审批         |
| EFFECTIVE        | 生效     | 当前生效版本         | 审批通过的生效版本   |
| HISTORY          | 历史     | 已被新版本替代       | 版本升级后的旧版本   |
| REJECTED         | 驳回     | 审批未通过           | 审批被拒绝           |
| OBSOLETE         | 作废     | 手动作废的版本       | 主动废弃的版本       |

#### 3. 保护气氛类型 (atmosphereTypes)

**数据结构**:
```json
{
  "PURE_NITROGEN": "纯氮气",
  "HYDROGEN_NITROGEN_MIX": "氢氮混合气",
  "ARGON": "氩气",
  "NITROGEN_HYDROGEN_MIX": "氮氢混合气",
  "OTHER": "其他"
}
```

**字段说明**:

| 枚举CODE              | 中文标签   | 说明                  | 适用工艺     |
| --------------------- | ---------- | --------------------- | ------------ |
| PURE_NITROGEN         | 纯氮气     | 100%氮气保护气氛      | 铝箔退火工艺 |
| HYDROGEN_NITROGEN_MIX | 氢氮混合气 | 氢气+氮气混合保护气氛 | 特殊退火工艺 |
| ARGON                 | 氩气       | 惰性气体保护气氛      | 高端材料退火 |
| NITROGEN_HYDROGEN_MIX | 氮氢混合气 | 氮气为主的混合气体    | 通用退火工艺 |
| OTHER                 | 其他       | 其他类型保护气氛      | 特殊工艺需求 |

#### 4. 循环风机速度 (circulationFanSpeeds)

**数据结构**:
```json
{
  "LOW": "低速",
  "MEDIUM": "中速",
  "HIGH": "高速"
}
```

**字段说明**:

| 枚举CODE | 中文标签 | 说明     | 适用场景      |
| -------- | -------- | -------- | ------------- |
| LOW      | 低速     | 低速运转 | 保温阶段      |
| MEDIUM   | 中速     | 中速运转 | 升温/降温阶段 |
| HIGH     | 高速     | 高速运转 | 快速冷却阶段  |

#### 5. 控温方式 (controlModes)

**数据结构**:
```json
{
  "TIME_TEMP": "定时定温"
}
```

**字段说明**:

| 枚举CODE  | 中文标签 | 说明             | 适用场景         |
| --------- | -------- | ---------------- | ---------------- |
| TIME_TEMP | 定时定温 | 按时间和温度控制 | 标准退火工艺控制 |

### 字段说明

**日期时间格式**:
- 所有日期时间字段均使用 ISO 8601 格式：`YYYY-MM-DDTHH:mm:ss.sssZ`
- 示例：`"2025-10-16T10:30:00.000Z"`

**枚举CODE命名规范**:
- 全部大写英文字母
- 多个单词使用下划线 `_` 分隔
- 具有自解释性
- 示例：`PENDING_APPROVAL`、`HYDROGEN_NITROGEN_MIX`

**中文标签规范**:
- 简洁明确，通常2-6个汉字
- 使用用户容易理解的业务术语
- 保持系统内一致性

## 安全说明

### 认证机制

所有枚举字典接口需要通过JWT Token认证，Token需在请求头中提供：

```
Authorization: Bearer {token}
```

Token获取方式请参考登录模块文档。

### 安全特性

1. **JWT Token验证**: 每次请求都会验证Token的有效性和过期时间
2. **权限控制**: 需要 `mdm.process-template.view` 权限
3. **数据只读**: 枚举字典接口仅提供查询功能，不支持修改
4. **速率限制**: 遵循系统统一的API访问速率限制

### 使用建议

1. **缓存策略**: 枚举数据变化频率低，建议客户端实现缓存机制
2. **批量获取**: 优先使用"获取所有枚举字典"接口，减少请求次数
3. **错误处理**: 实现降级方案，当接口不可用时使用本地默认值
4. **安全传输**: 生产环境必须使用HTTPS协议
