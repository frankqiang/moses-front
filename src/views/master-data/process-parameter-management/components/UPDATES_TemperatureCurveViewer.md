# TemperatureCurveViewer 功能优化记录

## 📅 2025-10-16 更新

### ✨ 功能优化

#### 1. 对比版本颜色区分优化

**问题描述**：对比版本的炉温和料温曲线使用相同的颜色，难以区分

**解决方案**：
- 炉温使用对比版本的原色（虚线）
- 料温使用原色的加亮版本（点线）
- 新增 `adjustColorBrightness()` 辅助方法，自动生成加亮40%的颜色

**示例**：
```javascript
// 如果对比版本颜色是 #FFA726（橙色）
// 炉温：#FFA726（原橙色，虚线）
// 料温：#FFD090（浅橙色，点线）
```

**视觉效果**：
- 🔴 当前版本 - 炉温：红色实线 + 圆圈标记
- 🔵 当前版本 - 料温：蓝色实线 + 菱形标记
- 🟠 对比版本 - 炉温：橙色虚线 + 圆圈标记
- 🟡 对比版本 - 料温：浅橙色点线 + 菱形标记

#### 2. 风机参数图表双Y轴优化

**问题描述**：循环风机速度使用枚举值（低速/中速/高速），而负压风机和吹洗风机使用赫兹(Hz)，单位不统一导致展示不直观

**解决方案**：采用双Y轴设计
- **左侧Y轴**：循环风机速度（显示低速/中速/高速标签）
- **右侧Y轴**：负压风机和吹洗风机的频率（Hz）

**实现细节**：
```javascript
// 循环风机速度映射为百分比
const speedMap = {
  '低速': 33,   // 33%
  '中速': 67,   // 67%
  '高速': 100   // 100%
}

// 双Y轴配置
yAxis: [
  {
    type: 'value',
    name: '循环风机速度',
    position: 'left',
    axisLabel: {
      formatter: value => {
        if (value <= 33) return '低速'
        if (value <= 67) return '中速'
        return '高速'
      }
    }
  },
  {
    type: 'value',
    name: '频率 (Hz)',
    position: 'right',
    axisLabel: {
      formatter: '{value} Hz'
    }
  }
]
```

**优点**：
1. ✅ 单位清晰：左右两侧Y轴分别标注不同单位
2. ✅ 数据直观：循环风机速度以枚举值显示，更符合实际操作习惯
3. ✅ 对比方便：三种风机参数在同一图表中，便于对比各段的风机配置
4. ✅ 专业性强：双Y轴设计符合工业图表的展示规范

### 🔧 新增方法

#### `adjustColorBrightness(color, percent)`
调整十六进制颜色的亮度

**参数**：
- `color` (String): 十六进制颜色代码（如 "#FFA726"）
- `percent` (Number): 亮度调整百分比（正数增加亮度，负数降低亮度）

**返回**：
- (String): 调整后的十六进制颜色代码

**算法**：
```javascript
// 转换流程：HEX → RGB → 调整亮度 → HEX
// 亮度调整公式：newValue = oldValue + (255 - oldValue) * (percent / 100)
```

**示例**：
```javascript
adjustColorBrightness('#FFA726', 40)  // 返回: '#FFD090' (加亮40%)
adjustColorBrightness('#E74C3C', -20) // 返回: '#B83C2F' (变暗20%)
```

### 📝 技术说明

#### 颜色亮度调整算法
使用线性插值方法调整颜色亮度：
- 增加亮度：向白色(255)方向插值
- 减少亮度：向黑色(0)方向插值
- 保持色相：RGB三通道同比例调整

#### 双Y轴配置要点
1. **yAxis数组**：定义两个Y轴配置对象
2. **yAxisIndex**：series中指定使用哪个Y轴（0或1）
3. **splitLine**：仅左侧Y轴显示网格线，避免视觉混乱
4. **position**：left和right分别显示在图表两侧

## 🎯 总结

这次优化主要解决了两个用户体验问题：

1. **颜色区分优化**：通过自动生成不同亮度的颜色，解决了对比版本曲线难以区分的问题
2. **双Y轴设计**：通过专业的双Y轴图表设计，解决了不同单位数据混合展示的问题

这些改进提升了图表的可读性和专业性，符合工业软件的展示标准。
