# 炉型管理模块说明文档

## 模块概述

炉型管理模块是制造执行系统（MES）主数据管理的重要组成部分，用于定义和管理车间内不同类型的退火炉。该模块允许系统管理员或工艺主管定义不同类型的炉型，每种炉型包含特定的能力参数配置，这些配置将直接影响工艺模板设计和设备参数设置。

## 业务价值

1. **标准化退火炉管理**：通过统一的炉型定义，实现退火炉管理的标准化，便于系统识别和管理不同类型的退火炉。
2. **工艺参数约束**：为工艺参数模板提供能力约束，确保工艺模板的参数设置不超出设备物理能力。
3. **设备配置基础**：为设备管理模块提供炉型基础配置，简化设备档案创建过程。
4. **数据一致性保障**：通过炉型与工艺模板、设备的关联，确保系统中数据的一致性和正确性。

## 数据结构

### 炉型基本信息
- **id**：系统内部唯一标识符
- **code**：炉型编码（如 "FT-A"、"SIEMENS-XYZ-2ZONE"）
- **name**：炉型名称（如 "标准双区退火炉"、"XYZ型单区快速冷却炉"）
- **status**：状态（启用/禁用）
- **description**：描述信息
- **createdBy**：创建人
- **createdAt**：创建时间
- **updatedBy**：最后修改人
- **updatedAt**：最后修改时间

### 炉型能力参数（capabilities）
- **hasBackZone**：是否有后区（Boolean）- 控制是否支持双区控制
- **hasNegativePressure**：是否有负压系统（Boolean）
- **hasCoolingValve**：是否有吹洗阀（Boolean）
- **maxSegments**：最大工艺段数（Integer）- 限制工艺模板中可设置的最大段数
- **maxTemperature**：最高温度（°C）（Integer）- 限制工艺模板中可设置的最高温度
- **maxHeatingRate**：最大升温速率（°C/分钟）（Float）- 限制工艺模板中可设置的最大升温速率

### 关联信息
- **equipmentCount**：关联设备数量
- **templateCount**：关联工艺模板数量

## 接口说明

### 获取炉型列表
- **URL**: `/mes/master-data/furnace-type/list`
- **方法**: GET
- **参数**:
  - page: 页码
  - limit: 每页条数
  - keyword: 搜索关键词（支持编码和名称）
  - status: 状态筛选
- **返回示例**:
```json
{
  "code": 20000,
  "data": {
    "total": 10,
    "items": [
      {
        "id": "1",
        "code": "FT-STANDARD",
        "name": "标准双区退火炉",
        "status": "enabled",
        "capabilities": {
          "hasBackZone": true,
          "hasNegativePressure": true,
          "hasCoolingValve": true,
          "maxSegments": 12,
          "maxTemperature": 1000,
          "maxHeatingRate": 10
        },
        "equipmentCount": 5,
        "templateCount": 8,
        "description": "标准双区退火炉，支持完整工艺控制",
        "createdBy": "admin",
        "createdAt": "2024-01-01T10:00:00",
        "updatedBy": "admin",
        "updatedAt": "2024-01-01T10:00:00"
      }
    ]
  }
}
```

### 获取炉型详情
- **URL**: `/mes/master-data/furnace-type/detail/{id}`
- **方法**: GET
- **参数**: id (路径参数)
- **返回**: 单个炉型的详细信息

### 创建炉型
- **URL**: `/mes/master-data/furnace-type/create`
- **方法**: POST
- **参数**: 炉型数据对象
- **返回**: 创建成功的炉型ID和基本信息

### 更新炉型
- **URL**: `/mes/master-data/furnace-type/update`
- **方法**: PUT
- **参数**: 炉型数据对象（含ID）
- **返回**: 更新成功状态

### 删除炉型
- **URL**: `/mes/master-data/furnace-type/delete/{id}`
- **方法**: DELETE
- **参数**: id (路径参数)
- **返回**: 删除成功状态

### 更改炉型状态
- **URL**: `/mes/master-data/furnace-type/status`
- **方法**: PUT
- **参数**: 
  - id: 炉型ID
  - status: 新状态
- **返回**: 更新成功状态

### 批量操作接口
- **批量删除**: `/mes/master-data/furnace-type/batch-delete`
- **批量更改状态**: `/mes/master-data/furnace-type/batch-status`

### 关联信息接口
- **获取关联设备**: `/mes/master-data/furnace-type/related-equipment/{id}`
- **获取关联工艺模板**: `/mes/master-data/furnace-type/related-templates/{id}`

### 导入/导出接口
- **导入数据**: `/mes/master-data/furnace-type/import`
- **导出数据**: `/mes/master-data/furnace-type/export`
- **下载导入模板**: `/mes/master-data/furnace-type/download-template`

## 使用场景

### 场景一：创建新炉型
1. 系统管理员登录系统，导航至"主数据 -> 炉型管理"
2. 点击"新增"按钮，填写炉型基本信息
3. 配置炉型能力参数
4. 保存炉型信息

### 场景二：修改现有炉型
1. 系统管理员登录系统，导航至"主数据 -> 炉型管理"
2. 在列表中找到需要修改的炉型，点击"编辑"
3. 修改炉型信息和能力参数
4. 保存修改

### 场景三：设备与炉型关联
1. 在"设备管理"模块创建或编辑设备
2. 从下拉列表中选择此设备对应的炉型
3. 保存设备信息，完成关联

### 场景四：工艺模板与炉型关联
1. 在"工艺参数管理"模块创建或编辑工艺模板
2. 从下拉列表中选择此模板适用的炉型
3. 系统根据所选炉型的能力参数，限制工艺模板中可设置的参数范围
4. 保存工艺模板，完成关联

## 注意事项

1. **删除限制**：当炉型已关联设备或工艺模板时，不允许删除，需先解除关联
2. **参数修改**：修改炉型能力参数时，需注意可能影响已关联的工艺模板
3. **编码唯一性**：炉型编码在系统中必须唯一
4. **状态管理**：禁用炉型不会影响已关联的设备和工艺模板，但会阻止新建关联
