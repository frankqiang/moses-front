## 认证接口详细说明

### 1. 用户注册

**接口路径**: `POST /auth/register`

**功能描述**: 注册新用户账户，创建用户信息并返回认证令牌。该接口用于新用户注册，验证用户输入信息的有效性，创建用户账户并返回完整的用户信息和认证令牌。

**请求参数**:

| 参数名 | 类型 | 必填 | 长度限制 | 描述 | 示例 |
|--------|------|------|----------|------|------|
| name | string | 是 | - | 真实姓名 | "张三" |
| username | string | 是 | 3-50字符 | 用户名，支持字母、数字、下划线，必须唯一 | "admin" |
| email | string | 是 | 有效邮箱格式 | 邮箱地址，必须唯一 | "user@example.com" |
| password | string | 是 | 最少8字符 | 密码，至少包含一个数字和一个字母 | "password123" |

**请求示例**:
```json
{
  "name": "张三",
  "username": "admin",
  "email": "user@example.com",
  "password": "password123"
}
```

**成功响应** (HTTP 201):
```json
{
  "user": {
    "id": "user-123",
    "username": "admin",
    "name": "张三",
    "email": "user@example.com",
    "role": "user",
    "isEmailVerified": false,
    "createdAt": "2024-01-20T10:30:00.000Z",
    "updatedAt": "2024-01-20T10:30:00.000Z"
  },
  "tokens": {
    "access": {
      "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
      "expires": "2024-01-20T11:00:00.000Z"
    },
    "refresh": {
      "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
      "expires": "2024-02-20T10:30:00.000Z"
    }
  }
}
```

**错误响应**:
- **400 Bad Request**: 参数验证失败
- **409 Conflict**: 用户名或邮箱已存在

### 2. 用户登录

**接口路径**: `POST /auth/login`

**功能描述**: 用户身份认证，验证用户名/邮箱和密码，返回访问令牌。该接口用于用户登录系统，验证用户身份并获取访问令牌，用于后续 API 调用的身份认证。支持用户名或邮箱登录，并提供记住登录状态的选项。

**请求参数**:

| 参数名 | 类型 | 必填 | 长度限制 | 描述 | 示例 |
|--------|------|------|----------|------|------|
| username | string | 否* | 3-50字符 | 用户名，与邮箱二选一 | "admin" |
| email | string | 否* | 有效邮箱格式 | 用户邮箱，与用户名二选一 | "user@example.com" |
| password | string | 是 | 6-20字符 | 密码，必填 | "password123" |
| rememberMe | boolean | 否 | - | 是否记住登录状态，可选，默认 false | false |

*注：username 和 email 必须提供其中一个

**请求示例**:
```json
{
  "username": "admin",
  "password": "password123",
  "rememberMe": false
}
```

**成功响应** (HTTP 200):
```json
{
  "success": true,
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "refreshToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "expiresIn": 1800
  },
  "message": "登录成功",
  "meta": {
    "timestamp": "2024-01-20T10:30:00.000Z",
    "requestId": "req-123456",
    "version": "v1"
  }
}
```

**错误响应**:
- **400 Bad Request**: 参数验证失败
- **401 Unauthorized**: 用户名或密码错误
- **429 Too Many Requests**: 登录尝试过多

### 3. 用户登出

**接口路径**: `POST /auth/logout`

**功能描述**: 用户登出，清除服务端会话信息。该接口用于用户退出登录，清除服务端的会话状态和令牌信息，确保安全退出。登出后，当前的访问令牌和刷新令牌将被加入黑名单，无法再次使用。

**认证要求**: 需要 Bearer Token

**请求头**:
```
Authorization: Bearer <access_token>
```

**请求参数**:

| 参数名 | 类型 | 必填 | 描述 | 示例 |
|--------|------|------|------|------|
| refreshToken | string | 是 | 刷新令牌 | "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..." |

**请求示例**:
```json
{
  "refreshToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
}
```

**成功响应** (HTTP 200):
```json
{
  "success": true,
  "data": {},
  "message": "登出成功",
  "meta": {
    "timestamp": "2024-01-20T10:30:00.000Z",
    "requestId": "req-123456",
    "version": "v1"
  }
}
```

**错误响应**:
- **400 Bad Request**: 参数验证失败
- **401 Unauthorized**: 未授权访问
- **404 Not Found**: 刷新令牌不存在

### 4. 刷新访问令牌

**接口路径**: `POST /auth/refresh-tokens`

**功能描述**: 使用刷新令牌获取新的访问令牌。当访问令牌过期时，可以使用此接口通过有效的刷新令牌获取新的访问令牌和刷新令牌，无需用户重新登录，提升用户体验。

**请求参数**:

| 参数名 | 类型 | 必填 | 描述 | 示例 |
|--------|------|------|------|------|
| refreshToken | string | 是 | 刷新令牌 | "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..." |

**请求示例**:
```json
{
  "refreshToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
}
```

**成功响应** (HTTP 200):
```json
{
  "access": {
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "expires": "2024-01-20T11:00:00.000Z"
  },
  "refresh": {
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "expires": "2024-02-20T10:30:00.000Z"
  }
}
```

**错误响应**:
- **401 Unauthorized**: 刷新令牌无效或已过期

### 5. 忘记密码

**接口路径**: `POST /auth/forgot-password`

**功能描述**: 发送重置密码邮件到用户邮箱。当用户忘记密码时，可以使用此接口发送密码重置邮件到用户注册的邮箱地址，邮件中包含重置密码的安全链接和令牌。

**请求参数**:

| 参数名 | 类型 | 必填 | 描述 | 示例 |
|--------|------|------|------|------|
| email | string | 是 | 用户邮箱地址 | "user@example.com" |

**请求示例**:
```json
{
  "email": "user@example.com"
}
```

**成功响应** (HTTP 204):
无响应体，仅返回状态码

**错误响应**:
- **404 Not Found**: 邮箱地址不存在

### 6. 重置密码

**接口路径**: `POST /auth/reset-password`

**功能描述**: 使用重置密码令牌重置用户密码。用户通过忘记密码邮件中的链接访问此接口，提供有效的重置令牌和新密码来完成密码重置操作。重置成功后，所有现有的访问令牌将失效。

**查询参数**:

| 参数名 | 类型 | 必填 | 描述 | 示例 |
|--------|------|------|------|------|
| token | string | 是 | 重置密码令牌 | "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..." |

**请求参数**:

| 参数名 | 类型 | 必填 | 长度限制 | 描述 | 示例 |
|--------|------|------|----------|------|------|
| password | string | 是 | 最少8字符 | 新密码，至少包含一个数字和一个字母 | "newPassword123" |

**请求示例**:
```
POST /auth/reset-password?token=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
```

```json
{
  "password": "newPassword123"
}
```

**成功响应** (HTTP 204):
无响应体，仅返回状态码

**错误响应**:
- **401 Unauthorized**: 重置令牌无效或已过期

### 7. 发送验证邮件

**接口路径**: `POST /auth/send-verification-email`

**功能描述**: 向用户邮箱发送邮箱验证邮件。已登录用户可以使用此接口重新发送邮箱验证邮件，邮件中包含验证链接和令牌，用于确认邮箱地址的有效性。

**认证要求**: 需要 Bearer Token

**请求头**:
```
Authorization: Bearer <access_token>
```

**请求参数**: 无

**成功响应** (HTTP 204):
无响应体，仅返回状态码

**错误响应**:
- **401 Unauthorized**: 未授权访问

### 8. 验证邮箱

**接口路径**: `POST /auth/verify-email`

**功能描述**: 使用验证令牌验证用户邮箱。用户通过邮箱验证邮件中的链接访问此接口，提供有效的验证令牌来完成邮箱验证操作，验证成功后用户的邮箱状态将被标记为已验证。

**查询参数**:

| 参数名 | 类型 | 必填 | 描述 | 示例 |
|--------|------|------|------|------|
| token | string | 是 | 邮箱验证令牌 | "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..." |

**请求示例**:
```
POST /auth/verify-email?token=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
```

**成功响应** (HTTP 204):
无响应体，仅返回状态码

**错误响应**:
- **401 Unauthorized**: 验证令牌无效或已过期

### 9. 获取用户信息

**接口路径**: `GET /auth/user`

**功能描述**: 获取当前登录用户的详细信息。该接口需要用户已登录并提供有效的访问令牌，返回当前用户的完整信息，包括基本资料、角色权限等。

**认证要求**: 需要 Bearer Token

**请求头**:
```
Authorization: Bearer <access_token>
```

**请求参数**: 无

**成功响应** (HTTP 200):
```json
{
  "success": true,
  "data": {
    "id": "user-123",
    "username": "admin",
    "name": "张三",
    "email": "user@example.com",
    "avatar": "",
    "roles": ["user"],
    "permissions": []
  },
  "message": "获取用户信息成功",
  "meta": {
    "timestamp": "2024-01-20T10:30:00.000Z",
    "requestId": "req-123456",
    "version": "v1"
  }
}
```

**响应字段说明**:

| 字段名 | 类型 | 描述 | 示例 |
|--------|------|------|------|
| id | string | 用户ID | "user-123" |
| username | string | 用户名 | "admin" |
| name | string | 用户姓名 | "张三" |
| email | string | 用户邮箱 | "user@example.com" |
| avatar | string | 用户头像URL | "" |
| roles | array | 用户角色列表 | ["user"] |
| permissions | array | 用户权限列表 | [] |

**错误响应**:
- **401 Unauthorized**: 未授权访问

## 错误码说明

### 认证相关错误码

| 错误码 | HTTP状态码 | 说明 | 处理建议 |
|--------|------------|------|----------|
| AUTH_001 | 401 | 未授权访问 | 需要提供有效的访问令牌 |
| AUTH_002 | 401 | 令牌已过期 | 使用刷新令牌获取新的访问令牌 |
| AUTH_003 | 401 | 无效的令牌 | 重新登录获取新令牌 |
| AUTH_011 | 401 | 用户名或密码错误 | 检查登录凭据 |
| AUTH_014 | 401 | 账户已锁定 | 联系管理员解锁账户 |
| AUTH_020 | 429 | 登录尝试过多 | 稍后重试或联系管理员 |

### 验证相关错误码

| 错误码 | HTTP状态码 | 说明 | 处理建议 |
|--------|------------|------|----------|
| VAL_001 | 400 | 参数验证失败 | 检查请求参数格式和内容 |
| VAL_002 | 400 | 必填参数缺失 | 提供所有必填参数 |
| VAL_003 | 400 | 参数格式错误 | 检查参数类型和格式 |

### 业务逻辑错误码

| 错误码 | HTTP状态码 | 说明 | 处理建议 |
|--------|------------|------|----------|
| BIZ_001 | 409 | 用户名已存在 | 使用不同的用户名 |
| BIZ_002 | 409 | 邮箱已存在 | 使用不同的邮箱地址 |
| BIZ_003 | 404 | 用户不存在 | 检查用户标识 |

### 系统错误码

| 错误码 | HTTP状态码 | 说明 | 处理建议 |
|--------|------------|------|----------|
| SYS_001 | 500 | 服务器内部错误 | 稍后重试或联系技术支持 |
| SYS_002 | 503 | 服务暂时不可用 | 稍后重试 |

## 安全说明

### 认证机制

1. **JWT 令牌**: 使用 JSON Web Token 进行身份认证
2. **双令牌机制**: 访问令牌（短期）+ 刷新令牌（长期）
3. **令牌过期**: 访问令牌默认30分钟过期，刷新令牌默认30天过期
4. **自动刷新**: 支持使用刷新令牌自动获取新的访问令牌

### 安全特性

1. **密码加密**: 使用 bcrypt 对密码进行哈希加密
2. **速率限制**: 对登录接口实施速率限制，防止暴力破解
3. **令牌黑名单**: 登出时将令牌加入黑名单，防止重复使用
4. **邮箱验证**: 支持邮箱验证功能，确保邮箱有效性
5. **密码重置**: 安全的密码重置流程，通过邮件验证身份

### 使用建议

1. **HTTPS**: 生产环境必须使用 HTTPS 传输
2. **令牌存储**: 建议将令牌存储在安全的地方（如 httpOnly cookie）
3. **令牌刷新**: 实现自动令牌刷新机制，提升用户体验
4. **错误处理**: 统一处理认证错误，避免信息泄露
5. **日志记录**: 记录关键操作日志，便于安全审计
