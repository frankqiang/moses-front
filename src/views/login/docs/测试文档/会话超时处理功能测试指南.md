# 会话超时处理功能测试指南

## 测试概述

本文档提供了详细的测试步骤和方法，用于验证会话超时处理功能的完整性和正确性。

## 功能说明

会话超时处理功能实现了以下核心特性：
- 30分钟无操作自动退出
- 会话过期前5分钟显示提醒弹窗
- 全局用户活动监听（鼠标、键盘、触摸事件）
- 多标签页会话状态同步
- 用户可选择继续工作或立即退出

## 测试环境准备

### 1. 启动开发服务器
```bash
npm run dev
```

### 2. 访问应用
打开浏览器访问：http://localhost:9528/

### 3. 登录系统
使用有效的用户凭据登录系统

## 测试用例

### 测试用例1：用户活动监听验证

**目的**：验证系统能够正确监听用户活动并重置会话计时器

**步骤**：
1. 登录系统后，打开浏览器开发者工具控制台
2. 观察控制台输出，应该看到"会话管理器已启动"的日志
3. 在页面上进行以下操作：
   - 移动鼠标
   - 点击页面元素
   - 按键盘按键
   - 滚动页面
4. 每次操作后，会话计时器应该重置

**预期结果**：
- 控制台显示会话管理器启动成功
- 用户活动能够被正确监听和记录
- 活动后会话计时器重置

### 测试用例2：会话过期提醒功能（快速测试）

**目的**：验证会话即将过期时的提醒弹窗功能

**注意**：为了快速测试，需要临时修改会话超时时间

**步骤**：
1. 当前已配置为测试模式，`src/utils/sessionManager.js` 中的配置为：
   ```javascript
   const SESSION_CONFIG = {
     SESSION_TIMEOUT: 3 * 60 * 1000, // 3分钟超时
     WARNING_TIME: 30 * 1000,        // 30秒提醒
     CHECK_INTERVAL: 5 * 1000        // 5秒检查
   }
   ```
2. 重新启动开发服务器（如果需要）
3. 登录系统
4. 停止所有用户操作，等待2分30秒
5. 观察是否出现会话过期提醒弹窗

**预期结果**：
- 在2分30秒后显示会话过期提醒弹窗
- 弹窗包含倒计时显示
- 弹窗提供"继续工作"和"立即退出"两个选项

### 测试用例3：继续工作功能

**目的**：验证用户选择继续工作后会话能够正常延续

**步骤**：
1. 按照测试用例2的步骤，等待2分30秒触发会话过期提醒
2. 在弹窗出现后，点击"继续工作"按钮
3. 观察弹窗是否关闭
4. 检查会话是否重新开始计时

**预期结果**：
- 点击"继续工作"后弹窗立即关闭
- 会话计时器重置
- 用户可以继续正常使用系统

### 测试用例4：立即退出功能

**目的**：验证用户选择立即退出后系统能够正确登出

**步骤**：
1. 按照测试用例2的步骤，等待2分30秒触发会话过期提醒
2. 在弹窗出现后，点击"立即退出"按钮
3. 观察系统行为

**预期结果**：
- 点击"立即退出"后立即执行登出操作
- 显示"会话已过期，请重新登录"提示消息
- 自动跳转到登录页面
- 本地存储中的认证信息被清除

### 测试用例5：自动超时退出

**目的**：验证会话超时后系统能够自动执行登出

**步骤**：
1. 使用当前的测试配置（3分钟超时，30秒提醒）
2. 登录系统后完全停止操作
3. 等待2分30秒，会话过期提醒弹窗出现
4. 不进行任何操作，等待30秒倒计时结束

**预期结果**：
- 倒计时结束后自动执行登出
- 显示超时提示消息
- 自动跳转到登录页面

### 测试用例6：多标签页同步功能

**目的**：验证多个标签页之间的会话状态同步

**步骤**：
1. 在浏览器中打开两个标签页，都访问应用并登录
2. 在标签页A中进行用户操作
3. 切换到标签页B，观察会话状态
4. 在标签页B中触发登出操作
5. 观察标签页A的状态变化

**预期结果**：
- 标签页A的活动能够同步到标签页B
- 标签页B登出后，标签页A也应该同步登出
- 所有标签页的会话状态保持一致

### 测试用例7：页面刷新后会话恢复

**目的**：验证页面刷新后会话管理器能够正确恢复

**步骤**：
1. 登录系统
2. 进行一些用户操作
3. 刷新页面（F5或Ctrl+R）
4. 观察会话管理器是否重新启动

**预期结果**：
- 页面刷新后会话管理器自动重新启动
- 会话状态正确恢复
- 用户无需重新登录

### 测试用例8：网络异常情况处理

**目的**：验证网络异常时会话管理的健壮性

**步骤**：
1. 登录系统
2. 断开网络连接
3. 触发会话过期提醒
4. 尝试继续工作或退出
5. 恢复网络连接

**预期结果**：
- 网络异常时系统不应崩溃
- 登出操作应该能够处理网络错误
- 网络恢复后功能正常

## 常见问题排查

### 问题1：会话管理器未启动

**症状**：控制台没有显示"会话管理器已启动"日志

**排查步骤**：
1. 检查用户是否已登录
2. 检查token是否有效
3. 检查permission.js中的集成代码

### 问题2：弹窗不显示

**症状**：会话即将过期时没有显示提醒弹窗

**排查步骤**：
1. 检查SessionExpiryDialog组件是否正确导入
2. 检查Vue组件挂载是否成功
3. 检查CSS样式是否正确加载

### 问题3：多标签页同步失效

**症状**：多个标签页之间会话状态不同步

**排查步骤**：
1. 检查localStorage是否可用
2. 检查storage事件监听是否正确注册
3. 检查浏览器是否支持storage事件
