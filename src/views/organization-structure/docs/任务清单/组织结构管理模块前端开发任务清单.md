# 组织结构管理模块前端开发任务清单

## 项目概述

基于项目需求文档3.6.2章节，组织结构管理模块是用户权限管理体系的重要基础模块，负责维护企业的部门层级结构和岗位信息。该模块为数据权限配置和工作流分配提供组织架构支撑，是实现基于组织架构的权限控制和业务流程管理的核心模块。本模块与现有Vue前端架构集成，采用Element UI组件库，遵循项目既定的开发规范和组件复用原则。

## 🚨 紧急开发模式说明

**开发原则：** 在当前项目时间紧张的情况下，采用"能用即可"的原则，优先确保核心功能的可用性和主要业务流程的正常执行。

**优先级说明：**

- 🔴 **P0 - 核心必需（立即实施）：** 系统基本运行的最低要求，必须在第一阶段完成
- 🟡 **P1 - 重要功能（第二阶段）：** 影响用户体验但不阻塞主流程的功能
- 🟢 **P2 - 优化功能（后续完善）：** 可以暂缓实现，待后续优化阶段逐步完善

### TASK001: 部门管理页面核心功能开发 🔴 **P0**

**任务名称:** 部门管理页面基础架构与核心 CRUD 功能实现（基于全局组件與真实 API）

**任务描述:**

- **需求文档参考:** `3.6.2. 组织结构管理 (Organization Structure Management)`
- **接口文档参考:**
  - `1. 创建部门 (POST /v1/departments)`
  - `2. 获取部门列表 (GET /v1/departments)`
  - `3. 获取部门树形结构 (GET /v1/departments/tree)`
  - `4. 获取部门详情 (GET /v1/departments/:id)`
  - `5. 更新部门信息 (PUT /v1/departments/:id)`
  - `6. 删除部门 (DELETE /v1/departments/:id)`

- 页面与组件：
  - 使用全局组件：`SearchForm`、`TableToolbar`、`BaseTable`、`DrawerForm`（或現有 `DepartmentFormDrawer`）、`ActionButtons`，避免直接使用 `el-table`/`el-tree`
  - 树形展示采用 `BaseTable` + 扁平化渲染方案（支持節點縮展），兼容大數據虛擬滾動

- 数据对接：
  - 首选调用 `GET /v1/departments/tree` 拉取树形数据；若失败则回退调用 `GET /v1/departments` 并在前端按 `parentId` 客户端构建树
  - 所有请求通过统一 `@/utils/request.js` 发起；严格使用真实后端 API，禁止使用 Mock（见 `development-config`）

- 开发阶段规范（development-config）：
  - 不编写任何权限检查逻辑（页面、组件、按钮、路由均不做权限拦截）
  - 为确保接口可用，开发环境需初始化临时 Token（通过 `@/utils/auth` 的 `setToken`/`setTokens`），以便请求头自动附带 `Authorization: Bearer <token>`

- 功能点：
  - 部门列表树形展示、节点评价/折叠、分页（如使用）、虚拟滚动（>1000 条启用）
  - 新增/编辑（表单校验与数据回填）、删除（确认与后端关联检查提示）
  - 导出（如需）与刷新、基础搜索（名称/状态/父级）

**版本:** v1.0

**状态:** 🚧 进行中

**🔴 P0 阶段验收标准（核心功能）:**

2. [ ] 新增部门：`POST /v1/departments` 成功，表单必填校验（`name`、`code`）有效，`code` 自动大写且唯一冲突能友好提示

**注意事项:**
