## 1. 设计概述

### 1.1 设计原则

基于 Moses API 项目的数据库开发规范，本设计遵循以下原则：

- **第三范式设计**：确保数据结构规范化，减少数据冗余
- **PostgreSQL + Sequelize ORM**：使用项目标准技术栈
- **安全性优先**：敏感数据加密存储，实现参数化查询
- **性能优化**：合理设计索引，优化查询性能
- **可扩展性**：预留扩展字段，支持业务发展

### 1.2 核心功能支持

数据库设计需要支持以下核心功能：

- **用户管理**：用户账号、基本信息、状态管理
- **角色管理**：角色定义、权限配置、状态控制
- **组织结构**：部门层级、岗位管理、人员归属
- **权限配置**：功能权限、数据权限、操作权限
- **审计追踪**：操作日志、变更历史、安全审计

## 2. 数据库表设计

### 2.1 用户相关表

#### 2.1.1 用户基础信息表 (users)

```sql
CREATE TABLE users (
    id SERIAL PRIMARY KEY,
    username VARCHAR(50) NOT NULL UNIQUE,
    email VARCHAR(100) NOT NULL UNIQUE,
    password_hash VARCHAR(255) NOT NULL,
    salt VARCHAR(32) NOT NULL,
    full_name VARCHAR(100) NOT NULL,
    phone VARCHAR(20),
    avatar_url VARCHAR(500),
    status VARCHAR(20) DEFAULT 'active' CHECK (status IN ('active', 'inactive', 'locked', 'deleted')),
    email_verified BOOLEAN DEFAULT FALSE,
    phone_verified BOOLEAN DEFAULT FALSE,
    last_login_at TIMESTAMP WITH TIME ZONE,
    last_login_ip INET,
    login_count INTEGER DEFAULT 0,
    failed_login_count INTEGER DEFAULT 0,
    locked_until TIMESTAMP WITH TIME ZONE,
    password_changed_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    created_by INTEGER REFERENCES users(id),
    updated_by INTEGER REFERENCES users(id)
);

COMMENT ON TABLE users IS '用户基础信息表';
COMMENT ON COLUMN users.username IS '用户名，唯一标识';
COMMENT ON COLUMN users.email IS '邮箱地址，用于登录和通知';
COMMENT ON COLUMN users.password_hash IS '密码哈希值，使用bcrypt加密';
COMMENT ON COLUMN users.salt IS '密码盐值';
COMMENT ON COLUMN users.status IS '用户状态：active-正常，inactive-未激活，locked-锁定，deleted-已删除';
COMMENT ON COLUMN users.failed_login_count IS '连续登录失败次数';
COMMENT ON COLUMN users.locked_until IS '账号锁定截止时间';
```

#### 2.1.2 用户扩展信息表 (user_profiles)

```sql
CREATE TABLE user_profiles (
    id SERIAL PRIMARY KEY,
    user_id INTEGER NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    employee_id VARCHAR(50),
    job_title VARCHAR(100),
    department_id INTEGER REFERENCES departments(id),
    manager_id INTEGER REFERENCES users(id),
    hire_date DATE,
    birth_date DATE,
    gender VARCHAR(10) CHECK (gender IN ('male', 'female', 'other')),
    address TEXT,
    emergency_contact VARCHAR(100),
    emergency_phone VARCHAR(20),
    notes TEXT,
    custom_fields JSONB,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

COMMENT ON TABLE user_profiles IS '用户扩展信息表';
COMMENT ON COLUMN user_profiles.employee_id IS '员工编号';
COMMENT ON COLUMN user_profiles.custom_fields IS '自定义字段，JSON格式存储';
```

### 2.2 角色相关表

#### 2.2.1 角色基础信息表 (roles)

```sql
CREATE TABLE roles (
    id SERIAL PRIMARY KEY,
    name VARCHAR(100) NOT NULL UNIQUE,
    code VARCHAR(50) NOT NULL UNIQUE,
    description TEXT,
    type VARCHAR(20) DEFAULT 'business' CHECK (type IN ('system', 'business', 'custom')),
    level INTEGER DEFAULT 0,
    status VARCHAR(20) DEFAULT 'active' CHECK (status IN ('active', 'inactive', 'deleted')),
    is_default BOOLEAN DEFAULT FALSE,
    parent_id INTEGER REFERENCES roles(id),
    sort_order INTEGER DEFAULT 0,
    permissions_config JSONB,
    data_scope VARCHAR(20) DEFAULT 'custom' CHECK (data_scope IN ('all', 'dept', 'dept_and_sub', 'self', 'custom')),
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    created_by INTEGER REFERENCES users(id),
    updated_by INTEGER REFERENCES users(id)
);

COMMENT ON TABLE roles IS '角色基础信息表';
COMMENT ON COLUMN roles.code IS '角色编码，用于程序中权限判断';
COMMENT ON COLUMN roles.type IS '角色类型：system-系统角色，business-业务角色，custom-自定义角色';
COMMENT ON COLUMN roles.level IS '角色级别，数字越大级别越高';
COMMENT ON COLUMN roles.data_scope IS '数据权限范围：all-全部数据，dept-本部门，dept_and_sub-本部门及下级，self-个人，custom-自定义';
```

#### 2.2.2 用户角色关联表 (user_roles)

```sql
CREATE TABLE user_roles (
    id SERIAL PRIMARY KEY,
    user_id INTEGER NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    role_id INTEGER NOT NULL REFERENCES roles(id) ON DELETE CASCADE,
    assigned_by INTEGER REFERENCES users(id),
    assigned_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    expires_at TIMESTAMP WITH TIME ZONE,
    status VARCHAR(20) DEFAULT 'active' CHECK (status IN ('active', 'inactive', 'expired')),
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    UNIQUE(user_id, role_id)
);

COMMENT ON TABLE user_roles IS '用户角色关联表';
COMMENT ON COLUMN user_roles.assigned_by IS '角色分配人';
COMMENT ON COLUMN user_roles.expires_at IS '角色过期时间，NULL表示永不过期';
```

### 2.3 组织结构表

#### 2.3.1 部门信息表 (departments)

```sql
CREATE TABLE departments (
    id SERIAL PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    code VARCHAR(50) NOT NULL UNIQUE,
    parent_id INTEGER REFERENCES departments(id),
    level INTEGER DEFAULT 1,
    path VARCHAR(500),
    manager_id INTEGER REFERENCES users(id),
    deputy_manager_id INTEGER REFERENCES users(id),
    type VARCHAR(20) DEFAULT 'business' CHECK (type IN ('company', 'division', 'department', 'team', 'group')),
    status VARCHAR(20) DEFAULT 'active' CHECK (status IN ('active', 'inactive', 'deleted')),
    sort_order INTEGER DEFAULT 0,
    description TEXT,
    contact_phone VARCHAR(20),
    contact_email VARCHAR(100),
    address TEXT,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    created_by INTEGER REFERENCES users(id),
    updated_by INTEGER REFERENCES users(id)
);

COMMENT ON TABLE departments IS '部门信息表';
COMMENT ON COLUMN departments.path IS '部门路径，如：/1/2/3/';
COMMENT ON COLUMN departments.level IS '部门层级，从1开始';
COMMENT ON COLUMN departments.type IS '部门类型：company-公司，division-事业部，department-部门，team-团队，group-小组';
```

#### 2.3.2 岗位信息表 (positions)

```sql
CREATE TABLE positions (
    id SERIAL PRIMARY KEY,

    department_id INTEGER REFERENCES departments(id),
    level INTEGER DEFAULT 1,
    category VARCHAR(50),
    description TEXT,

    requirements TEXT,
    status VARCHAR(20) DEFAULT 'active' CHECK (status IN ('active', 'inactive', 'deleted')),
    sort_order INTEGER DEFAULT 0,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    created_by INTEGER REFERENCES users(id),
    updated_by INTEGER REFERENCES users(id)
);

COMMENT ON TABLE positions IS '岗位信息表';
COMMENT ON COLUMN positions.responsibilities IS '岗位职责描述';
COMMENT ON COLUMN positions.requirements IS '岗位要求描述';
```

### 2.4 权限相关表

#### 2.4.1 权限资源表 (permissions)

```sql
CREATE TABLE permissions (
    id SERIAL PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    code VARCHAR(100) NOT NULL UNIQUE,
    type VARCHAR(20) NOT NULL CHECK (type IN ('menu', 'button', 'api', 'data', 'field')),
    parent_id INTEGER REFERENCES permissions(id),
    level INTEGER DEFAULT 1,
    path VARCHAR(500),
    resource_url VARCHAR(500),
    method VARCHAR(10),
    icon VARCHAR(100),
    sort_order INTEGER DEFAULT 0,
    status VARCHAR(20) DEFAULT 'active' CHECK (status IN ('active', 'inactive', 'deleted')),
    description TEXT,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    created_by INTEGER REFERENCES users(id),
    updated_by INTEGER REFERENCES users(id)
);

COMMENT ON TABLE permissions IS '权限资源表';
COMMENT ON COLUMN permissions.type IS '权限类型：menu-菜单，button-按钮，api-接口，data-数据，field-字段';
COMMENT ON COLUMN permissions.path IS '权限路径，如：/system/user/list';
COMMENT ON COLUMN permissions.method IS 'HTTP方法，如：GET、POST、PUT、DELETE';
```

#### 2.4.2 角色权限关联表 (role_permissions)

```sql
CREATE TABLE role_permissions (
    id SERIAL PRIMARY KEY,
    role_id INTEGER NOT NULL REFERENCES roles(id) ON DELETE CASCADE,
    permission_id INTEGER NOT NULL REFERENCES permissions(id) ON DELETE CASCADE,
    granted BOOLEAN DEFAULT TRUE,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    created_by INTEGER REFERENCES users(id),
    UNIQUE(role_id, permission_id)
);

COMMENT ON TABLE role_permissions IS '角色权限关联表';
COMMENT ON COLUMN role_permissions.granted IS '是否授权，TRUE-授权，FALSE-拒绝';
```

### 2.5 审计日志表

#### 2.5.1 操作日志表 (audit_logs)

```sql
CREATE TABLE audit_logs (
    id SERIAL PRIMARY KEY,
    user_id INTEGER REFERENCES users(id),
    action VARCHAR(50) NOT NULL,
    resource_type VARCHAR(50) NOT NULL,
    resource_id VARCHAR(100),
    old_values JSONB,
    new_values JSONB,
    ip_address INET,
    user_agent TEXT,
    request_id VARCHAR(100),
    session_id VARCHAR(100),
    status VARCHAR(20) DEFAULT 'success' CHECK (status IN ('success', 'failed', 'error')),
    error_message TEXT,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

COMMENT ON TABLE audit_logs IS '操作审计日志表';
COMMENT ON COLUMN audit_logs.action IS '操作类型：create、update、delete、login、logout等';
COMMENT ON COLUMN audit_logs.resource_type IS '资源类型：user、role、department等';
COMMENT ON COLUMN audit_logs.old_values IS '变更前的值，JSON格式';
COMMENT ON COLUMN audit_logs.new_values IS '变更后的值，JSON格式';
```

## 3. 索引设计

### 3.1 主要索引

```sql
-- 用户表索引
CREATE INDEX idx_users_username ON users(username);
CREATE INDEX idx_users_email ON users(email);
CREATE INDEX idx_users_status ON users(status);
CREATE INDEX idx_users_last_login_at ON users(last_login_at);
CREATE INDEX idx_users_created_at ON users(created_at);

-- 用户扩展信息表索引
CREATE INDEX idx_user_profiles_user_id ON user_profiles(user_id);
CREATE INDEX idx_user_profiles_department_id ON user_profiles(department_id);
CREATE INDEX idx_user_profiles_manager_id ON user_profiles(manager_id);
CREATE INDEX idx_user_profiles_employee_id ON user_profiles(employee_id);

-- 角色表索引
CREATE INDEX idx_roles_code ON roles(code);
CREATE INDEX idx_roles_type ON roles(type);
CREATE INDEX idx_roles_status ON roles(status);
CREATE INDEX idx_roles_parent_id ON roles(parent_id);

-- 用户角色关联表索引
CREATE INDEX idx_user_roles_user_id ON user_roles(user_id);
CREATE INDEX idx_user_roles_role_id ON user_roles(role_id);
CREATE INDEX idx_user_roles_status ON user_roles(status);
CREATE INDEX idx_user_roles_expires_at ON user_roles(expires_at);

-- 部门表索引
CREATE INDEX idx_departments_code ON departments(code);
CREATE INDEX idx_departments_parent_id ON departments(parent_id);
CREATE INDEX idx_departments_path ON departments(path);
CREATE INDEX idx_departments_manager_id ON departments(manager_id);

-- 权限表索引
CREATE INDEX idx_permissions_code ON permissions(code);
CREATE INDEX idx_permissions_type ON permissions(type);
CREATE INDEX idx_permissions_parent_id ON permissions(parent_id);
CREATE INDEX idx_permissions_path ON permissions(path);

-- 角色权限关联表索引
CREATE INDEX idx_role_permissions_role_id ON role_permissions(role_id);
CREATE INDEX idx_role_permissions_permission_id ON role_permissions(permission_id);

-- 审计日志表索引
CREATE INDEX idx_audit_logs_user_id ON audit_logs(user_id);
CREATE INDEX idx_audit_logs_action ON audit_logs(action);
CREATE INDEX idx_audit_logs_resource_type ON audit_logs(resource_type);
CREATE INDEX idx_audit_logs_created_at ON audit_logs(created_at);
CREATE INDEX idx_audit_logs_ip_address ON audit_logs(ip_address);
```

### 3.2 复合索引

```sql
-- 用户状态和创建时间复合索引
CREATE INDEX idx_users_status_created_at ON users(status, created_at);

-- 用户角色状态和过期时间复合索引
CREATE INDEX idx_user_roles_status_expires_at ON user_roles(status, expires_at);

-- 部门层级和状态复合索引
CREATE INDEX idx_departments_level_status ON departments(level, status);

-- 权限类型和状态复合索引
CREATE INDEX idx_permissions_type_status ON permissions(type, status);

-- 审计日志资源类型和创建时间复合索引
CREATE INDEX idx_audit_logs_resource_type_created_at ON audit_logs(resource_type, created_at);
```

## 4. 约束设计

### 4.1 外键约束

```sql
-- 用户扩展信息表外键约束
ALTER TABLE user_profiles ADD CONSTRAINT fk_user_profiles_user_id
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE;
ALTER TABLE user_profiles ADD CONSTRAINT fk_user_profiles_department_id
    FOREIGN KEY (department_id) REFERENCES departments(id) ON DELETE SET NULL;
ALTER TABLE user_profiles ADD CONSTRAINT fk_user_profiles_manager_id
    FOREIGN KEY (manager_id) REFERENCES users(id) ON DELETE SET NULL;

-- 用户角色关联表外键约束
ALTER TABLE user_roles ADD CONSTRAINT fk_user_roles_user_id
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE;
ALTER TABLE user_roles ADD CONSTRAINT fk_user_roles_role_id
    FOREIGN KEY (role_id) REFERENCES roles(id) ON DELETE CASCADE;

-- 部门表外键约束
ALTER TABLE departments ADD CONSTRAINT fk_departments_parent_id
    FOREIGN KEY (parent_id) REFERENCES departments(id) ON DELETE SET NULL;
ALTER TABLE departments ADD CONSTRAINT fk_departments_manager_id
    FOREIGN KEY (manager_id) REFERENCES users(id) ON DELETE SET NULL;

-- 角色权限关联表外键约束
ALTER TABLE role_permissions ADD CONSTRAINT fk_role_permissions_role_id
    FOREIGN KEY (role_id) REFERENCES roles(id) ON DELETE CASCADE;
ALTER TABLE role_permissions ADD CONSTRAINT fk_role_permissions_permission_id
    FOREIGN KEY (permission_id) REFERENCES permissions(id) ON DELETE CASCADE;
```

### 4.2 检查约束

```sql
-- 用户状态检查约束
ALTER TABLE users ADD CONSTRAINT chk_users_status
    CHECK (status IN ('active', 'inactive', 'locked', 'deleted'));

-- 角色类型检查约束
ALTER TABLE roles ADD CONSTRAINT chk_roles_type
    CHECK (type IN ('system', 'business', 'custom'));

-- 部门类型检查约束
ALTER TABLE departments ADD CONSTRAINT chk_departments_type
    CHECK (type IN ('company', 'division', 'department', 'team', 'group'));

-- 权限类型检查约束
ALTER TABLE permissions ADD CONSTRAINT chk_permissions_type
    CHECK (type IN ('menu', 'button', 'api', 'data', 'field'));
```

## 总结

本数据库设计文档基于 Moses API 项目的数据库开发规范，为用户角色管理界面提供了完整的数据库支持。设计包含：

1. **完整的表结构设计**：涵盖用户、角色、组织、权限、审计等核心功能
2. **优化的索引策略**：提供高效的查询性能
3. **严格的约束控制**：确保数据完整性和一致性

该设计充分考虑了安全性、性能、可扩展性和维护性，为用户权限管理模块的开发提供了坚实的数据基础。
