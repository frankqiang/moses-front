# 密码管理功能使用说明

用户管理模块现已完成密码管理功能的P0阶段开发，包含以下核心功能：

### 📋 **已完成功能清单**

1. ✅ **管理员重置用户密码**
2. ✅ **用户修改自己的密码**
3. ✅ **密码强度实时验证**
4. ✅ **密码修改成功提示**
5. ✅ **密码输入框安全性处理**

## 功能详细说明

### 1. 管理员重置用户密码

**功能入口：** 用户管理列表 → 操作列 → 重置密码

**功能特性：**
- 支持系统自动生成安全密码或管理员手动输入
- 可设置是否要求用户下次登录时修改密码
- 密码强度实时验证和提示
- 自动生成的临时密码会显示给管理员
- 完整的安全提示和操作记录

**使用流程：**
1. 在用户列表中找到目标用户，点击"重置密码"
2. 选择重置方式：系统自动生成 或 手动输入新密码
3. 如选择手动输入，可使用密码生成器生成安全密码
4. 设置是否要求用户下次登录时修改密码
5. 可填写重置原因（可选）
6. 确认重置，系统会显示临时密码

### 2. 用户修改密码

**功能入口：** 个人中心页面 → 账户设置 → 修改密码

**重要更正：** 为确保系统安全性，用户修改密码功能已从用户管理页面移至个人中心页面。用户只能修改自己的密码，无法修改他人密码。

**功能特性：**
- 需要验证当前密码
- 新密码强度实时验证
- 支持密码生成器生成安全密码
- 修改成功后可选择重新登录
- 完整的安全建议和提示

**使用流程：**
1. 点击顶部导航栏用户头像，选择"个人中心"
2. 在个人中心的"账户设置"区域，点击"修改密码"按钮
3. 输入当前密码进行身份验证
4. 输入新密码，系统会实时验证强度
5. 确认新密码
6. 提交修改，成功后可选择重新登录

### 3. 密码强度验证

**验证规则：**
- 最小长度：8位字符
- 必须包含：字母和数字
- 推荐包含：大写字母、小写字母、数字、特殊字符

**强度等级：**
- 🔴 **弱**：仅满足基本要求
- 🟡 **中**：包含3种字符类型
- 🟢 **强**：包含4种字符类型，长度适中
- 🔵 **很强**：包含所有字符类型，长度较长

**实时反馈：**
- 颜色进度条显示强度等级
- 具体的改进建议
- 常见弱密码模式检测

### 4. 密码输入框安全性

**安全特性：**
- 默认启用安全模式，禁用复制、粘贴功能
- 禁用右键菜单
- 禁用拖拽操作
- 支持密码可见性切换
- 内置密码生成器

## 技术实现

### 核心组件

1. **SecurePasswordInput** - 安全密码输入框
2. **PasswordStrengthIndicator** - 密码强度指示器
3. **ResetPasswordDialog** - 管理员重置密码对话框
4. **ChangePasswordDialog** - 用户修改密码对话框

### 工具函数

1. **password-utils.js** - 密码相关工具函数
   - `validatePasswordBasic()` - 基础密码验证
   - `calculatePasswordStrength()` - 密码强度计算
   - `generateSecurePassword()` - 安全密码生成
   - `disablePasswordCopyPaste()` - 禁用复制粘贴

### API接口

1. **resetUserPassword()** - 管理员重置用户密码
2. **changeUserPassword()** - 用户修改密码

## 配置说明

### 密码策略配置

密码策略基于需求文档中的安全策略配置：

```javascript
// 基础要求
{
  minLength: 8,          // 最小长度
  requireLetter: true,   // 必须包含字母
  requireNumber: true,   // 必须包含数字
}

// 推荐配置
{
  requireUpperCase: true,  // 推荐大写字母
  requireSymbol: true,     // 推荐特殊字符
  maxLength: 50,          // 最大长度
}
```

### 安全模式配置

```javascript
// 默认安全设置
{
  securityMode: true,        // 启用安全模式
  disableCopyPaste: true,    // 禁用复制粘贴
  showStrengthIndicator: true,  // 显示强度指示器
  requirePasswordChange: true,   // 重置后要求修改密码
}
```

## 最佳实践

### 管理员操作建议

1. **重置密码时：**
   - 建议使用系统自动生成安全密码
   - 始终要求用户首次登录后修改密码
   - 记录重置原因，便于安全审计
   - 通过安全渠道将临时密码传达给用户

2. **密码策略：**
   - 定期检查用户密码强度
   - 建议用户使用强密码
   - 定期提醒用户更换密码

### 用户操作建议

1. **密码选择：**
   - 使用系统推荐的强密码
   - 避免使用个人信息作为密码
   - 不要在多个系统使用相同密码

2. **安全习惯：**
   - 定期主动修改密码
   - 发现账户异常时立即修改密码
   - 妥善保管密码，不要泄露给他人

## 故障排除

### 常见问题

1. **密码强度不满足要求**
   - 检查是否包含字母和数字
   - 确保长度至少8位
   - 参考强度指示器的建议

2. **重置密码失败**
   - 检查网络连接
   - 确认当前用户有重置权限
   - 检查目标用户状态是否正常

3. **修改密码失败**
   - 确认当前密码输入正确
   - 检查新密码格式是否符合要求
   - 确保网络连接正常
