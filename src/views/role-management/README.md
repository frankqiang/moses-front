# 角色管理模块

## 功能概述

角色管理模块用于管理系统中的角色定义，是RBAC权限管理体系的核心组件。角色作为权限分配的载体，支持角色的创建、编辑、复制、删除以及状态管理功能。

## 主要功能

1. **角色列表展示**：以表格形式展示所有角色，包括角色名称、编码、类型、状态、级别、用户数量、创建时间等信息。
2. **搜索与筛选**：支持按角色名称、编码进行搜索，按角色类型、状态、级别、默认角色等条件进行筛选。
3. **角色管理**：支持新增、编辑、查看、复制、删除角色。
4. **状态管理**：支持启用/禁用角色，以及批量状态变更。
5. **权限控制**：系统角色和有用户关联的角色受到保护，防止误操作。

## 使用的全局组件

- **SearchForm**：搜索表单组件，用于实现角色的搜索和筛选功能。
- **BaseTable**：表格组件，用于展示角色列表，支持排序、分页、选择等功能。
- **TableToolbar**：表格工具栏组件，用于实现批量操作、列设置、刷新等功能。
- **StatusTag**：状态标签组件，用于展示角色的类型和状态。
- **ActionButtons**：操作按钮组件，用于实现角色的各种操作。
- **Drawer**：抽屉组件，用于角色表单的弹出显示。

## 数据结构

角色对象包含以下字段：

```javascript
{
  id: 'role-123',              // 角色ID
  name: '系统管理员',           // 角色名称
  code: 'admin',               // 角色编码
  description: '系统管理员角色', // 角色描述
  type: 'custom',              // 角色类型：system-系统角色, custom-自定义角色
  level: 1,                    // 角色级别：1-5
  status: 'active',            // 角色状态：active-启用, inactive-禁用
  isDefault: false,            // 是否为默认角色
  userCount: 5,                // 使用该角色的用户数量
  createdAt: '2024-01-20T10:30:00.000Z', // 创建时间
  updatedAt: '2024-01-20T10:30:00.000Z'  // 更新时间
}
```

## 常量配置

模块常量按照标准模式组织（参考 `process-management` 模块）：

- **role.js**: 角色核心常量，包括角色类型、状态、级别等枚举值和配置
- **table-config.js**: 表格配置常量，包括列配置、状态映射等
- **form-config.js**: 表单配置常量，包括搜索表单和角色表单的字段配置
- **index.js**: 统一导出入口，便于组件引用

## API接口

模块使用以下API接口（定义在 `api/roles.js`）：

- `getRoleList(params)` - 获取角色列表
- `createRole(data)` - 创建角色
- `updateRole(id, data)` - 更新角色
- `copyRole(id, data)` - 复制角色
- `deleteRole(id)` - 删除角色
- `updateRoleStatus(id, data)` - 更新角色状态
- `batchDeleteRoles(ids)` - 批量删除角色
- `batchUpdateRoleStatus(ids, data)` - 批量更新角色状态
- `getRolePermissions(id)` - 获取角色权限配置
- `updateRolePermissions(id, data)` - 更新角色权限配置
- `getAvailableRoles(params)` - 获取可用角色列表

## 权限控制

1. **页面权限**：通过路由配置 `meta.roles` 控制页面访问权限
2. **操作权限**：系统角色不允许编辑、删除、状态切换
3. **数据保护**：有用户关联的角色不允许删除
4. **批量操作**：只对符合条件的角色执行批量操作

## 使用说明

1. **访问路径**：通过导航菜单"用户权限 > 角色管理"访问
2. **新增角色**：点击"新增角色"按钮，填写角色信息后提交
3. **编辑角色**：点击表格行的"编辑"按钮，修改角色信息后保存
4. **复制角色**：点击"复制"按钮，可选择是否复制权限配置
5. **状态管理**：通过"启用/禁用"按钮切换角色状态
6. **批量操作**：选择多个角色后，使用工具栏的批量操作功能

## 注意事项

1. 角色编码必须唯一，只能包含字母、数字、下划线、中划线
2. 系统角色受到保护，不允许编辑、删除或状态切换
3. 有用户关联的角色不允许删除
4. 角色级别范围为1-5，1为最高级别
5. 默认角色在用户注册时会自动分配给新用户
