## 功能概述

### 所有功能

查询单个维护任务（Get Maintenance Task）是设备TPM管理模块中的核心查询接口之一,用于根据任务ID获取维护任务的完整详情信息，以支持任务详情查看、任务跟踪、状态监控等业务场景。

该接口返回的数据包含维护任务的基本信息、关联数据（设备、维护计划）、人员信息（执行人、确认人、创建人、更新人）、时间信息（计划时间、实际时间）以及任务状态等完整信息，是前端展示任务详情页面的数据基础。

### 关键特性

- ✅ **完整关联信息**：返回任务关联的设备、维护计划、执行人员等完整信息，无需前端二次查询
- ✅ **实时状态同步**：任务状态与设备状态实时关联，准确反映当前执行情况
- ✅ **权限控制**：基于JWT认证，确保只有授权用户可以查看任务详情
- ✅ **快速响应**：基于主键ID查询，查询性能优异，响应速度快
- ✅ **数据完整性**：包含任务创建、更新、执行的全生命周期信息
- ✅ **统一响应格式**：遵循系统统一的成功响应格式，便于前端统一处理

```
┌─────────────────┐
│  JWT认证验证    │ → 失败：返回401未授权错误
└────────┬────────┘
         │ 成功
         ▼
┌─────────────────┐
│  验证taskId格式 │ → 失败：返回400参数错误
└────────┬────────┘
         │ 成功
         ▼
┌─────────────────┐
│  查询任务数据   │ → 不存在：返回404任务不存在
└────────┬────────┘
         │ 存在
         ▼
┌─────────────────┐
│  关联查询设备   │
│  关联查询计划   │

         ▼

└────────┬────────┘
         │

┌─────────────────┐
│  返回成功响应   │ → HTTP 200 + 任务详情JSON
└─────────────────┘
```

### 详细步骤说明

#### 步骤1: JWT认证验证
- **验证内容**：验证请求头中的Bearer Token是否有效
- **失败响应**：HTTP 401，错误码 `UNAUTHORIZED`
- **特殊说明**：Token过期或格式错误都会导致认证失败，需重新登录

#### 步骤2: 路径参数验证
- **操作内容**：使用Joi验证器验证taskId是否为有效的UUID格式
- **技术实现**：`maintenanceTaskValidation.getMaintenanceTask`中间件
- **失败情况**：如果taskId格式不正确，返回HTTP 400参数验证错误

#### 步骤3: 数据库查询任务
- **操作内容**：根据taskId从MaintenanceTask表查询任务记录
- **技术实现**：`maintenanceTaskService.getMaintenanceTaskById(taskId)`
- **查询条件**：`WHERE id = taskId AND isDeleted = false`
- **失败情况**：如果任务不存在或已被软删除，抛出404错误

#### 步骤4: 关联数据查询
- **操作内容**：通过Sequelize的include功能关联查询相关数据
- **关联查询包括**：
  - Equipment（设备信息）
  - MaintenancePlan（维护计划，如果有）
  - User（执行人员 assignee）
  - User（确认人 confirmer）
  - User（创建人 creator）
  - User（更新人 updater）
- **技术实现**：在模型定义中配置的关联关系
- **数据过滤**：User关联仅返回id、name、email字段

#### 步骤5: 数据组装与响应
- **操作内容**：将查询结果组装成统一的响应格式
- **响应封装**：使用`sendSuccess(res, task, '获取维护任务详情成功')`
- **返回内容**：包含success、data、message、meta的完整响应对象

## 接口文档

### 基本信息

**接口路径**: `GET /v1/mdm/tpm/maintenance-tasks/:taskId`

**功能描述**: 根据任务ID返回维护任务的完整详情，包含关联的设备、维护计划、执行人、确认人、创建人、更新人等信息，用于任务详情展示和业务处理。

**认证要求**: JWT Bearer Token，需要 `mdm.tpm.maintenance-task.view` 权限

**请求头**:

```
Authorization: Bearer <access_token>
```

### 路径参数

| 参数名 | 类型   | 必填 | 限制     | 描述                 | 示例                                   |
| ------ | ------ | ---- | -------- | -------------------- | -------------------------------------- |
| taskId | string | 是   | UUID格式 | 维护任务ID，唯一标识 | "d4e5f6a7-b8c9-0123-def0-234567890123" |

### 请求示例

#### cURL 命令

```bash
curl -X GET http://localhost:3000/v1/mdm/tpm/maintenance-tasks/d4e5f6a7-b8c9-0123-def0-234567890123 \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
```

#### JavaScript/Axios 示例

```javascript
const axios = require('axios');

const taskId = 'd4e5f6a7-b8c9-0123-def0-234567890123';
const token = 'eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...';

axios.get(`http://localhost:3000/v1/mdm/tpm/maintenance-tasks/${taskId}`, {
  headers: {
    'Authorization': `Bearer ${token}`
  }
})
.then(response => {
  console.log('任务详情:', response.data.data);
})
.catch(error => {
  console.error('查询失败:', error.response.data);
});
```

## 附录

### 任务状态枚举

| 状态码 | 中文名称 | 说明                 | 可转换状态               |
| ------ | -------- | -------------------- | ------------------------ |
| 待执行 | 待执行   | 任务已创建，等待执行 | → 执行中、已延期、已取消 |
| 执行中 | 执行中   | 任务正在执行中       | → 已完成、已取消         |
| 已完成 | 已完成   | 任务已完成           | （终态，不可转换）       |
| 已延期 | 已延期   | 任务已申请延期       | → 执行中、已取消         |
| 已取消 | 已取消   | 任务已取消           | （终态，不可转换）       |

### 任务类型枚举

| 类型代码 | 中文名称 | 说明                           |
| -------- | -------- | ------------------------------ |
| 计划维护 | 计划维护 | 根据维护计划定期执行的维护任务 |
| 应急抢修 | 应急抢修 | 设备故障时的紧急维修任务       |
| 状态检修 | 状态检修 | 根据设备状态触发的检修任务     |

### 设备状态枚举

| 状态代码 | 中文名称 | 说明                   |
| -------- | -------- | ---------------------- |
| 空闲     | 空闲     | 设备正常，可以执行任务 |
| 维护中   | 维护中   | 设备正在维护，不可使用 |
| 故障     | 故障     | 设备故障，需要维修     |
| 停用     | 停用     | 设备已停用，不可使用   |
