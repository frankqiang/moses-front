## 🔔 逾期功能实施（2025-11-01）

### 功能概述

为日历视图添加了逾期任务标记功能，与列表视图保持一致的判断逻辑，通过视觉化的方式突出显示逾期任务。

### 实施内容

#### 1. 逾期判断逻辑

添加 `isOverdue` 方法，判断条件：
- 计划开始时间（start）已过期
- 任务状态为"待执行"或"执行中"
- 与列表视图 TaskTable.vue 的逻辑完全一致

#### 2. 视觉标记方案

**日历事件标记**：
- 逾期任务使用深红色背景（#C45656）
- 深色边框（#A03C3C）增强对比
- 脉冲动画效果，吸引用户注意
- 悬浮时缩放效果更明显

**详情对话框警告**：
- 使用 el-alert 组件显示逾期警告
- 自动计算逾期天数/小时数
- 醒目的红色警告提示

#### 3. 关键代码

```javascript
// 逾期判断
isOverdue(task) {
  if (!task || !task.start) return false
  const now = new Date()
  const plannedTime = new Date(task.start)
  return (
    plannedTime < now &&
    (task.status === '待执行' || task.status === '执行中')
  )
}

// 逾期消息
getOverdueMessage(task) {
  const now = new Date()
  const plannedTime = new Date(task.start)
  const diffMs = now - plannedTime
  const diffHours = Math.floor(diffMs / (1000 * 60 * 60))
  const diffDays = Math.floor(diffHours / 24)

  if (diffDays > 0) {
    return `该任务已逾期 ${diffDays} 天，请尽快处理`
  } else if (diffHours > 0) {
    return `该任务已逾期 ${diffHours} 小时，请尽快处理`
  }
  return '该任务已逾期，请尽快处理'
}
```
