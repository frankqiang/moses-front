# 维护任务管理业务流程说明

## 文档说明

本文档基于维护任务管理模块的实际实现，说明核心业务逻辑和数据流转规则，为前端开发提供业务理解基础。

## 核心概念

### 维护任务与维护记录

- **维护任务（MaintenanceTask）**：从创建到完成的工作安排，包含计划时间、执行人员、任务状态等管理信息
- **维护记录（MaintenanceRecord）**：任务完成后自动生成的历史记录，包含实际维护内容、问题描述、使用备件等详细信息

### 任务类型

| 类型     | 定义                             | 特点                       | 触发方式       |
| -------- | -------------------------------- | -------------------------- | -------------- |
| 计划维护 | 定期执行的预防性维护             | 有固定周期，关联维护计划   | 系统自动或手动 |
| 应急抢修 | 设备故障时的紧急维修             | 优先级高，需快速响应       | 故障时手动创建 |
| 状态检修 | 根据设备运行状态触发的针对性维护 | 基于状态监控数据，按需执行 | 状态异常时创建 |

### 状态模型

#### 状态流转图

```
待执行 → 执行中 → 已完成
   ↓       ↓
已延期 → 已取消
```

#### 状态定义

| 状态   | 含义                         | 可执行操作             |
| ------ | ---------------------------- | ---------------------- |
| 待执行 | 任务已创建，等待执行人员接单 | 派工、接单、延期、取消 |
| 执行中 | 任务已开始，设备维护中       | 完成、延期、取消       |
| 已完成 | 任务已完成，记录已生成       | 无（终态）             |
| 已延期 | 任务因故延期，等待重新开始   | 开始、取消             |
| 已取消 | 任务已取消，不再执行         | 无（终态）             |

### 状态转换约束

| 操作     | 允许状态               | 约束条件                   |
| -------- | ---------------------- | -------------------------- |
| 接单     | 待执行                 | 未派工或派给当前用户       |
| 开始执行 | 待执行、已延期         | 当前用户是执行人           |
| 完成任务 | 执行中                 | 当前用户是执行人           |
| 申请延期 | 待执行、执行中         | 当前用户是执行人           |
| 取消任务 | 待执行、执行中、已延期 | 管理权限或当前用户是执行人 |

## 业务流程详解

### 1. 任务创建

#### 手工创建
- **触发方式**：管理员或调度员通过界面录入
- **必填信息**：设备ID、任务类型、任务标题、计划开始时间
- **可选信息**：任务编码（自动生成：MT-设备编码-时间戳）、维护计划ID、计划结束时间、执行人员、任务描述、备注
- **初始状态**：待执行

#### 自动生成
- **触发方式**：系统根据维护计划周期自动创建
- **自动填充**：任务编码、维护计划ID、设备ID、任务类型、标题描述、计划开始时间
- **初始状态**：待执行

### 2. 任务派工

#### 派工操作
- **条件**：任务状态为"待执行"，执行人员状态为"激活"
- **内容**：指定执行人员，记录派工时间，可重新派工
- **权限**：需要管理权限（mdm.tpm.maintenance-task.manage）

#### 自主接单
- **条件**：任务状态为"待执行"，未派工或已派工给当前用户
- **内容**：维护人员主动接收任务，系统记录接单时间
- **权限**：需要执行权限（mdm.tpm.maintenance-task.execute）

### 3. 任务执行

#### 开始执行
- **状态变更**：待执行/已延期 → 执行中
- **自动触发**：记录实际开始时间，设备状态变更为"维护中"

#### 任务完成
- **必填信息**：维护内容详情
- **可选信息**：发现问题、处理措施、使用备件、维护工时、设备状态前后对比、下次维护建议
- **状态变更**：执行中 → 已完成
- **自动触发**：
  1. 记录实际结束时间和确认人信息
  2. 设备状态恢复为"空闲"
  3. 自动创建维护记录（MR-任务编码-时间戳）

### 4. 任务调整

#### 任务延期
- **条件**：任务状态为"待执行"或"执行中"，当前用户是执行人
- **必填**：延期原因
- **可选**：新的计划开始时间
- **状态变更**：待执行/执行中 → 已延期
- **设备状态**：如处于执行中，设备恢复"空闲"

#### 任务取消
- **条件**：任务状态为"待执行"/"执行中"/"已延期"，有管理权限或是执行人
- **必填**：取消原因
- **状态变更**：→ 已取消
- **设备状态**：如处于执行中，设备恢复"空闲"

### 5. 查询与统计

#### 任务列表查询
- **筛选条件**：设备ID、维护计划ID、任务类型、状态、执行人、关键词、时间范围
- **排序**：默认按计划开始时间升序
- **分页**：每页10-100条

#### 我的任务
- **自动筛选**：当前用户的任务（assignedTo=当前用户）
- **用途**：维护人员查看待办和历史任务

#### 逾期任务
- **定义**：状态为"待执行"或"执行中"且计划开始时间早于当前时间
- **用途**：监控任务执行情况，提醒处理

#### 日历视图
- **数据格式**：适配日历组件（ID、标题、时间、状态、设备、执行人）
- **用途**：展示维护任务时间安排

#### 负载分析
- **分析维度**：按执行人或设备分组
- **统计指标**：总任务数、待执行、执行中、已完成、已延期
- **用途**：工作量分析、资源调配决策

#### 人员筛选
- **筛选条件**：部门ID、岗位ID、角色ID列表
- **用途**：任务派工时选择合适的维护人员

## 数据约束规则

### 任务约束

| 字段         | 约束规则                                           |
| ------------ | -------------------------------------------------- |
| 任务编码     | 自动生成（MT-设备编码-时间戳）或用户指定（需唯一） |
| 计划开始时间 | 必须晚于或等于当前时间                             |
| 计划结束时间 | 如提供，必须晚于计划开始时间                       |
| 设备关联     | 设备必须存在且状态有效                             |
| 维护计划关联 | 如提供，维护计划必须存在且状态有效                 |
| 执行人员关联 | 如提供，执行人员必须存在且状态为"激活"             |
| 任务类型     | 计划维护、应急抢修、状态检修（三选一）             |

### 时间记录规则

| 时间类型     | 记录方式   | 说明                         |
| ------------ | ---------- | ---------------------------- |
| 计划时间     | 创建时指定 | 可通过延期操作更新           |
| 实际开始时间 | 自动记录   | 开始执行时记录，不可手动修改 |
| 实际结束时间 | 自动记录   | 完成任务时记录，不可手动修改 |
| 确认时间     | 自动记录   | 完成任务时记录               |

### 设备状态联动

| 操作     | 任务状态变更                  | 设备状态变更                  |
| -------- | ----------------------------- | ----------------------------- |
| 开始执行 | 待执行/已延期 → 执行中        | 空闲 → 维护中                 |
| 完成任务 | 执行中 → 已完成               | 维护中 → 空闲                 |
| 取消任务 | 待执行/执行中/已延期 → 已取消 | 如是"维护中" → 空闲，否则不变 |
| 任务延期 | 待执行/执行中 → 已延期        | 如是"维护中" → 空闲，否则不变 |

## 权限控制

| 权限代码                         | 权限说明     | 覆盖操作                                   |
| -------------------------------- | ------------ | ------------------------------------------ |
| mdm.tpm.maintenance-task.view    | 查看维护任务 | 查询列表、查看详情、导出、查询统计数据     |
| mdm.tpm.maintenance-task.manage  | 管理维护任务 | 创建、派工、取消（任意任务）               |
| mdm.tpm.maintenance-task.execute | 执行维护任务 | 接单、开始、完成、延期、取消（自己的任务） |

### 执行人验证规则

| 操作     | 验证逻辑                                 |
| -------- | ---------------------------------------- |
| 接单     | assignedTo为空可接单，接单后设为当前用户 |
| 开始执行 | assignedTo必须等于当前用户               |
| 完成任务 | assignedTo必须等于当前用户               |
| 申请延期 | assignedTo必须等于当前用户               |

## 核心业务规则

1. **状态单向流转**：任务状态按预定义规则流转，已完成和已取消不可逆
2. **设备状态联动**：任务执行时设备"维护中"，完成或取消后恢复"空闲"
3. **自动生成记录**：任务完成时自动创建维护记录
4. **执行人验证**：执行相关操作时验证当前用户身份
5. **时间自动记录**：实际时间由系统自动记录，不可手动修改
6. **事务保护**：关键操作使用数据库事务确保数据一致性
7. **状态校验**：操作前验证状态是否允许，不允许则返回明确错误信息

## 模块集成关系

| 关联模块     | 集成方式                                     | 说明                           |
| ------------ | -------------------------------------------- | ------------------------------ |
| 设备主数据   | 必须关联有效设备，任务执行时联动设备状态     | 状态联动：空闲 ⇄ 维护中        |
| 维护计划     | 计划维护关联维护计划，系统按计划自动生成任务 | 定期自动生成维护任务           |
| 维护记录     | 任务完成后自动生成维护记录                   | 保存详细维护信息，用于历史追溯 |
| 备件管理     | 完成时记录使用的备件清单                     | 用于成本统计和库存管理         |
| 用户组织架构 | 根据部门岗位筛选维护人员，控制操作权限       | 人员筛选、权限控制、负载统计   |

## 典型业务场景

### 场景1：日常计划维护
1. 系统根据维护计划自动生成任务（待执行）
2. 管理员派工给维护人员
3. 维护人员接单 → 开始执行（设备状态：维护中）
4. 维护人员完成任务，记录维护内容和发现的问题
5. 系统自动生成维护记录（设备状态：空闲）

### 场景2：应急抢修
1. 设备故障，值班人员手动创建应急抢修任务
2. 管理员紧急派工给在岗维修人员
3. 维修人员立即接单并开始执行
4. 完成抢修，记录故障原因、处理措施和使用备件
5. 系统生成维护记录，设备恢复正常

### 场景3：任务延期
1. 维护人员接到任务，准备执行
2. 发现缺少必要备件，无法立即完成
3. 申请延期并说明原因（"备件未到货"）
4. 任务状态变为"已延期"（如正在执行，设备恢复空闲）
5. 备件到货后重新开始执行
6. 完成任务，生成维护记录

### 场景4：任务取消
1. 管理员创建维护任务
2. 设备临时被调拨或计划调整
3. 管理员取消任务并说明原因
4. 任务状态变为"已取消"（如正在执行，设备恢复空闲）

## 接口使用建议

### 核心接口

| 接口类型 | 接口路径                                              | 说明                           |
| -------- | ----------------------------------------------------- | ------------------------------ |
| 查询     | `GET /v1/mdm/tpm/maintenance-tasks`                   | 分页查询任务列表，支持多种筛选 |
| 查询详情 | `GET /v1/mdm/tpm/maintenance-tasks/:taskId`           | 获取任务完整信息和关联数据     |
| 我的任务 | `GET /v1/mdm/tpm/maintenance-tasks/my-tasks`          | 自动筛选当前用户的任务         |
| 创建     | `POST /v1/mdm/tpm/maintenance-tasks`                  | 创建维护任务                   |
| 派工     | `POST /v1/mdm/tpm/maintenance-tasks/:taskId/assign`   | 指定执行人员                   |
| 接单     | `POST /v1/mdm/tpm/maintenance-tasks/:taskId/accept`   | 维护人员接收任务               |
| 开始执行 | `POST /v1/mdm/tpm/maintenance-tasks/:taskId/start`    | 开始执行维护工作               |
| 完成     | `POST /v1/mdm/tpm/maintenance-tasks/:taskId/complete` | 完成任务并生成维护记录         |
| 延期     | `POST /v1/mdm/tpm/maintenance-tasks/:taskId/postpone` | 申请延期                       |
| 取消     | `POST /v1/mdm/tpm/maintenance-tasks/:taskId/cancel`   | 取消任务                       |

### 统计分析接口

| 接口名称 | 接口路径                                      | 说明                     |
| -------- | --------------------------------------------- | ------------------------ |
| 逾期任务 | `GET /v1/mdm/tpm/maintenance-tasks/overdue`   | 查询逾期未完成的任务     |
| 日历视图 | `GET /v1/mdm/tpm/maintenance-tasks/calendar`  | 获取日历展示数据         |
| 负载分析 | `GET /v1/mdm/tpm/maintenance-tasks/workload`  | 按人员或设备统计任务负载 |
| 人员筛选 | `GET /v1/mdm/tpm/maintenance-tasks/personnel` | 根据组织架构筛选维护人员 |

### 常见错误码

| 错误码           | 说明           | 处理建议         |
| ---------------- | -------------- | ---------------- |
| TPM_TASK_001     | 任务不存在     | 检查任务ID       |
| TPM_TASK_010-015 | 状态不允许操作 | 检查任务当前状态 |
| TPM_TASK_016     | 权限不足       | 验证执行人身份   |
| VALIDATION_ERROR | 参数验证失败   | 检查请求参数     |

### 前端展示建议

**状态徽章颜色映射**：
- 待执行：灰色（default）
- 执行中：蓝色（processing）
- 已完成：绿色（success）
- 已延期：橙色（warning）
- 已取消：红色（error）

**任务类型颜色映射（日历视图）**：
- 计划维护：蓝色（#1890ff）
- 应急抢修：红色（#f5222d）
- 状态检修：橙色（#faad14）
