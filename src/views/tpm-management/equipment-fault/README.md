# 设备故障管理模块

## 📋 模块说明

设备故障管理模块是设备TPM管理系统的关键模块，负责管理设备故障的全生命周期，从故障发现、报告、处理、验证到关闭的完整流程。

## ✅ 已实现功能（TASK001 - 故障列表页面）

### P0 核心功能（已完成9/9）

1. ✅ **列表页面渲染**
   - 支持分页查询，默认每页10条
   - 数据加载状态反馈
   - 加载失败重试机制

2. ✅ **多条件筛选**
   - 按设备筛选
   - 按故障等级筛选（I级-严重、II级-重大、III级-一般、IV级-轻微）
   - 按故障类型筛选（机械、电气、液压、控制、其他）
   - 按处理状态筛选（待处理、处理中、已解决、已验证、已关闭）
   - 支持多状态组合查询

3. ✅ **高级筛选**
   - 按报告人筛选
   - 按处理人筛选
   - 按是否重复故障筛选
   - 关键词搜索（故障编码或描述）
   - 时间范围筛选（故障发生时间）

4. ✅ **表格展示**
   - 故障编码（支持点击复制）
   - 设备编码/名称
   - 故障描述（支持文本溢出提示）
   - 故障等级（醒目标识）
   - 影响程度
   - 故障类型
   - 处理状态（标签展示）
   - 重复故障标记（红色警告图标）
   - MTTR（平均修复时间，格式化为"X.X小时"）
   - 报告人/处理人
   - 故障时间

5. ✅ **故障等级醒目标识**
   - I级-严重：红色（danger）+ 行高亮
   - II级-重大：橙色（warning）+ 行高亮
   - III级-一般：灰色（info）
   - IV级-轻微：绿色（success）

6. ✅ **处理状态标签展示**
   - 待处理：info
   - 处理中：warning
   - 已解决：success
   - 已验证：primary
   - 已关闭：info

7. ✅ **重复故障标记**
   - 红色警告图标
   - 脉冲动画效果
   - 鼠标悬停提示

8. ✅ **分页和排序**
   - 灵活的分页配置（10/20/50/100条每页）
   - 支持按多列排序
   - 默认按故障时间倒序

9. ✅ **快捷操作按钮**
   - 查看详情
   - 处理（待处理/处理中状态显示）
   - 关闭（非已关闭状态显示）
   - 根据状态动态显示/隐藏

### P1 优化功能（已完成2/7）

## 🎨 设计特点

1. **全局组件优先使用**
   - 基于 BaseTable 实现表格功能
   - 使用 TableToolbar 实现工具栏
   - 使用 SearchForm 实现搜索功能
   - 使用 StatusTag 实现状态标签
   - 使用 ActionButtons 实现操作按钮

2. **配置驱动**
   - 表格列配置化
   - 搜索表单配置化
   - 常量集中管理

3. **标准架构**
   - 遵循 aluminum-foil-product-management 模块的设计模式
   - 常量、组件、API 分离
   - 统一的错误处理和消息提示

4. **现代化UI**
   - 醒目的故障等级标识
   - 行级高亮显示严重故障
   - 动画效果增强用户体验
   - 友好的交互反馈

## 🔧 技术实现

### 核心技术栈
- Vue 2.x
- Element UI
- Axios

### 关键功能实现

1. **多条件筛选**
   ```javascript
   // 支持多维度组合筛选
   - 精确匹配：设备、等级、类型、报告人、处理人
   - 范围筛选：时间范围
   - 模糊搜索：关键词搜索
   - 多值筛选：状态组合查询
   ```

2. **故障等级标识**
   ```scss
   // 行级样式 + 标签颜色
   .fault-table__row--critical  // I级严重：红色背景
   .fault-table__row--major     // II级重大：橙色背景
   ```

3. **重复故障标记**
   ```vue
   <i class="el-icon-warning fault-table__repeat-icon" />
   // 红色 + 脉冲动画
   ```
