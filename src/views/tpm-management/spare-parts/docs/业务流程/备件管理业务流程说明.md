# 备件管理业务流程说明

## 文档说明

本文档基于备件管理模块的实际实现，说明核心业务逻辑和数据管理规则，为前端开发提供业务理解基础。

## 核心概念

### 备件管理定义

**备件管理（SparePart Management）**：管理设备维护所需备件的基础信息、库存状态和出入库流水，实现备件从采购入库、领用消耗到库存预警的全生命周期管理。

### 三层数据结构

| 数据层级   | 定义                     | 核心字段                        | 作用                         |
| ---------- | ------------------------ | ------------------------------- | ---------------------------- |
| 备件主数据 | 备件的基础信息和规格参数 | 编码、名称、规格、供应商、价格  | 定义备件属性，设置库存策略   |
| 库存记录   | 备件的实时库存状态       | 当前库存、在途数量、预留数量    | 反映备件可用性，支持库存决策 |
| 出入库流水 | 备件的所有进出记录       | 单号、类型、数量、关联任务/故障 | 可追溯，成本核算，消耗分析   |

### 出入库类型

| 类型 | 定义                       | 库存影响 | 关联要求             | 特点                 |
| ---- | -------------------------- | -------- | -------------------- | -------------------- |
| 入库 | 采购、调拨等入库操作       | 增加库存 | 无                   | 补充库存，更新可用量 |
| 领用 | 维护任务或故障维修使用     | 减少库存 | 必须关联任务或故障单 | 消耗备件，责任可追溯 |
| 退库 | 领用后剩余备件退回         | 增加库存 | 可选关联任务或故障单 | 回收可用备件         |
| 报废 | 过期、损坏等不可用备件处理 | 减少库存 | 无                   | 清理库存，损失记录   |

## 业务流程详解

### 1. 备件主数据管理

#### 创建备件
- **触发方式**：管理员通过界面录入新备件信息
- **必填信息**：
  - 备件编码（全局唯一，自动转大写）
  - 备件名称
  - 计量单位（如：件、个、升、公斤）
- **可选信息**：
  - 规格型号
  - 适用设备类型/型号（逗号分隔，支持多种设备）
  - 供应商信息（JSON格式：名称、联系人、电话、邮箱）
  - 单价
  - 库存上限/下限/安全库存
  - 采购提前期（天）
  - 存储位置
  - 保质期（月）
  - 备注
- **自动操作**：
  - 创建备件时自动创建对应的库存记录（初始库存为0）
  - 记录创建人和创建时间
- **验证规则**：
  - 备件编码唯一性验证
  - 库存上限必须 ≥ 库存下限
  - 数值类型字段非负验证

#### 查询备件
- **列表查询筛选条件**：
  - 备件编码：模糊查询
  - 备件名称：模糊查询
  - 适用设备类型：模糊查询
  - 低库存筛选：只显示当前库存 ≤ 安全库存的备件
- **排序**：支持按编码、名称、创建时间、更新时间排序
- **分页**：每页1-100条可配置，默认10条
- **详情查询**：包含备件基础信息、当前库存信息、创建人/更新人信息

#### 更新备件
- **权限要求**：需要管理权限（mdm.tpm.spare-part.manage）
- **可更新内容**：除备件编码外的所有字段均可更新
- **更新场景**：
  - 供应商信息变更
  - 价格调整
  - 库存策略调整（上下限、安全库存）
  - 存储位置变更
  - 补充完善备件信息
- **验证规则**：与创建时相同的验证逻辑

### 2. 库存管理

#### 库存状态
- **当前库存（currentQuantity）**：实际可用的库存数量
- **在途数量（inTransitQuantity）**：已采购但未到货的数量
- **预留数量（reservedQuantity）**：已被预留但未实际领用的数量
- **可用库存**：当前库存 - 预留数量（计算字段）

#### 库存查询
- **查询方式**：
  - 按备件ID查询单个备件的库存详情
  - 列表查询时自动包含库存信息
  - 低库存备件列表专项查询
- **返回信息**：
  - 当前库存数量
  - 在途数量
  - 预留数量
  - 可用库存（计算值）
  - 是否低于安全库存（布尔值）
  - 关联的备件基础信息

#### 低库存预警
- **预警条件**：当前库存 ≤ 安全库存
- **预警用途**：
  - 提醒采购补货
  - 库存报表分析
  - 避免缺货影响维护
- **查询方式**：
  - 列表查询时使用 `lowStock=true` 参数
  - 专用低库存列表接口

#### 库存自动更新
- **入库操作**：自动增加当前库存
- **出库操作**：自动减少当前库存
- **验证机制**：出库时检查库存充足性
- **更新时间**：每次变更自动记录最后更新时间

### 3. 出入库管理

#### 备件入库
- **触发方式**：
  - 采购入库
  - 调拨入库
  - 退库（已领用备件退回）
- **必填信息**：
  - 备件ID
  - 入库数量（必须 > 0）
- **可选信息**：
  - 入库单号（不提供则自动生成：SP-IN-时间戳）
  - 用途说明
  - 备注
- **业务操作**：
  1. 验证备件存在性
  2. 生成或验证入库单号唯一性
  3. 创建入库记录
  4. 更新库存（增加当前库存）
  5. 记录操作人和操作时间
- **事务保护**：使用数据库事务确保记录和库存同步更新

#### 备件出库（领用）
- **触发方式**：
  - 维护任务执行时领用
  - 故障维修时领用
- **必填信息**：
  - 备件ID
  - 出库数量（必须 > 0 且 ≤ 当前库存）
  - 关联维护任务ID 或 关联故障单ID（至少填一项）
- **可选信息**：
  - 出库单号（不提供则自动生成：SP-OUT-时间戳）
  - 用途说明
  - 备注
- **业务验证**：
  1. 验证备件存在性
  2. 检查库存是否充足
  3. 验证关联任务或故障单存在性
  4. 验证出库单号唯一性
- **业务操作**：
  1. 创建出库记录
  2. 更新库存（减少当前库存）
  3. 记录操作人和操作时间
- **强制关联**：领用必须关联维护任务或故障单，确保责任可追溯

#### 备件退库
- **触发方式**：领用后有剩余备件退回
- **必填信息**：
  - 备件ID
  - 退库数量（必须 > 0）
- **可选信息**：
  - 退库单号（不提供则自动生成：SP-RET-时间戳）
  - 关联维护任务ID（可选）
  - 关联故障单ID（可选）
  - 用途说明
  - 备注
- **业务操作**：与入库流程相同，增加库存

#### 备件报废
- **触发方式**：
  - 备件过期
  - 备件损坏不可用
  - 备件规格淘汰
- **必填信息**：
  - 备件ID
  - 报废数量（必须 > 0 且 ≤ 当前库存）
- **可选信息**：
  - 报废单号（不提供则自动生成：SP-SCR-时间戳）
  - 用途说明（报废原因）
  - 备注
- **业务操作**：与出库流程相同，减少库存

### 4. 出入库记录查询

#### 查询条件
- **按备件筛选**：查询指定备件的所有出入库记录
- **按类型筛选**：入库、领用、退库、报废
- **按单号筛选**：出入库单号模糊查询
- **按时间筛选**：开始日期、结束日期范围
- **排序**：默认按出入库时间降序（最新记录在前）
- **分页**：每页1-100条可配置，默认10条

#### 记录详情
- **基本信息**：单号、类型、数量、时间
- **备件信息**：编码、名称、单位
- **人员信息**：经手人（姓名、邮箱）
- **关联信息**：
  - 关联维护任务（任务编码、标题、状态）
  - 关联故障单（故障编码、描述、状态）
- **辅助信息**：用途说明、备注、创建人/更新人

#### 查询用途
- **备件消耗分析**：统计某段时间内的备件使用情况
- **成本核算**：计算维护任务的备件成本
- **库存追溯**：追踪备件流向和使用记录
- **审计检查**：验证出入库操作的合规性

## 数据约束规则

### 备件主数据约束

| 字段         | 约束规则                                      |
| ------------ | --------------------------------------------- |
| 备件编码     | 必填，全局唯一，自动转大写，长度1-100字符     |
| 备件名称     | 必填，长度1-200字符                           |
| 规格型号     | 可选，长度最多200字符                         |
| 适用设备类型 | 可选，长度最多500字符，逗号分隔               |
| 供应商信息   | 可选，JSONB格式，包含名称、联系人、电话、邮箱 |
| 单价         | 可选，decimal(10,2)，必须 ≥ 0                 |
| 计量单位     | 必填，长度1-50字符                            |
| 库存上限     | 可选，整数，必须 ≥ 0，必须 ≥ 库存下限         |
| 库存下限     | 可选，整数，必须 ≥ 0，必须 ≤ 库存上限         |
| 安全库存     | 必填，默认0，整数，必须 ≥ 0                   |
| 采购提前期   | 可选，整数，必须 ≥ 0，单位：天                |
| 存储位置     | 可选，长度最多100字符                         |
| 保质期       | 可选，整数，必须 ≥ 0，单位：月                |
| 备注         | 可选，文本类型                                |

| 关联任务ID | 可选（领用时必填之一），UUID格式          |
| 关联故障ID | 可选（领用时必填之一），UUID格式          |
| 用途说明   | 可选，文本类型                            |
| 备注       | 可选，文本类型                            |

## 核心业务规则

1. **备件编码唯一性**：备件编码全局唯一，自动转大写，创建和更新时验证
2. **库存策略验证**：库存上限必须 ≥ 库存下限，创建和更新时验证
3. **一备件一库存**：创建备件时自动创建唯一的库存记录，初始库存为0
4. **领用强制关联**：备件领用必须关联维护任务或故障单，至少选一项
5. **库存充足性检查**：出库和报废时验证当前库存是否充足
6. **单号唯一性**：出入库单号全局唯一，自动转大写
7. **低库存预警**：当前库存 ≤ 安全库存时标记为低库存状态
8. **软删除策略**：备件和出入库记录采用软删除，保留历史数据
9. **事务保护**：所有出入库操作使用数据库事务确保数据一致性
10. **审计追踪**：记录创建人、更新人、创建时间、更新时间

| 采购管理   | 低库存预警触发采购需求（未来扩展） | 自动补货、采购计划         |

## 典型业务场景

### 场景1：新备件录入和首次采购入库
1. 仓库管理员收到新备件入库通知
2. 创建备件主数据：
   - 备件编码：SP-BEARING-001
   - 备件名称：高温轴承
   - 规格型号：SKF 6208
   - 适用设备类型：退火炉，行车
   - 供应商：{name: "SKF供应商", contact: "张三", phone: "138xxxx"}
   - 单价：280.00
   - 计量单位：件
   - 库存上限：50，库存下限：10，安全库存：5
   - 采购提前期：7天
   - 存储位置：仓库A区2号货架
3. 系统自动创建库存记录（初始库存为0）
4. 执行入库操作：
   - 选择刚创建的备件
   - 入库数量：30
   - 用途说明：采购入库
5. 系统生成入库单号：SP-IN-1704038400000
6. 库存自动更新为30件

### 场景2：维护任务领用备件
1. 维护工程师执行退火炉维护任务（任务ID：task-001）
2. 需要更换轴承，查询备件库存：
   - 搜索"高温轴承"
   - 查看当前库存：30件（充足）
3. 执行备件领用：
   - 选择备件：SP-BEARING-001
   - 领用数量：2
   - 关联维护任务：task-001
   - 用途说明：更换退火炉1#传动轴承
4. 系统验证：
   - 库存充足（30 ≥ 2）
   - 任务存在且有效
5. 生成领用单号：SP-OUT-1704038500000
6. 库存自动减少到28件
7. 维护任务记录显示使用备件清单

### 场景3：低库存预警和补货
1. 系统定期检查低库存备件
2. 发现"高温轴承"当前库存28件，多次领用后降至4件
3. 低库存预警触发（4 ≤ 5）
4. 采购部门查看低库存列表：
   - 使用筛选条件：lowStock=true
   - 查看预警备件列表
5. 根据备件信息制定采购计划：
   - 当前库存：4件
   - 安全库存：5件
   - 库存上限：50件
   - 采购提前期：7天
   - 建议采购数量：46件（上限 - 当前库存）
6. 采购到货后执行入库操作
7. 库存恢复正常

### 场景4：故障维修紧急领用
1. 行车发生故障（故障单ID：failure-002）
2. 维修人员诊断需要更换轴承
3. 查询备件库存：
   - 搜索适用设备类型："行车"
   - 找到"高温轴承"，当前库存：50件
4. 紧急领用备件：
   - 选择备件：SP-BEARING-001
   - 领用数量：1
   - 关联故障单：failure-002
   - 用途说明：行车主轴轴承损坏更换
5. 系统生成领用单号并更新库存
6. 故障单关联备件使用记录

### 场景5：备件退库和报废
1. 维护任务完成后发现领用的备件有剩余
2. 执行退库操作：
   - 选择备件：SP-BEARING-001
   - 退库数量：1
   - 关联维护任务：task-001（可选）
   - 用途说明：任务完成剩余退库
3. 库存自动增加
4. 仓库管理员定期检查库存，发现部分备件已过保质期
5. 执行报废操作：
   - 选择过期备件
   - 报废数量：3
   - 用途说明：超过保质期报废
6. 库存自动减少，生成报废单记录

### 场景6：备件消耗统计分析
1. 月度设备管理会议，需要备件消耗报告
2. 设备管理员查询出入库记录：
   - 时间范围：2024年第一季度
   - 筛选类型：领用
3. 统计分析结果：
   - 总领用次数：120次
   - 总消耗数量：358件
   - 领用最多的备件：高温轴承（85次）
   - 关联维护任务：95次
   - 关联故障维修：25次
4. 按设备类型分析备件消耗：
   - 退火炉：65%
   - 行车：25%
   - 其他设备：10%
5. 根据分析优化采购计划和库存策略

## 接口使用建议

### 核心接口

| 接口类型       | 接口路径                                     | 说明                             |
| -------------- | -------------------------------------------- | -------------------------------- |
| 创建备件       | `POST /v1/mdm/tpm/spare-parts`               | 创建备件主数据，自动创建库存记录 |
| 查询列表       | `GET /v1/mdm/tpm/spare-parts`                | 分页查询备件列表，支持多种筛选   |
| 查询详情       | `GET /v1/mdm/tpm/spare-parts/:id`            | 获取备件完整信息和库存状态       |
| 更新备件       | `PATCH /v1/mdm/tpm/spare-parts/:id`          | 更新备件基础信息                 |
| 查询库存       | `GET /v1/mdm/tpm/spare-parts/:id/inventory`  | 获取备件库存详情和预警状态       |
| 备件入库       | `POST /v1/mdm/tpm/spare-parts/:id/in-stock`  | 备件入库操作，自动更新库存       |
| 备件出库       | `POST /v1/mdm/tpm/spare-parts/:id/out-stock` | 备件领用/退库/报废，自动更新库存 |
| 查询出入库记录 | `GET /v1/mdm/tpm/spare-parts/transactions`   | 分页查询出入库流水               |

### 常见错误码

| 错误码                | 说明                         | 处理建议               |
| --------------------- | ---------------------------- | ---------------------- |
| SPARE_PART_001        | 备件编码已存在               | 使用不同的备件编码     |
| SPARE_PART_002        | 备件不存在                   | 检查备件ID             |
| SPARE_PART_003        | 库存上限小于库存下限         | 调整库存上下限设置     |
| SPARE_PART_004        | 库存记录不存在               | 联系管理员修复数据     |
| SPARE_PART_005        | 出入库单号已存在             | 使用自动生成的单号     |
| SPARE_PART_006        | 库存不足，无法出库           | 检查库存或减少出库数量 |
| SPARE_PART_007        | 备件领用必须关联任务或故障单 | 选择关联的任务或故障单 |
| MAINTENANCE_TASK_002  | 关联的维护任务不存在         | 检查任务ID             |
| EQUIPMENT_FAILURE_002 | 关联的故障单不存在           | 检查故障单ID           |
| USER_001              | 用户不存在                   | 检查经手人ID           |
| VALIDATION_ERROR      | 参数验证失败                 | 检查请求参数           |
