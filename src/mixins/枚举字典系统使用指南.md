# 枚举字典系统使用指南

## 📋 概述

枚举字典系统通过后端API统一管理所有枚举值和对应的中文标签，避免前端硬编码，确保前后端数据一致性。

## 🎯 核心优势

### ✅ 解决的问题
- **前后端不一致**：枚举值和中文映射由后端统一维护
- **硬编码问题**：前端无需维护大量的枚举映射表
- **支持国际化**：后端可根据语言返回不同标签
- **动态更新**：新增枚举值无需前端发版

### 🔄 工作原理
```
┌─────────────┐
│  应用启动   │
└──────┬──────┘
       │
       ▼
┌─────────────────────┐
│ 加载枚举字典API     │
│ GET /v1/prod/plans/ │
│ dictionaries        │
└──────┬──────────────┘
       │
       ▼
┌─────────────────────┐
│ 存储到Vuex Store    │
│ 缓存到localStorage  │
│ 有效期: 24小时      │
└──────┬──────────────┘
       │
       ▼
┌─────────────────────┐
│ 组件通过mixin       │
│ 或工具函数访问      │
└─────────────────────┘
```

## 🚀 快速开始

### 方式一：使用Mixin（推荐）

#### 1. 引入Mixin

```vue
<script>
import dictionaryMixin from '@/mixins/dictionaryMixin'

export default {
  name: 'MyComponent',
  mixins: [dictionaryMixin]
}
</script>
```

#### 2. 在模板中使用

```vue
<template>
  <div>
    <!-- 显示状态标签 -->
    <el-tag>{{ getPlanStatusLabel(plan.status) }}</el-tag>

    <!-- 下拉选择框 -->
    <el-select v-model="formData.priority">
      <el-option
        v-for="item in planPriorityOptions"
        :key="item.value"
        :label="item.label"
        :value="item.value"
      />
    </el-select>
  </div>
</template>
```

#### 3. 在JS中使用

```javascript
methods: {
  handleStatusChange(status) {
    const label = this.getPlanStatusLabel(status)
    this.$message.success(`状态已变更为：${label}`)
  }
}
```

---

### 方式二：使用工具函数

#### 1. 引入工具函数

```javascript
import {
  getPlanStatusLabel,
  getPlanItemStatusLabel,
  getPlanPriorityOptions
} from '@/utils/dictionary'
```

#### 2. 直接调用

```javascript
export default {
  methods: {
    formatStatus(status) {
      return getPlanStatusLabel(status)
    }
  },
  computed: {
    priorityOptions() {
      return getPlanPriorityOptions()
    }
  }
}
```

---

### 方式三：直接访问Store

```javascript
export default {
  computed: {
    statusLabel() {
      return this.$store.getters['dictionary/getPlanStatusLabel'](this.status)
    },
    priorityOptions() {
      return this.$store.getters['dictionary/planPriorityOptions']
    }
  }
}
```

## 📚 可用的字典类型

### 生产计划主状态 (`planStatuses`)

| 枚举值               | 中文标签 | 说明 |
|---------------------|---------|-----|
| RECEIVED            | 已接收   | 从ERP接收的计划 |
| CONFIRMED           | 已确认   | 确认生产 |
| READY_FOR_SCHEDULING| 待排程   | 等待排程 |
| SCHEDULED           | 已排程   | 已分配时间 |
| RELEASED            | 已发布   | 已下达生产 |
| IN_PROGRESS         | 执行中   | 正在生产 |
| PAUSED              | 已暂停   | 暂停生产 |
| COMPLETED           | 已完成   | 生产完成 |
| CANCELLED           | 已取消   | 取消生产 |

**使用方法**：
```javascript
// 获取标签
getPlanStatusLabel('RELEASED') // → "已发布"

// 获取选项
planStatusOptions // → [{ value: 'RECEIVED', label: '已接收' }, ...]
```

## 🔧 完整的Mixin API

### 计算属性（Computed）

| 属性名                    | 返回类型 | 说明             |
|--------------------------|---------|-----------------|
| `planStatusOptions`      | Array   | 计划状态选项     |
| `planItemStatusOptions`  | Array   | 子批次状态选项   |
| `planPriorityOptions`    | Array   | 计划优先级选项   |
| `planSourceOptions`      | Array   | 计划来源选项     |

### 方法（Methods）

| 方法名                              | 参数   | 返回值 | 说明                  |
|------------------------------------|--------|-------|----------------------|
| `getPlanStatusLabel(status)`       | string | string | 获取计划状态标签      |
| `getPlanItemStatusLabel(status)`   | string | string | 获取子批次状态标签    |
| `getPlanPriorityLabel(priority)`   | string | string | 获取计划优先级标签    |
| `getPlanSourceLabel(source)`       | string | string | 获取计划来源标签      |
| `getProcessTemplateLinkTypeLabel(type)` | string | string | 获取工艺模板关联类型标签 |
| `getEquipmentLinkTypeLabel(type)`  | string | string | 获取设备关联类型标签  |
| `getChangeTypeLabel(type)`         | string | string | 获取变更类型标签      |
| `getOperationSourceLabel(source)`  | string | string | 获取操作来源标签      |

## ⚙️ 高级功能

### 强制刷新字典

```javascript
// 在某个组件中强制刷新字典数据
this.$store.dispatch('dictionary/loadProductionPlanDictionaries', true)
```

### 清除缓存

```javascript
// 清除字典缓存（下次会从服务器重新加载）
this.$store.dispatch('dictionary/clearDictionaryCache')
```

### 检查字典加载状态

```javascript
computed: {
  isDictionaryLoaded() {
    return this.$store.state.dictionary.loaded
  },
  isDictionaryLoading() {
    return this.$store.state.dictionary.loading
  }
}
```

## 🔍 故障排查

### 问题1：字典数据未加载

**症状**：页面显示的是枚举值而不是中文

**排查步骤**：
1. 检查控制台是否有 `[Dictionary] 从缓存加载字典数据` 或 `[Dictionary] 从服务器加载字典数据` 日志
2. 检查Network面板是否成功调用 `/v1/prod/plans/dictionaries`
3. 检查localStorage中是否有 `app_dictionaries_cache`

**解决方案**：
```javascript
// 手动触发加载
this.$store.dispatch('dictionary/loadProductionPlanDictionaries', true)
```

---

### 问题2：缓存过期

**症状**：字典数据是旧的

**解决方案**：
```javascript
// 清除缓存并重新加载
this.$store.dispatch('dictionary/clearDictionaryCache')
  .then(() => {
    this.$store.dispatch('dictionary/loadProductionPlanDictionaries', true)
  })
```

---

### 问题3：Mixin中的方法返回undefined

**原因**：字典数据还未加载完成

**解决方案**：
```vue
<template>
  <div v-if="isDictionaryLoaded">
    {{ getPlanStatusLabel(status) }}
  </div>
  <div v-else>
    加载中...
  </div>
</template>

<script>
export default {
  computed: {
    isDictionaryLoaded() {
      return this.$store.state.dictionary.loaded
    }
  }
}
</script>
```

## 📦 缓存机制

### 缓存策略
- **存储位置**：localStorage
- **缓存键名**：`app_dictionaries_cache`
- **有效期**：24小时
- **更新时机**：
  - 缓存过期后自动从服务器加载
  - 手动强制刷新
  - 首次登录

### 缓存优势
- ✅ 减少API调用
- ✅ 提升加载速度
- ✅ 离线可用（在有效期内）

## 🎓 最佳实践

1. **优先使用Mixin**：代码更简洁
2. **避免硬编码**：所有枚举都从字典获取
3. **统一数据源**：后端是唯一数据源
4. **合理使用缓存**：不要频繁清除缓存
5. **错误处理**：字典未加载时显示加载中或默认值
